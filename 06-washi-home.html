每个归档含 include/erika.h、许可证文本与记录 tag/commit 的 MANIFEST.txt。Linux 暂未发布。

# Cargo.toml
[dependencies]
erika = { git = "https://github.com/AimesSoft/Erika", tag = "v0.1.5" }

从源码构建前需先用 cargo run -p xtask -- deps build --all --profile lgpl 准备原生依赖。

# pubspec.yaml
dependencies:
  erika_flutter:
    git:
      url: https://github.com/AimesSoft/Erika
      path: packages/erika_flutter

export ERIKA_PREBUILT=1   # 用预编译运行时,下载失败回退源码构建

插件覆盖 macOS / iOS / tvOS / Windows / Android / HarmonyOS 六个目标。

#include "erika.h"

ErikaPresenterHandle *p = erika_presenter_create();
erika_presenter_attach_metal_layer(p, (uint64_t)layer, w, h, scale);
erika_presenter_open(p, "/path/to/video.mp4");
erika_presenter_play(p);

/* 每个显示帧 */
ErikaPresenterStats stats;
erika_presenter_render_tick(p, host_time, &stats);

ErikaPresenterHandle 由内核托管完整播放栈;若宿主想自己拥有渲染循环,改用 ErikaHandle 自行拉取帧数据。

名は『うみねこのなく頃に』の探偵、古戸ヱリカより。
一つは表の再生器、一つは裏の機関。

「GOOD！我是 Erika,是 NipaPlay 里继 mdk、video player、libmpv、media kit 之后的第五个播放器内核。」

「即便算上你,也只有四个播放器内核！」

名字取自《海猫鸣泣之时》的侦探古戸ヱリカ(古户绘梨花)。NipaPlay 取自《寒蝉鸣泣之时》古手梨花的口癖「にぱー☆」。一个是台前的播放器,一个是幕后的引擎。
