这个页面是怎么接入的

import { Player } from
  'https://cdn.jsdelivr.net/npm/@aimessoft/liberika-web@0.3.8/index.js';

const player = await Player.create({ canvas });
await player.open(fileOrURL);   // File, Blob, or a URL
await player.play();

本页直接从 npm CDN 加载 @aimessoft/liberika-web，没有自带任何 WASM 文件。在自己的项目里用 npm install @aimessoft/liberika-web，Vite 等打包器无需额外配置。

可以试什么

  • 带 ASS 特效字幕和字体附件的 MKV：定位、旋转、卡拉 OK、描边都按原脚本绘制。
  • Bilibili XML 或弹弹play JSON 弹幕文件，再拖动不透明度和字号。
  • 在地址后加 ?src=视频地址 打开远程文件，服务器需要支持 CORS 和 HTTP Range。

能否播放取决于浏览器的 WebCodecs 支持的编码；当前输出为 SDR。需要较新的 Chrome、Edge 或 Safari。
