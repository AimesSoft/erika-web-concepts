Evidence / npm

这一页只写了三行

本页没有自带任何 WASM 文件，播放内核直接从 npm CDN 加载。在自己的项目里安装同一个包即可。

JAVASCRIPT 
// npm install @aimessoft/liberika-web
import { Player } from '@aimessoft/liberika-web';

const player = await Player.create({ canvas });
await player.open(fileOrURL); // File, Blob, or a URL
await player.play();

NOTEVite 等打包器无需额外配置；不用打包器时可以像本页一样从 CDN 导入。

远程文件

在地址后加 ?src=视频地址 打开远程文件，服务器需要支持 CORS 和 HTTP Range。

  • HTTP Range
  • CORS

能否播放取决于浏览器的 WebCodecs 支持的编码；当前输出为 SDR。需要较新的 Chrome、Edge 或 Safari。
