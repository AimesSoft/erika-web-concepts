Linux 接入

Linux / X11 / Wayland / WSLg

0.2.1 新增实验性 Linux 支持：Rust、C/C++ 与 Flutter 宿主可通过 X11 或 Wayland 显示视频，通过 PulseAudio 输出音频。Linux 目前从源码构建，尚无预编译发布包。

  • 依赖 FFmpeg 8.x
  • 窗口 X11 / Wayland
  • 音频 PulseAudio

准备依赖#

以下依赖命令适用于 Ubuntu 26.04；Rust 需要 1.92+。Ubuntu 22.04 / 24.04 默认仓库中的旧版 FFmpeg 不满足这一构建路径。

Ubuntu 26.04

sudo apt update
sudo apt install -y \
  build-essential pkg-config clang libclang-dev rustc cargo rustfmt \
  curl ca-certificates meson ninja-build patch xz-utils python3 \
  libavdevice-dev libavfilter-dev libavformat-dev libavcodec-dev \
  libswresample-dev libswscale-dev libavutil-dev \
  libfreetype-dev libharfbuzz-dev libfribidi-dev libfontconfig-dev \
  libpulse-dev libx11-dev libwayland-dev libxkbcommon-dev \
  libxkbcommon-x11-0 libvulkan-dev mesa-vulkan-drivers libegl1 \
  libgl1-mesa-dri fonts-dejavu-core pulseaudio-utils

PipeWire 桌面需启用 pipewire-pulse。可用 pactl info 检查音频连接；WSLg 已提供 PulseAudio 服务。

构建与运行#

shell

git clone https://github.com/AimesSoft/Erika.git
cd Erika
git checkout v0.2.1
bash scripts/build_linux_libass.sh
cargo build --locked --release -p linux_native_demo -p erika_capi
cargo run --locked --release -p linux_native_demo -- /path/to/video.mkv

libass 使用 Erika 补丁版 0.17.5，构建脚本负责下载、校验和应用字体回退补丁。FFmpeg 8 与 PulseAudio 默认动态链接系统库。产物位于 target/release/。

Demo 自动选择窗口协议，也可传入 --x11 或 --wayland。空格暂停或继续，左右箭头跳转 5 秒，Esc 退出。

Flutter 接入#

shell

cargo build --locked --release -p erika_capi
export ERIKA_LIBRARY_DIR="${CARGO_TARGET_DIR:-$PWD/target}/release"
# 在 Flutter 宿主目录中执行：
flutter build linux --release

宿主添加 erika_flutter: ^0.2.1。ErikaVideoView 与 ErikaTextureVideoView 使用 SDR RGBA 纹理，支持 Flutter 裁剪和 UI 叠层；这条路径需要逐帧 GPU 读回。

Wayland 可选 ErikaWindowOverlayVideoView，用 wl_subsurface 将原生视频放在透明 Flutter UI 下，减少逐帧 RGBA 读回。视频区域需留透明；该原生层支持不透明 srcOver，视频本身不接受 Flutter 裁剪或颜色滤镜。X11 使用纹理视图。

Rust 与 C/C++ 接入#

Rust 宿主启用 erika 的 wgpu feature。C 宿主链接 liberika_capi.so，使用同次构建的 erika.h。

surface kindraw_windowraw_display
ErikaWgpuSurfaceKind_XlibWindowX11 Window 整数 IDDisplay*
ErikaWgpuSurfaceKind_WaylandSurfacewl_surface*wl_display*

通过 erika_presenter_attach_wgpu_surface 附着窗口；指针经 uintptr_t 转为 uint64_t，宽高传物理像素。窗口与 display 在 detach 或销毁 presenter 完成后释放。同一 presenter 的 attach、render、resize 和 detach 在窗口事件线程串行执行。

调用顺序：create → attach → open → play → render_tick → close → detach → destroy。可运行的 C 示例位于 examples/linux_native_demo/capi_smoke.c。

解码与 GPU 路径#

Linux 默认尝试 NVIDIA NVDEC，再尝试 Intel / AMD VA-API；驱动或格式不支持时回退 FFmpeg 软解。

shell

export ERIKA_HWDEC=auto  # auto / cuda / nvdec / vaapi / software
# 多显卡机器可指定：
export ERIKA_CUDA_DEVICE=0
export ERIKA_VAAPI_DEVICE=/dev/dri/renderD128

普通 NVDEC 路径可将解码平面下载后上传到 wgpu；VA-API 到 Vulkan 的直接导入为实验性路径。Linux HDR 需要合成器实际提供 FP16 extended-linear WSI 表面，Flutter RGBA 纹理输出为 SDR。

WSLg#

shell

bash scripts/run_wsl_gpu.sh --wayland /mnt/c/path/to/video.mkv
# 或使用 X11：
bash scripts/run_wsl_gpu.sh --x11

启动脚本为 Erika 进程选择 wgpu → OpenGL/EGL → Mesa D3D12。WSL 使用 Windows 显卡驱动，无需安装 Linux NVIDIA 内核驱动。仓库位于 /mnt/c 时，可将 CARGO_TARGET_DIR 放到 Linux 文件系统以加快构建。

运行检查#

shell

bash scripts/check_linux.sh
# 同时检查 Wayland：
ERIKA_TEST_WAYLAND=1 bash scripts/check_linux.sh

检查需要可用的显示和音频服务，覆盖播放、暂停、seek、resize 和 C ABI 生命周期。
