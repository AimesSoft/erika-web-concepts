Linux access

Linux / X11 / Wayland / WSLg

0.2.1 Added experimental Linux support: Rust, C/C++ and Flutter hosts can display video through X11 or Wayland and output audio through PulseAudio. Linux is currently built from source code and there is no precompiled release package.

  • Depend on FFmpeg 8.x
  • window X11 / Wayland
  • Audio PulseAudio

Prepare to depend on#

The following dependency commands are applicable to Ubuntu 26.04; Rust requires 1.92+. Ubuntu 22.04 / 24.04 The old version of FFmpeg in the default repository does not satisfy this build path.

Ubuntu 26.04

sudo apt update
sudo apt install -y \
  build-essential pkg-config clang libclang-dev rustc cargo rustfmt \
  curl ca-certificates meson ninja-build patch xz-utils python3 \
  libavdevice-dev libavfilter-dev libavformat-dev libavcodec-dev \
  libswresample-dev libswscale-dev libavutil-dev \
  libfreetype-dev libharfbuzz-dev libfribidi-dev libfontconfig-dev \
  libpulse-dev libx11-dev libwayland-dev libxkbcommon-dev \
  libxkbcommon-x11-0 libvulkan-dev mesa-vulkan-drivers libegl1 \
  libgl1-mesa-dri fonts-dejavu-core pulseaudio-utils

PipeWire desktop needs to be enabled pipewire-pulse. Available pactl info Check audio connection; WSLg has provided PulseAudio service.

Build and run#

shell

git clone https://github.com/AimesSoft/liberika.git
cd liberika
git checkout v0.3.0
bash scripts/build_linux_libass.sh
cargo build --locked --release -p linux_native_demo -p erika_capi
cargo run --locked --release -p linux_native_demo -- /path/to/video.mkv

libass uses liberika patch version 0.17.5, and the build script is responsible for downloading, verifying, and applying the font fallback patch. FFmpeg 8 and PulseAudio dynamically link system libraries by default. The product is located in target/release/。

Demo automatically selects the window protocol, which can also be passed in --x11 or --wayland. Space to pause or continue, left and right arrows to jump for 5 seconds, Esc to exit.

Flutter access#

shell

cargo build --locked --release -p erika_capi
export ERIKA_LIBRARY_DIR="${CARGO_TARGET_DIR:-$PWD/target}/release"
# 在 Flutter 宿主目录中执行：
flutter build linux --release

host added erika_flutter: ^0.3.0。ErikaVideoView with ErikaTextureVideoView Using the SDR RGBA texture, Flutter cropping and UI overlaying are supported; this path requires frame-by-frame GPU readback.

Wayland optional ErikaWindowOverlayVideoView, use wl_subsurface Put native video under transparent Flutter UI to reduce frame-by-frame RGBA readback. The video area needs to be left transparent; this native layer supports opaque srcOver, and the video itself does not accept Flutter cropping or color filters. X11 uses texture views.

Rust and C/C++ access#

Rust host enabled erika of wgpu feature. C host link liberika_capi.so, using the same build erika.h。

surface kindraw_windowraw_display
ErikaWgpuSurfaceKind_XlibWindowX11 Window integer IDDisplay*
ErikaWgpuSurfaceKind_WaylandSurfacewl_surface*wl_display*

Pass erika_presenter_attach_wgpu_surface attached window; pointer uintptr_t convert to uint64_t, width and height transmit physical pixels. The window with display is released after detach or presenter is destroyed. attach, render, resize and detach of the same presenter are executed serially in the window event thread.

Calling sequence:create → attach → open → play → render_tick → close → detach → destroy. A runnable C example is located at examples/linux_native_demo/capi_smoke.c。

Decoding with GPU path#

Linux will try NVIDIA NVDEC by default, and then try Intel / AMD VA-API; if the driver or format is not supported, it will fall back to FFmpeg software decoding.

shell

export ERIKA_HWDEC=auto  # auto / cuda / nvdec / vaapi / software
# 多显卡机器可指定：
export ERIKA_CUDA_DEVICE=0
export ERIKA_VAAPI_DEVICE=/dev/dri/renderD128

The ordinary NVDEC path can download the decoding plane and then upload it to wgpu; the direct import from VA-API to Vulkan is an experimental path. Linux HDR requires the compositor to actually provide the FP16 extended-linear WSI surface, Flutter RGBA texture output is SDR.

WSLg#

shell

bash scripts/run_wsl_gpu.sh --wayland /mnt/c/path/to/video.mkv
# 或使用 X11：
bash scripts/run_wsl_gpu.sh --x11

The startup script selects wgpu → OpenGL/EGL → Mesa D3D12 for the liberika process. WSL uses the Windows GPU driver; no Linux NVIDIA kernel driver is required. If the repository is under /mnt/c, place CARGO_TARGET_DIR on the Linux filesystem to speed up builds.

run check#

shell

bash scripts/check_linux.sh
# 同时检查 Wayland：
ERIKA_TEST_WAYLAND=1 bash scripts/check_linux.sh

The check requires available display and audio services, covering the play, pause, seek, resize and C ABI lifecycles.
