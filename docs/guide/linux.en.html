Linux integration

Linux / X11 / Wayland / WSLg

Version 0.2.1 added experimental Linux support. Rust, C/C++, and Flutter hosts can display video through X11 or Wayland and output audio through PulseAudio. Linux is currently built from source; there is no prebuilt release package.

  • Depends on FFmpeg 8.x
  • Window X11 / Wayland
  • Audio PulseAudio

Install dependencies#

The following commands are for Ubuntu 26.04. Rust 1.92+ is required. The older FFmpeg in the default Ubuntu 22.04 and 24.04 repositories does not satisfy this build path.

Ubuntu 26.04

sudo apt update
sudo apt install -y \
  build-essential pkg-config clang libclang-dev rustc cargo rustfmt \
  curl ca-certificates meson ninja-build patch xz-utils python3 \
  libavdevice-dev libavfilter-dev libavformat-dev libavcodec-dev \
  libswresample-dev libswscale-dev libavutil-dev \
  libfreetype-dev libharfbuzz-dev libfribidi-dev libfontconfig-dev \
  libpulse-dev libx11-dev libwayland-dev libxkbcommon-dev \
  libxkbcommon-x11-0 libvulkan-dev mesa-vulkan-drivers libegl1 \
  libgl1-mesa-dri fonts-dejavu-core pulseaudio-utils

On PipeWire desktops, enable pipewire-pulse. You can check the audio connection with pactl info. WSLg already provides a PulseAudio service.

Build and run#

shell

git clone https://github.com/AimesSoft/liberika.git
cd liberika
git checkout v0.3.0
bash scripts/build_linux_libass.sh
cargo build --locked --release -p linux_native_demo -p erika_capi
cargo run --locked --release -p linux_native_demo -- /path/to/video.mkv

libass uses liberika's patched version of 0.17.5; the build script downloads it, verifies it, and applies the font fallback patch. FFmpeg 8 and PulseAudio link dynamically against system libraries by default. Build outputs are in target/release/.

The demo selects the window protocol automatically; you can also pass --x11 or --wayland. Press Space to pause or resume, the left and right arrow keys to seek 5 seconds, and Esc to exit.

Flutter integration#

shell

cargo build --locked --release -p erika_capi
export ERIKA_LIBRARY_DIR="${CARGO_TARGET_DIR:-$PWD/target}/release"
# Run in the Flutter host directory:
flutter build linux --release

Add erika_flutter: ^0.3.0 to the host app. ErikaVideoView and ErikaTextureVideoView use an SDR RGBA texture and support Flutter clipping and UI overlays; this path requires a per-frame GPU readback.

On Wayland you can optionally use ErikaWindowOverlayVideoView, which places the native video under the transparent Flutter UI with wl_subsurface to reduce per-frame RGBA readback. Leave the video area transparent. This native layer supports opaque srcOver compositing, and the video itself does not accept Flutter clipping or color filters. X11 uses the texture views.

Rust and C/C++ integration#

A Rust host enables the wgpu feature of erika. A C host links liberika_capi.so and uses the erika.h from the same build.

surface kindraw_windowraw_display
ErikaWgpuSurfaceKind_XlibWindowX11 Window integer IDDisplay*
ErikaWgpuSurfaceKind_WaylandSurfacewl_surface*wl_display*

Attach a window with erika_presenter_attach_wgpu_surface. Convert pointers to uint64_t through uintptr_t, and pass the width and height in physical pixels. Release the window and display only after detach completes or the presenter is destroyed. Run attach, render, resize, and detach for the same presenter serially on the window event thread.

Call order: create → attach → open → play → render_tick → close → detach → destroy. A runnable C example is at examples/linux_native_demo/capi_smoke.c.

Decoding and the GPU path#

On Linux, liberika tries NVIDIA NVDEC first, then Intel / AMD VA-API. If the driver or format is not supported, it falls back to FFmpeg software decoding.

shell

export ERIKA_HWDEC=auto  # auto / cuda / nvdec / vaapi / software
# On multi-GPU machines you can pick a device:
export ERIKA_CUDA_DEVICE=0
export ERIKA_VAAPI_DEVICE=/dev/dri/renderD128

The regular NVDEC path downloads the decoded planes and then uploads them to wgpu. Direct import from VA-API to Vulkan is experimental. Linux HDR requires the compositor to actually provide an FP16 extended-linear WSI surface; Flutter RGBA texture output is SDR.

WSLg#

shell

bash scripts/run_wsl_gpu.sh --wayland /mnt/c/path/to/video.mkv
# Or with X11:
bash scripts/run_wsl_gpu.sh --x11

The launch script selects wgpu → OpenGL/EGL → Mesa D3D12 for the liberika process. WSL uses the Windows GPU driver, so you do not need to install a Linux NVIDIA kernel driver. If the repository is under /mnt/c, put CARGO_TARGET_DIR on the Linux filesystem to speed up builds.

Verification#

shell

bash scripts/check_linux.sh
# Also check Wayland:
ERIKA_TEST_WAYLAND=1 bash scripts/check_linux.sh

The check requires working display and audio services. It covers play, pause, seek, resize, and the C ABI lifecycle.
