Linux アクセス

Linux / X11 / Wayland / WSLg

0.2.1 実験的な Linux サポートを追加: Rust、C/C++、および Flutter ホストは、X11 または Wayland を介してビデオを表示し、PulseAudio を介してオーディオを出力できます。 Linux は現在ソース コードからビルドされており、プリコンパイルされたリリース パッケージはありません。

  • 依存する FFmpeg 8.x
  • 窓 X11 / Wayland
  • オーディオ PulseAudio

依存する準備をする#

次の依存関係コマンドは、Ubuntu 26.04 に適用されます。 Rust には 1.92 以降が必要です。 Ubuntu 22.04 / 24.04 デフォルト リポジトリ内の古いバージョンの FFmpeg は、このビルド パスを満たしていません。

Ubuntu 26.04

sudo apt update
sudo apt install -y \
  build-essential pkg-config clang libclang-dev rustc cargo rustfmt \
  curl ca-certificates meson ninja-build patch xz-utils python3 \
  libavdevice-dev libavfilter-dev libavformat-dev libavcodec-dev \
  libswresample-dev libswscale-dev libavutil-dev \
  libfreetype-dev libharfbuzz-dev libfribidi-dev libfontconfig-dev \
  libpulse-dev libx11-dev libwayland-dev libxkbcommon-dev \
  libxkbcommon-x11-0 libvulkan-dev mesa-vulkan-drivers libegl1 \
  libgl1-mesa-dri fonts-dejavu-core pulseaudio-utils

PipeWire デスクトップを有効にする必要があります pipewire-pulse。利用可能 pactl info オーディオ接続を確認してください。 WSLg は PulseAudio サービスを提供しました。

構築して実行する#

shell

git clone https://github.com/AimesSoft/liberika.git
cd liberika
git checkout v0.3.0
bash scripts/build_linux_libass.sh
cargo build --locked --release -p linux_native_demo -p erika_capi
cargo run --locked --release -p linux_native_demo -- /path/to/video.mkv

libass は liberika パッチ バージョン 0.17.5 を使用し、ビルド スクリプトはフォント フォールバック パッチのダウンロード、検証、および適用を担当します。 FFmpeg 8 および PulseAudio は、デフォルトでシステム ライブラリを動的にリンクします。製品は次の場所にあります target/release/。

Demo はウィンドウ プロトコルを自動的に選択します。これを渡すこともできます。 --x11 または --wayland。スペースで一時停止または続行、左右の矢印で 5 秒間ジャンプ、Esc で終了します。

Flutter アクセス#

shell

cargo build --locked --release -p erika_capi
export ERIKA_LIBRARY_DIR="${CARGO_TARGET_DIR:-$PWD/target}/release"
# 在 Flutter 宿主目录中执行：
flutter build linux --release

ホストが追加されました erika_flutter: ^0.3.0。ErikaVideoView と ErikaTextureVideoView SDR RGBA テクスチャを使用すると、Flutter トリミングと UI オーバーレイがサポートされます。このパスには、フレームごとの GPU リードバックが必要です。

Wayland オプション ErikaWindowOverlayVideoView、使用します wl_subsurface フレームごとの RGBA リードバックを減らすために、ネイティブ ビデオを透明な Flutter UI の下に置きます。ビデオ領域は透明のままにしておく必要があります。このネイティブ レイヤーは不透明な srcOver をサポートしており、ビデオ自体は Flutter トリミングやカラー フィルターを受け入れません。 X11 はテクスチャ ビューを使用します。

Rust および C/C++ アクセス#

Rust ホストが有効になりました erika の wgpu feature。 C ホストリンク liberika_capi.so、同じビルドを使用 erika.h。

surface kindraw_windowraw_display
ErikaWgpuSurfaceKind_XlibWindowX11 Window 整数 IDDisplay*
ErikaWgpuSurfaceKind_WaylandSurfacewl_surface*wl_display*

パス erika_presenter_attach_wgpu_surface 付属の窓。ポインタ uintptr_t に変換する uint64_t、幅と高さは物理ピクセルを送信します。 display を持つウィンドウは、detach または presenter が破棄された後に解放されます。同じ presenter の attach、render、resize、detach は、ウィンドウ イベント スレッドでシリアルに実行されます。

呼び出しシーケンス:create → attach → open → play → render_tick → close → detach → destroy。実行可能な C の例は次の場所にあります。 examples/linux_native_demo/capi_smoke.c。

GPU パスでデコードする#

Linux は、デフォルトで NVIDIA NVDEC を試行し、次に Intel / AMD VA-API を試行します。ドライバーまたは形式がサポートされていない場合は、FFmpeg ソフトウェアデコードにフォールバックします。

shell

export ERIKA_HWDEC=auto  # auto / cuda / nvdec / vaapi / software
# 多显卡机器可指定：
export ERIKA_CUDA_DEVICE=0
export ERIKA_VAAPI_DEVICE=/dev/dri/renderD128

通常の NVDEC パスでは、デコード済みプレーンをダウンロードして wgpu にアップロードできます。VA-API から Vulkan への直接インポートは実験的です。Linux の HDR には、コンポジターが FP16 extended-linear WSI サーフェスを提供する必要があります。Flutter の RGBA テクスチャ出力は SDR です。

WSLg#

shell

bash scripts/run_wsl_gpu.sh --wayland /mnt/c/path/to/video.mkv
# 或使用 X11：
bash scripts/run_wsl_gpu.sh --x11

起動スクリプトは liberika プロセスに wgpu → OpenGL/EGL → Mesa D3D12 を選択します。WSL は Windows の GPU ドライバーを使うため、Linux の NVIDIA カーネルドライバーは不要です。リポジトリが /mnt/c にある場合、CARGO_TARGET_DIR を Linux ファイルシステムに置くとビルドを高速化できます。

実行チェック#

shell

bash scripts/check_linux.sh
# 同时检查 Wayland：
ERIKA_TEST_WAYLAND=1 bash scripts/check_linux.sh

このチェックには、再生、一時停止、seek、resize、および C ABI ライフサイクルをカバーする、利用可能なディスプレイ サービスとオーディオ サービスが必要です。
