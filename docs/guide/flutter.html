Flutter 嵌入

Flutter Embedding

erika_flutter 是 Erika 的官方 Flutter 插件，支持 macOS、iOS、tvOS、Windows、Android、OpenHarmony，并提供实验性 Linux 插件。插件提供完整的播放控制、多轨管理、弹幕与字幕渲染、ArtCNN 超分以及三种视图组件。

  • 目标平台 7 个
  • 视图组件 3 款
  • Dart SDK ≥ 3.5

依赖与安装インストール#

pubspec.yaml

dependencies:
  erika_flutter: ^0.2.1

运行 flutter pub get 即可。Apple、Windows、Android 与 OpenHarmony 构建会自动下载匹配的预编译内核。Linux 需先构建本地动态库并设置 ERIKA_LIBRARY_DIR，步骤收录在 Linux 接入。若需要从本地源码构建，设置环境变量 ERIKA_FORCE_SOURCE_BUILD=1 并指定 ERIKA_REPO_ROOT 即可。例外：在 Erika 仓库内使用 macOS 插件时，检测到 crates/erika_capi 会自动改走源码编译（无需 Rust 工具链的仓库内场景可设 ERIKA_FORCE_PREBUILT=1 强制使用预编译包）。

视图选择ビューの選択#

插件提供三个渲染视图组件：

视图组件底层机制推荐场景
ErikaWindowOverlayVideoView原生子窗口 / 原生 Overlay 图层Apple / Windows 的原生呈现；Linux Wayland 使用原生视频层，视频区域需保持透明。
ErikaTextureVideoViewFlutter Texture：macOS 使用 IOSurface + Metal，Windows 使用共享 D3D11 纹理，OpenHarmony 使用外部纹理，Linux 使用 RGBA 读回；其他平台回退 ErikaVideoView。macOS / Windows / OpenHarmony / Linux 上需要 Opacity、裁剪、变换、颜色滤镜等 Flutter 合成效果时使用。
ErikaVideoView统一跨平台视图：macOS/iOS PlatformView、Windows 原生窗口、Android TextureView/SurfaceView、OpenHarmony 外部纹理、Linux RGBA 纹理。通用播放入口。需要 Flutter 裁剪、颜色滤镜时优先选择 Texture；Windows Texture 输出 SDR。

基础使用示例

import 'package:flutter/material.dart';
import 'package:erika_flutter/erika_flutter.dart';

class VideoScreen extends StatefulWidget {
  const VideoScreen({super.key});

  @override
  State<VideoScreen> createState() => _VideoScreenState();
}

class _VideoScreenState extends State<VideoScreen> {
  final _player = ErikaPlayer();

  @override
  void initState() {
    super.initState();
    _initPlayer();
  }

  Future<void> _initPlayer() async {
    /* 1. 同步打开媒体（解析轨道与时长，状态置为 Ready） */
    await _player.open(
      'https://example.com/movie.mp4',
      httpHeaders: {'User-Agent': 'FlutterApp/1.0'},
    );
    /* 2. 启动异步解码与播放 */
    await _player.play();
  }

  @override
  void dispose() {
    _player.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: AspectRatio(
          aspectRatio: 16 / 9,
          child: ErikaVideoView(player: _player),
        ),
      ),
    );
  }
}

透明视频与混合模式透明動画とブレンドモード#

透明视频按 player 请求：ErikaVideoAlphaMode.packedAlphaRight 要求左右分区的编码素材——左半是颜色、右半是灰度 alpha 蒙版。GPU 呈现着色器（Metal / wgpu / D3D11）会重建预乘 alpha 的画面，视频以编码宽度的一半呈现。未请求该模式的 player 仍按不透明解释画面，既有内容不受影响。混合与不透明度在视频 widget 上传入。

透明视频示例

final player = ErikaPlayer(
  videoAlphaMode: ErikaVideoAlphaMode.packedAlphaRight,
);

ErikaTextureVideoView(
  player: player,
  blendMode: BlendMode.overlay,
  opacity: 0.8,
)
平台与路径blendModeopacity
macOS · ErikaTextureVideoView（Flutter Texture）仅 srcOver；其他值改走原生层由 Core Animation 混合Flutter Opacity
macOS · 原生层（blendMode ≠ srcOver）支持 overlay（背景感知）；其他值忽略原生 CALayer opacity
Windows · ErikaTextureVideoView（SDR）srcOver；overlay 改走原生合成层Flutter Opacity
Linux · Flutter 纹理 / Wayland 原生层纹理走 Flutter 合成；原生层仅不透明 srcOver纹理支持 Flutter Opacity；原生层固定不透明
Windows · 窗口 Overlay（DirectComposition）srcOver / overlay；其他值抛插件错误IDCompositionEffectGroup opacity
Android / iOS / OpenHarmony接受创建参数但不消费Texture 路径上由 Flutter 侧应用

Windows 透明/overlay 窗口 Overlay 视频不再使用独立不透明弹窗，而是通过绑定到 Flutter HWND 的预乘 alpha DirectComposition swap chain 直接合成，底层 Flutter 或游戏画面保持可见；HDR 片源会在 Erika 内部 tone map 到该 SDR 合成空间。不透明视频仍沿用原有子 HWND 路径。

事件监听イベント購読#

监听播放器事件流

_player.events.listen((event) {
  switch (event.kind) {
    case ErikaEventKind.stateChanged:
      debugPrint('播放状态: ${event.state}');
    case ErikaEventKind.durationChanged:
      debugPrint('总时长: ${event.duration}');
    case ErikaEventKind.positionChanged:
      debugPrint('当前进度: ${event.position}');
    case ErikaEventKind.bufferingChanged:
      debugPrint('缓冲状态: ${event.buffering}');
    case ErikaEventKind.error:
      debugPrint('播放错误: ${event.error ?? event.message}');
    default:
      break;
  }
});

HTTP 缓存#

httpReadAheadBytes 决定向前预读的字节数，默认 2 MiB；httpBackBufferBytes 决定保留多少已播放数据，默认 16 MiB。两者省略或传 0 使用默认值。预读默认值也可由 ERIKA_HTTP_READAHEAD_BYTES 设置。

回退缓存内的后退 seek 可直接复用已下载数据。高码率视频需要更大的预算：80 Mbit/s 的视频保留约 10 秒需约 100 MB。缓存按字节限制，不代表固定的播放秒数。

Dart

await player.open(
  'https://example.com/video.mp4',
  httpReadAheadBytes: 8 * 1024 * 1024,
  httpBackBufferBytes: 128 * 1024 * 1024,
);
await player.play();

导出 GIF#

ErikaPlayer.exportGif() 使用独立的无头管线，不需要视频视图，也不影响当前播放。传入片段起止时间、帧率和输出尺寸：

Dart

final result = await ErikaPlayer.exportGif(
  ErikaGifExportOptions(
    inputUri: '/path/input.mp4',
    outputPath: '/path/output.gif',
    start: const Duration(seconds: 5),
    end: const Duration(seconds: 10),
    framesPerSecond: 10,
    outputWidth: 640,
    outputHeight: 360,
    quality: ErikaGifExportQuality.high,
  ),
);
