Flutter 嵌入

Flutter Embedding

erika_flutter 是 Erika 的官方 Flutter 插件，支持 macOS、iOS、tvOS、Windows、Android 与 HarmonyOS 六个平台。插件提供完整的播放控制、多轨管理、弹幕与字幕渲染、ArtCNN 超分以及两种视图呈现方案。

  • 目标平台 6 个
  • 视图组件 2 款
  • Dart SDK ≥ 3.5

依赖与安装インストール#

pubspec.yaml

dependencies:
  erika_flutter: ^0.1.7

运行 flutter pub get 即可。构建时插件会自动下载与当前平台匹配的预编译原生二进制。若需要从本地源码构建，设置环境变量 ERIKA_FORCE_SOURCE_BUILD=1 并指定 ERIKA_REPO_ROOT 即可。例外：在 Erika 仓库内使用 macOS 插件时，检测到 crates/erika_capi 会自动改走源码编译（无需 Rust 工具链的仓库内场景可设 ERIKA_FORCE_PREBUILT=1 强制使用预编译包）。

视图选择ビューの選択#

插件提供两个渲染视图组件：

视图组件底层机制推荐场景
ErikaWindowOverlayVideoView原生子窗口 / 原生 Overlay 图层macOS / iOS / tvOS / Windows 推荐，原生 60/120fps 极低开销与高帧率。
ErikaTextureVideoViewFlutter Texture：macOS 走 IOSurface + Metal 直写（无逐帧 CPU 回读），OpenHarmony 复用外部纹理；其余平台回退 ErikaVideoView。macOS / OpenHarmony 上需要 Opacity、裁剪、变换、颜色滤镜等 Flutter 合成效果时使用。
ErikaVideoView统一跨平台视图：macOS/iOS PlatformView、Windows Overlay、Android TextureView/SurfaceView、HarmonyOS 外部纹理。全部 6 平台可用。开箱即用，支持被 Flutter 复杂控件（如圆角裁剪、半透明蒙层）正常层叠。

基础使用示例

import 'package:flutter/material.dart';
import 'package:erika_flutter/erika_flutter.dart';

class VideoScreen extends StatefulWidget {
  const VideoScreen({super.key});

  @override
  State<VideoScreen> createState() => _VideoScreenState();
}

class _VideoScreenState extends State<VideoScreen> {
  final _player = ErikaPlayer();

  @override
  void initState() {
    super.initState();
    _initPlayer();
  }

  Future<void> _initPlayer() async {
    /* 1. 同步打开媒体（解析轨道与时长，状态置为 Ready） */
    await _player.open(
      'https://example.com/movie.mp4',
      httpHeaders: {'User-Agent': 'FlutterApp/1.0'},
    );
    /* 2. 启动异步解码与播放 */
    await _player.play();
  }

  @override
  void dispose() {
    _player.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: AspectRatio(
          aspectRatio: 16 / 9,
          child: ErikaVideoView(player: _player),
        ),
      ),
    );
  }
}

透明视频与混合模式透明動画とブレンドモード#

透明视频按 player 请求：ErikaVideoAlphaMode.packedAlphaRight 要求左右分区的编码素材——左半是颜色、右半是灰度 alpha 蒙版。GPU 呈现着色器（Metal / wgpu / D3D11）会重建预乘 alpha 的画面，视频以编码宽度的一半呈现。未请求该模式的 player 仍按不透明解释画面，既有内容不受影响。混合与不透明度在视频 widget 上传入。

透明视频示例

final player = ErikaPlayer(
  videoAlphaMode: ErikaVideoAlphaMode.packedAlphaRight,
);

ErikaTextureVideoView(
  player: player,
  blendMode: BlendMode.overlay,
  opacity: 0.8,
)
平台与路径blendModeopacity
macOS · ErikaTextureVideoView（Flutter Texture）仅 srcOver；其他值改走原生层由 Core Animation 混合Flutter Opacity
macOS · 原生层（blendMode ≠ srcOver）支持 overlay（背景感知）；其他值忽略原生 CALayer opacity
Windows · 窗口 Overlay（DirectComposition）srcOver / overlay；其他值抛插件错误IDCompositionEffectGroup opacity
Android / iOS / OpenHarmony接受创建参数但不消费Texture 路径上由 Flutter 侧应用

Windows 透明/overlay 窗口 Overlay 视频不再使用独立不透明弹窗，而是通过绑定到 Flutter HWND 的预乘 alpha DirectComposition swap chain 直接合成，底层 Flutter 或游戏画面保持可见；HDR 片源会在 Erika 内部 tone map 到该 SDR 合成空间。不透明视频仍沿用原有子 HWND 路径。

事件监听イベント購読#

监听播放器事件流

_player.events.listen((event) {
  switch (event.kind) {
    case ErikaEventKind.stateChanged:
      debugPrint('播放状态: ${event.state}');
    case ErikaEventKind.durationChanged:
      debugPrint('总时长: ${event.duration}');
    case ErikaEventKind.positionChanged:
      debugPrint('当前进度: ${event.position}');
    case ErikaEventKind.bufferingChanged:
      debugPrint('缓冲状态: ${event.buffering}');
    case ErikaEventKind.error:
      debugPrint('播放错误: ${event.error ?? event.message}');
    default:
      break;
  }
});
