Flutter 嵌入

Flutter Embedding

erika_flutter 是 Erika 的官方 Flutter 插件，支持 macOS、iOS、tvOS、Windows、Android 与 HarmonyOS 六个平台。插件提供完整的播放控制、多轨管理、弹幕与字幕渲染、ArtCNN 超分以及两种视图呈现方案。

  • 目标平台 6 个
  • 视图组件 2 款
  • Dart SDK ≥ 3.5

依赖与安装インストール#

pubspec.yaml

dependencies:
  erika_flutter: ^0.1.7

运行 flutter pub get 即可。构建时插件会自动下载与当前平台匹配的预编译原生二进制。若需要从本地源码构建，设置环境变量 ERIKA_FORCE_SOURCE_BUILD=1 并指定 ERIKA_REPO_ROOT 即可。

视图选择ビューの選択#

插件提供两个渲染视图组件：

视图组件底层机制推荐场景
ErikaWindowOverlayVideoView原生子窗口 / 原生 Overlay 图层macOS / iOS / tvOS / Windows 推荐，原生 60/120fps 极低开销与高帧率。
ErikaVideoViewFlutter PlatformView / 外部纹理（TextureView / SurfaceProducer）通用兼容模式，或需要被 Flutter 复杂控件（如透明遮罩、翻转动画）裁剪时使用。

基础使用示例

import 'package:flutter/material.dart';
import 'package:erika_flutter/erika_flutter.dart';

class VideoScreen extends StatefulWidget {
  const VideoScreen({super.key});

  @override
  State<VideoScreen> createState() => _VideoScreenState();
}

class _VideoScreenState extends State<VideoScreen> {
  final _player = ErikaPlayer();

  @override
  void initState() {
    super.initState();
    _initPlayer();
  }

  Future<void> _initPlayer() async {
    /* 打开媒体并自动播放 */
    await _player.open(
      'https://example.com/movie.mp4',
      headers: {'User-Agent': 'FlutterApp/1.0'},
      play: true,
    );
  }

  @override
  void dispose() {
    _player.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: AspectRatio(
          aspectRatio: 16 / 9,
          child: ErikaWindowOverlayVideoView(player: _player),
        ),
      ),
    );
  }
}

事件监听イベント購読#

监听播放器事件流

_player.events.listen((event) {
  switch (event) {
    case ErikaStateChangedEvent(:final state):
      debugPrint('播放状态: $state');
    case ErikaDurationChangedEvent(:final duration):
      debugPrint('总时长: $duration');
    case ErikaPositionChangedEvent(:final position):
      debugPrint('当前进度: $position');
    case ErikaBufferingChangedEvent(:final isBuffering):
      debugPrint('缓冲状态: $isBuffering');
    case ErikaErrorEvent(:final message):
      debugPrint('播放错误: $message');
    default:
      break;
  }
});
