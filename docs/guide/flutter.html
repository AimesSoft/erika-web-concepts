Flutter 嵌入

Flutter Embedding

插件 erika_flutter 覆盖 macOS / iOS / tvOS / Windows / Android / HarmonyOS 六个目标。播放器 API 与原生侧一一对应，视图提供两条路径：platform view 用于兼容与诊断，原生 window overlay 是 macOS / iOS / tvOS 的推荐路径。

  • 目标 6 平台
  • 视图路径 2 条
  • Dart SDK ≥3.5

依赖依存#

pubspec.yaml

dependencies:
  erika_flutter:
    git:
      url: https://github.com/AimesSoft/Erika
      path: packages/erika_flutter

环境要求：Dart SDK ≥ 3.5.0，Flutter ≥ 3.24.0。构建时默认从源码编译原生库；设置 ERIKA_PREBUILT=1 后改用预编译运行时，下载失败自动回退源码构建。Android 与 HarmonyOS 的预编译消费方式见发布与产物。

播放器 APIプレイヤー API#

lib/main.dart

final player = ErikaPlayer();
await player.open('/path/to/video.mp4');
await player.play();

await player.seek(Duration(seconds: 30));
await player.setPlaybackRate(1.25);
await player.setVolume(0.8);

await player.dispose();

方法与 C ABI 的 presenter 面一一对应：

分组方法
播放控制open / play / pause / stop / close / seek / setPlaybackRate / setVolume
字幕addExternalSubtitle / removeSubtitleTrack / selectSubtitleTrack / setSubtitleScale / setSubtitleStyle / registerSubtitleMemoryFont / selectSubtitleMemoryFonts / clearSubtitleMemoryFonts / getSubtitleMemoryFontStatus
弹幕loadDanmakuFile / loadDanmakuJson / addDanmakuTrackFile / addDanmakuTrackJson / removeDanmakuTrack / setDanmakuTrackEnabled / setDanmakuTrackOffset / setDanmakuGlobalOffset / clearDanmaku / setDanmakuEnabled / setDanmakuConfig
输出setUpscaler / getUpscalerStatus / getOutputStatus / getResourceStatus / getPresenterStats / setDebugHudEnabled
系统媒体setMediaMetadata / setSystemMediaNavigation
视图attachView / detachView / createTextureSurface / resizeTextureSurface / releaseTextureSurface / attachWindowOverlay / detachWindowOverlay / setWindowOverlayFrame

ErikaMediaMetadata 携带标题、艺术家、专辑与封面，经系统媒体控制（Now Playing）呈现。后台音频播放时挂起视频解码，见更新日志 0.1.5。

视图路径ビュー#

组件机制适用
ErikaVideoViewFlutter platform view（Android 为原生 TextureView / SurfaceView）或外部纹理（HarmonyOS）。兼容与诊断路径，所有平台可用。
ErikaWindowOverlayVideoView原生 window overlay（Apple / Windows）。macOS / iOS / tvOS 推荐路径，完整播放器 UI。

推荐：原生 overlay 路径

ErikaWindowOverlayVideoView(player: player)

兼容 / 诊断：platform view 路径

ErikaVideoView(player: player)

desktop 的 overlay API 支持多窗口与次窗口定位，播放器在宿主窗口间迁移时保持表面、可见性、代际与 aspect-fit 状态。

事件イベント#

播放器状态经 ErikaPlayerEvent 发布，与原生事件一一对应：状态、时长、位置、轨道、缓冲、视频参数、解码器、音频输出、错误等。事件载荷类型（ErikaTrackInfo、ErikaVideoParams、ErikaVideoDecoderInfo 等）镜像 erika.h 的结构体。

平台差异プラットフォーム#

  • Android 与 HarmonyOS 的 surface 策略不同：Android 使用 Flutter platform view 内的原生 TextureView（SDR 路径，HDR 路径改用 SurfaceView），HarmonyOS 使用 Flutter 外部纹理（TextureRegistry）。插件内部按平台选择，宿主代码一致。
  • tvOS 插件实现了 window overlay（与 iOS 同族的原生 ErikaWindowOverlayView）；Dart 侧没有独立的 TargetPlatform.tvOS，沿用 iOS 平台语义。
  • 系统媒体控制（Now Playing）在 iOS、tvOS、macOS、Android、Windows、HarmonyOS 六平台可用。
