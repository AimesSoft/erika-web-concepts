OpenHarmony / OHPM 接入

Native ArkTS SDK

erika 是 OpenHarmony 原生 ArkTS SDK。应用通过 XComponent 获取原生 surface，使用 ErikaPlayer 驱动播放控制、事件处理与每帧渲染调度。

  • 公开版 erika 0.1.9
  • 目标架构 arm64
  • 最低 API API 18

安装与引入インストール#

在 DevEco Studio 项目根目录安装公开版 0.1.9（0.2.1 已提交审核）：

shell

ohpm install erika

包详情见 OHPM 详情页；源码模块参见官方仓库的 packages/erika_ohos 目录。

表面生命周期与控制器サーフェス制御#

ErikaPlayer 封装了底层 Presenter 实例。宿主在 XComponentController 回调中绑定原生 surface 并进行尺寸同步：

ErikaSurfaceController.ets

import { ErikaNativeResponse, ErikaPlayer } from 'erika';

export class ErikaSurfaceController extends XComponentController {
  private readonly player: ErikaPlayer = new ErikaPlayer();
  private attached: boolean = false;
  private pendingUri: string = '';

  onSurfaceCreated(surfaceId: string): void {
    /* 记录表面创建 */
  }

  onSurfaceChanged(surfaceId: string, rect: SurfaceRect): void {
    if (!this.attached) {
      this.player.attachSurface({
        surfaceId: BigInt(surfaceId),
        width: rect.surfaceWidth,
        height: rect.surfaceHeight,
        scale: 1.0,
      });
      this.attached = true;
    } else {
      this.player.resizeSurface(rect.surfaceWidth, rect.surfaceHeight, 1.0);
    }
    this.startPendingPlay();
  }

  onSurfaceDestroyed(_surfaceId: string): void {
    if (this.attached) {
      this.player.detachSurface();
      this.attached = false;
    }
    this.player.dispose();
  }

  openAndPlay(uri: string): void {
    this.pendingUri = uri;
    this.startPendingPlay();
  }

  renderFrame(timeSeconds: number): ErikaNativeResponse {
    return this.player.renderTick(timeSeconds);
  }

  private startPendingPlay(): void {
    if (!this.attached || this.pendingUri.length === 0) {
      return;
    }
    const uri: string = this.pendingUri;
    this.pendingUri = '';
    this.player.open(uri);
    this.player.play();
  }
}

在 ArkUI 页面中使用ArkUI 連携#

Index.ets

import { ErikaSurfaceController } from './ErikaSurfaceController';

@Entry
@Component
struct VideoPlayerPage {
  private readonly controller: ErikaSurfaceController = new ErikaSurfaceController();
  private timerId: number = -1;

  aboutToAppear(): void {
    /* 简化示例：用定时器调用 renderTick，应用可改用显示帧回调 */
    let startTime = Date.now();
    this.timerId = setInterval(() => {
      const nowSeconds = (Date.now() - startTime) / 1000.0;
      this.controller.renderFrame(nowSeconds);
    }, 16);
  }

  aboutToDisappear(): void {
    if (this.timerId !== -1) {
      clearInterval(this.timerId);
      this.timerId = -1;
    }
  }

  build() {
    Column() {
      XComponent({
        id: 'erika_video_surface',
        type: XComponentType.SURFACE,
        controller: this.controller,
      })
        .width('100%')
        .aspectRatio(1.777)
        .onLoad(() => {
          this.controller.openAndPlay('https://example.com/stream.mp4');
        })
    }
    .width('100%')
    .height('100%')
  }
}

ArkTS ErikaPlayer 公开 API公開 API#

分类方法功能说明
播放控制open(uri) / play() / pause() / stop() / close() / seek(positionMicros) / setPlaybackRate(rate) / setVolume(volume)打开媒体源、播放、暂停、跳转进度（微秒）、调节倍速与音量。
表面管理attachSurface(options) / resizeSurface(w, h, scale) / detachSurface()绑定 XComponent 原生表面，同步像素尺寸，释放表面。
渲染调度renderTick(timeSeconds) / audioOnlyTick() / pollEvent()驱动显示时钟渲染帧、音频无画面调度与轮询状态事件。
附加能力captureFrame(w, h) / registerSubtitleMemoryFont(bytes) / dispose()抓取当前帧像素、注册内存字幕字体与销毁播放器实例。

0.2.1 HTTP 缓存选项#

截至 2026-10-02，OHPM 公开版本为 0.1.9，0.2.1 已提交审核。下面的回退缓存参数属于 0.2.1 SDK；审核期间可从 Erika 仓库的 0.2.1 源码构建 HAR。

httpReadAheadBytes 决定向前预读的字节数，默认 2 MiB；httpBackBufferBytes 决定保留多少已播放数据，默认 16 MiB。两者省略或传 0 使用默认值。预读默认值也可由 ERIKA_HTTP_READAHEAD_BYTES 设置。

回退缓存内的后退 seek 可直接复用已下载数据。高码率视频需要更大的预算：80 Mbit/s 的视频保留约 10 秒需约 100 MB。缓存按字节限制，不代表固定的播放秒数。

ArkTS

player.open('https://example.com/video.mp4', {
  httpReadAheadBytes: 8 * 1024 * 1024,
  httpBackBufferBytes: 128 * 1024 * 1024,
});
player.play();
