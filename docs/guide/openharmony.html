OpenHarmony / OHPM 接入

Native ArkTS SDK

erika 是独立的 OpenHarmony 原生 ArkTS SDK，不依赖 Flutter。应用通过 XComponent 提供呈现表面，使用 ErikaPlayer 驱动播放、生命周期和每帧渲染。

  • 包 erika 0.1.7
  • 目标 arm64
  • 最低 API 18
  • 依赖 Flutter 无

安装インストール#

shell

ohpm install erika

包详情见 OHPM；源码包说明见仓库的 packages/erika_ohos/README.md。

表面生命周期サーフェスのライフサイクル#

ErikaPlayer 不创建 ArkUI 组件。宿主在 XComponentController 回调中附着、调整大小和释放原生 surface：

ErikaSurfaceController.ets

import { ErikaNativeResponse, ErikaPlayer } from 'erika';

class ErikaSurfaceController extends XComponentController {
  private readonly player: ErikaPlayer = new ErikaPlayer();
  private attached: boolean = false;
  private pendingUri: string = '';

  onSurfaceCreated(surfaceId: string): void {
    console.info(`Erika XComponent surface created: ${surfaceId}`);
  }

  onSurfaceChanged(surfaceId: string, rect: SurfaceRect): void {
    if (!this.attached) {
      this.player.attachSurface({
        surfaceId: BigInt(surfaceId),
        width: rect.surfaceWidth,
        height: rect.surfaceHeight,
        scale: 1.0,
      });
      this.attached = true;
    } else {
      this.player.resizeSurface(rect.surfaceWidth, rect.surfaceHeight);
    }
    this.startPendingUri();
  }

  onSurfaceDestroyed(_surfaceId: string): void {
    if (this.attached) {
      this.player.detachSurface();
      this.attached = false;
    }
    this.player.dispose();
  }

  open(uri: string): void {
    this.pendingUri = uri;
    this.startPendingUri();
  }

  renderFrame(timeSeconds: number): ErikaNativeResponse {
    return this.player.renderTick(timeSeconds);
  }

  private startPendingUri(): void {
    if (!this.attached || this.pendingUri.length === 0) {
      return;
    }
    const uri: string = this.pendingUri;
    this.pendingUri = '';
    this.player.open(uri);
    this.player.play();
  }
}

播放控制再生制御#

在 surface 可用后调用播放器方法。open() 发起打开请求，随后调用 play()；状态和错误通过返回值或异常检查。示例控制器会在 onSurfaceChanged() 完成 attach 后启动缓存的 URI，因此 onLoad 早于 surface 回调也不会抢跑。

ArkTS

this.player.open('https://example.com/video.mp4');
this.player.play();

this.player.pause();
this.player.seek(positionMicros);

帧调度フレームスケジューリング#

宿主负责把显示帧回调传给 renderTick()。该方法返回 ErikaNativeResponse，可用于读取本帧的状态和诊断信息；不需要视频 surface 时改用 audioOnlyTick()。

host frame scheduler

renderFrame(timeSeconds: number): ErikaNativeResponse {
  return this.player.renderTick(timeSeconds);
}

controller.renderFrame(frameTimeSeconds);

放入 ArkUI 页面ArkUI への組み込み#

Index.ets

@Entry
@Component
struct VideoPage {
  private readonly surfaceController: ErikaSurfaceController =
    new ErikaSurfaceController();

  build() {
    XComponent({
      id: 'erika-surface',
      type: XComponentType.SURFACE,
      controller: this.surfaceController,
    })
      .width('100%')
      .height('100%')
      .onLoad(() => {
        this.surfaceController.open('https://example.com/video.mp4');
      });
  }
}

真实应用应在页面销毁时让控制器完成 detachSurface() 和 dispose()，并把自己的 display-frame callback 接到 renderTick()。

核心 API主要 API#

分组方法用途
播放open / play / pause / stop / close / seek / setPlaybackRate / setVolume播放控制。
表面attachSurface / resizeSurface / detachSurfaceXComponent surface 生命周期。
调度renderTick / audioOnlyTick / pollEvent显示帧、音频帧和事件消费。
输出captureFrame / getOutputStatus / getResourceStatus截图、输出状态和资源诊断。
