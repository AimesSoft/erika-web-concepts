Surface のライフサイクルとコントローラーサーフェスコントロール#

ErikaPlayer 基になる Presenter インスタンスをカプセル化します。ホストは XComponentController コールバックでネイティブ surface をバインドし、サイズを同期します。

ErikaSurfaceController.ets

import { ErikaNativeResponse, ErikaPlayer } from 'erika';

export class ErikaSurfaceController extends XComponentController {
  private readonly player: ErikaPlayer = new ErikaPlayer();
  private attached: boolean = false;
  private pendingUri: string = '';

  onSurfaceCreated(surfaceId: string): void {
    /* 记录表面创建 */
  }

  onSurfaceChanged(surfaceId: string, rect: SurfaceRect): void {
    if (!this.attached) {
      this.player.attachSurface({
        surfaceId: BigInt(surfaceId),
        width: rect.surfaceWidth,
        height: rect.surfaceHeight,
        scale: 1.0,
      });
      this.attached = true;
    } else {
      this.player.resizeSurface(rect.surfaceWidth, rect.surfaceHeight, 1.0);
    }
    this.startPendingPlay();
  }

  onSurfaceDestroyed(_surfaceId: string): void {
    if (this.attached) {
      this.player.detachSurface();
      this.attached = false;
    }
    this.player.dispose();
  }

  openAndPlay(uri: string): void {
    this.pendingUri = uri;
    this.startPendingPlay();
  }

  renderFrame(timeSeconds: number): ErikaNativeResponse {
    return this.player.renderTick(timeSeconds);
  }

  private startPendingPlay(): void {
    if (!this.attached || this.pendingUri.length === 0) {
      return;
    }
    const uri: string = this.pendingUri;
    this.pendingUri = '';
    this.player.open(uri);
    this.player.play();
  }
}

ArkUIページで使用されていますArkUI リンクされました#

Index.ets

import { ErikaSurfaceController } from './ErikaSurfaceController';

@Entry
@Component
struct VideoPlayerPage {
  private readonly controller: ErikaSurfaceController = new ErikaSurfaceController();
  private timerId: number = -1;

  aboutToAppear(): void {
    /* 简化示例：用定时器调用 renderTick，应用可改用显示帧回调 */
    let startTime = Date.now();
    this.timerId = setInterval(() => {
      const nowSeconds = (Date.now() - startTime) / 1000.0;
      this.controller.renderFrame(nowSeconds);
    }, 16);
  }

  aboutToDisappear(): void {
    if (this.timerId !== -1) {
      clearInterval(this.timerId);
      this.timerId = -1;
    }
  }

  build() {
    Column() {
      XComponent({
        id: 'erika_video_surface',
        type: XComponentType.SURFACE,
        controller: this.controller,
      })
        .width('100%')
        .aspectRatio(1.777)
        .onLoad(() => {
          this.controller.openAndPlay('https://example.com/stream.mp4');
        })
    }
    .width('100%')
    .height('100%')
  }
}

分類方法機能説明
再生コントロールopen(uri) / play() / pause() / stop() / close() / seek(positionMicros) / setPlaybackRate(rate) / setVolume(volume)メディア ソースを開いて、再生、一時停止、進行状況 (マイクロ秒単位) のジャンプ、速度と音量の調整を行います。
表面管理attachSurface(options) / resizeSurface(w, h, scale) / detachSurface()XComponent ネイティブ サーフェスをバインドし、ピクセル サイズを同期して、サーフェスを解放します。
レンダリングスケジュールrenderTick(timeSeconds) / audioOnlyTick() / pollEvent()ドライバーは、クロック レンダリング フレーム、オーディオおよび画像のないスケジュール、およびポーリング ステータス イベントを表示します。
追加機能captureFrame(w, h) / registerSubtitleMemoryFont(bytes) / dispose()現在のフレームのピクセルを取得し、メモリの字幕フォントを登録し、プレーヤーのインスタンスを破棄します。

HTTP キャッシュオプション（0.2.1 以降）#

2026 年 10 月 30 日の時点で、OHPM 0.3.0 が公開されており、次の HTTP フォールバック キャッシュ パラメーターが含まれています。

httpReadAheadBytes 前方に読み取るバイト数を決定します。デフォルトは 2 MiB です。httpBackBufferBytes 保持する再生データの量を決定します。デフォルトは 16 MiB です。両方を省略するか、0 を渡してデフォルト値を使用します。先読みのデフォルト値は次のように指定することもできます。 ERIKA_HTTP_READAHEAD_BYTES 設定。

ロールバック キャッシュ内のフォールバック seek は、ダウンロードされたデータを直接再利用できます。高ビットレートのビデオには、より大きな予算が必要です。80 Mbit/s のビデオを約 10 秒保持するには、約 100 MB が必要になります。キャッシュはバイト数によって制限されており、固定の再生秒数を表しません。

ArkTS

player.open('https://example.com/video.mp4', {
  httpReadAheadBytes: 8 * 1024 * 1024,
  httpBackBufferBytes: 128 * 1024 * 1024,
});
player.play();
