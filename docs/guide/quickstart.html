快速开始

Quickstart

Erika 尚未发布到 crates.io；Flutter 插件 erika_flutter 已发布到 pub.dev，OpenHarmony 原生 ArkTS 包 erika 已发布到 OHPM。接入方式包括 GitHub Releases 的预编译归档、以 git 依赖从源码构建、Flutter 项目经 pub.dev 安装插件，或 OpenHarmony 项目经 OHPM 安装。

  • 预编译 6 平台
  • 源码 Rust 1.92+
  • 原生依赖 静态链接

预编译产物プリビルト#

GitHub Releases（github.com/AimesSoft/Erika/releases）按平台提供归档。原生依赖（FFmpeg、libass、FreeType、HarfBuzz、FriBidi、zlib、dav1d）已经以 lgpl profile 静态链接，除操作系统框架外自包含。

归档内容
erika-capi-macos-universal.zipliberika_capi.dylib / .a
erika-capi-windows-x64.ziperika_capi.dll / .dll.lib / .lib
erika-capi-ios.ziperika_capi.xcframework
erika-capi-tvos.ziperika_capi.xcframework
erika-capi-android.zip4 个 ABI 的库 + libc++_shared.so
erika-capi-openharmony-arm64.zipliberika_capi.so + N-API 桥

每个归档含 include/erika.h、许可证文本与记录 tag/commit 的 MANIFEST.txt。Linux 暂未发布。归档的消费方式见发布与产物。

Rust 接入Rust#

Cargo.toml

# 或使用预编译归档的 .a / .dylib 与 erika.h（经 FFI 调用）
[dependencies]
erika = { git = "https://github.com/AimesSoft/Erika", tag = "v0.1.7" }

从源码构建前，先用 xtask 准备原生依赖：

shell

cargo run -p xtask -- deps build --all --profile lgpl

src/main.rs

use erika::{Player, PlayerConfig, MediaRequest};

let player = Player::new(PlayerConfig::default());
player.open(MediaRequest::new("/path/to/video.mp4"))?;
player.play()?;

完整 API 见Rust 嵌入。

C 接入C ABI#

使用预编译归档中的 erika.h 与 liberika_capi。push 模型的最小示例：

main.c

#include "erika.h"

ErikaPresenterHandle *p = erika_presenter_create();
erika_presenter_attach_metal_layer(p, (uint64_t)layer, w, h, scale);
erika_presenter_open(p, "/path/to/video.mp4");
erika_presenter_play(p);

/* 每个显示帧 */
ErikaPresenterStats stats;
erika_presenter_render_tick(p, host_time, &stats);

ErikaPresenterHandle 由内核托管完整播放栈。宿主自行管理渲染循环时改用 ErikaHandle 拉取帧数据。完整对比与约定见C ABI 嵌入。

Flutter 接入Flutter#

pubspec.yaml

dependencies:
  erika_flutter: ^0.1.7   # 或 flutter pub add erika_flutter

shell

export ERIKA_FORCE_SOURCE_BUILD=1   # 默认下载预编译运行时；此变量改为从源码构建

lib/main.dart

final player = ErikaPlayer();
await player.open('/path/to/video.mp4');
await player.play();

插件覆盖 macOS / iOS / tvOS / Windows / Android / HarmonyOS 六个目标。视图路径与完整 API 见Flutter 嵌入。

OpenHarmony / OHPMOpenHarmony#

原生 ArkTS 包 erika 0.1.7 已发布到 OHPM，目标为 OpenHarmony arm64，最低兼容 API 18。宿主通过 XComponent surface 使用 ErikaPlayer。

shell

ohpm install erika

完整的 ArkTS 宿主代码、XComponent 表面生命周期和 renderTick() 帧调度见 OpenHarmony 接入指南；包的发布信息见 OHPM 详情页。
