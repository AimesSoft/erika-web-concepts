快速开始

Quickstart

Erika 提供了面向多种技术栈的接入方式：SwiftPM 包 ErikaSwift、Flutter 插件 erika_flutter、OpenHarmony ArkTS 原生包 erika、Rust 原生 crate 以及标准 C ABI 动态/静态库。

  • 预编译 6 大平台
  • 源码 Rust 1.92+
  • 原生依赖 静态封装

Swift / Apple 原生接入Swift#

在 Xcode 项目中添加 SwiftPM 依赖 https://github.com/AimesSoft/ErikaSwift，通过 Metal 渲染与系统硬解快速起步：

Swift 示例

import ErikaSwift

let player = ErikaPlayer()
try player.open("https://example.com/video.mp4")
try player.play()

详细的 SwiftUI 图层包装与生命周期见 Swift 接入指南。

Flutter 接入Flutter#

pubspec.yaml

dependencies:
  erika_flutter: ^0.1.7

lib/main.dart

final player = ErikaPlayer();
await player.open('/path/to/video.mp4', play: true);

插件覆盖 macOS / iOS / tvOS / Windows / Android / HarmonyOS 六个平台，详见 Flutter 嵌入指南。

OpenHarmony / ArkTSOpenHarmony#

通过 OHPM 安装原生 ArkTS 包，结合 XComponent 表面驱动播放：

shell

ohpm install erika

详细的 ArkTS 页面生命周期与帧调度参见 OpenHarmony 接入指南。

Rust 接入Rust#

Cargo.toml

[dependencies]
erika = { git = "https://github.com/AimesSoft/Erika", tag = "v0.1.7" }

src/main.rs

use erika::{Player, PlayerConfig, MediaRequest};

let player = Player::new(PlayerConfig::default());
player.open(MediaRequest::new("/path/to/video.mp4"))?;
player.play()?;

完整 API 与通道订阅见 Rust 嵌入。

C / C++ ABI 接入C ABI#

通过 erika.h 与预编译 liberika_capi 接入。推荐使用内核托管渲染与音频的 ErikaPresenterHandle：

main.c

#include "erika.h"

ErikaPresenterHandle *p = erika_presenter_create();
erika_presenter_attach_metal_layer(p, (uint64_t)layer, w, h, scale);
erika_presenter_open(p, "https://example.com/video.mp4");
erika_presenter_play(p);

/* 在显示时钟回调中每帧驱动 */
ErikaPresenterStats stats;
erika_presenter_render_tick(p, host_time, &stats);

完整规范与无头 ErikaHandle 对比见 C ABI 嵌入。
