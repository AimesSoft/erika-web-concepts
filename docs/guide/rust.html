Rust 嵌入

Rust Embedding

Rust 宿主直接使用 erika crate 的 Player。播放器持有内部线程与状态机，宿主订阅事件通道感知状态变化，并按需订阅视频、音频与字幕帧。

  • 入口 Player
  • 事件 12 种
  • 帧订阅 3 通道

依赖与构建セットアップ#

Cargo.toml

[dependencies]
erika = { git = "https://github.com/AimesSoft/Erika", tag = "v0.1.5" }

首次构建前准备原生依赖：

shell

cargo run -p xtask -- deps build --all --profile lgpl
cargo build -p erika

播放生命周期ライフサイクル#

src/main.rs

use erika::{Player, PlayerConfig, MediaRequest};

let player = Player::new(PlayerConfig::default())?;
player.open(MediaRequest::file("/path/to/video.mp4"))?;
player.play()?;
player.pause()?;
player.seek(1_500_000)?;   // 微秒
player.set_playback_rate(1.5)?;
player.stop()?;
player.close()?;

方法语义：

  • open 是异步的。返回后媒体尚未就绪，就绪状态经事件通道发布（DurationChanged、TracksChanged、VideoParamsChanged 等）。打开失败时播放器转入 Error 状态。
  • play 只投递命令。最终结果以 StateChanged 或 Error 事件为准。
  • seek 以微秒为单位。暂停期间 seek 会解码并呈现目标位置附近的关键帧，时钟保持冻结。
  • close 先结束内部线程再返回，之后可以安全丢弃播放器。

MediaRequest 支持 HTTP(S) URL 与请求头。构造 MediaRequest::new(uri) 后用 with_http_headers 添加头。Debug 输出对 header 值打码。

事件订阅イベント#

事件循环

let events = player.subscribe();

loop {
  match events.recv() {
    Ok(PlayerEvent::StateChanged(state)) => { /* 更新 UI */ }
    Ok(PlayerEvent::BufferingChanged(b)) => { /* 缓冲指示 */ }
    Ok(PlayerEvent::Error(e)) => { /* 错误处理 */ }
    Ok(PlayerEvent::Closed) => break,
    _ => {}
  }
}

事件通道为 unbounded，容量不受背压影响。事件类型与 C ABI 的 ErikaEventKind 一一对应：

事件触发条件
StateChanged播放状态机迁移。
DurationChanged时长确定或变化。
PositionChanged播放位置推进。
TracksChanged轨道列表变化。
TrackSelectionChanged选中轨道变化。
BufferingChanged缓冲状态切换。
VideoParamsChanged视频参数（尺寸、色彩）变化。
VideoDecoderChanged解码后端切换。
AudioOutputChanged音频输出状态变化。
SurfaceAttached / SurfaceDetached表面附着与分离。
Error错误发生。

帧订阅フレーム#

宿主自行渲染时订阅帧通道。三个通道均为 bounded，容量取 PlayerConfig 中对应的队列配置：

帧拉取

let video = player.subscribe_video_frames();
let audio = player.subscribe_audio_frames();
let subtitles = player.subscribe_subtitle_frames();

loop {
  if let Ok(frame) = video.try_recv() {
    /* 上传纹理并呈现 */
  }
  /* 每 10 ms 轮询一次，或 select 多个通道 */
}

队列满时新帧被丢弃，播放继续。需要推模型（内核托管渲染）时使用 presenter，Rust 侧入口为 Presenter，C 宿主经 ErikaPresenterHandle 使用同一实现。

配置项設定#

PlayerConfig 的默认值与字段：

字段默认含义
name"Erika"播放器实例名，用于线程命名与诊断。
event_channel_capacity1024事件通道容量。
rendererAuto渲染后端偏好。
video_frame_queue_capacity3视频帧队列深度。
audio_frame_queue_capacity192音频帧队列深度。
subtitle_frame_queue_capacity16字幕帧队列深度，带下限常量。

Player 实现了 Clone，克隆体共享同一播放会话，可用于向多个持有者分发事件。

错误处理エラー#

方法返回 Result<(), PlayerError>。错误分两类：

  • PlayerError::Closed — 播放器已关闭，操作被拒绝。
  • PlayerError::InvalidStateTransition — 在非法状态下调用（渲染器、背压、源、播放四类）。

打开请求带序号与代际校验，过期的 open 返回 superseded 错误。播放过程中异步失败不通过返回值上报，经 Error 事件发布。
