Flutter埋め込み

Flutter Embedding

erika_flutter これは、liberika の公式 Flutter プラグインであり、macOS、iOS、tvOS、Windows、Android、OpenHarmony をサポートし、実験的な Linux プラグインを提供します。このプラグインは、完全な再生制御、マルチトラック管理、弾幕と字幕のレンダリング、ArtCNN アップスケーリング、および 3 つのビュー コンポーネントを提供します。

  • ターゲットプラットフォーム 7 ある
  • ビューコンポーネント 3 お金
  • Dart SDK ≥ 3.5

依存関係とインストールインストール#

pubspec.yaml

dependencies:
  erika_flutter: ^0.3.0

走る flutter pub get それだけです。 Apple、Windows、Android、および OpenHarmony ビルドは、一致するプリコンパイルされたカーネルを自動的にダウンロードします。 Linux は、最初にローカル動的ライブラリを構築して設定する必要があります ERIKA_LIBRARY_DIRの手順は次のとおりです。 Linux アクセス。ローカル ソース コードからビルドする必要がある場合は、環境変数を設定します ERIKA_FORCE_SOURCE_BUILD=1 そして指定します ERIKA_REPO_ROOT それだけです。例外: liberika リポジトリで macOS プラグインを使用するときに検出されました crates/erika_capi ソースコードのコンパイルが自動的に変更されます(Rustツールチェーンを必要としないウェアハウス内のシーンを設定可能) ERIKA_FORCE_PREBUILT=1 プリコンパイルされたパッケージの使用を強制します)。

ビューの選択ビューの選択肢#

このプラグインは、次の 3 つのレンダリング ビュー コンポーネントを提供します。

ビューコンポーネント根底にあるメカニズム推奨されるシナリオ
ErikaWindowOverlayVideoViewネイティブ子ウィンドウ/ネイティブ Overlay レイヤーApple / Windows のネイティブ レンダリング。 Linux Wayland はネイティブ ビデオ レイヤーを使用し、ビデオ領域は透明なままにする必要があります。
ErikaTextureVideoViewFlutter Texture: macOS は IOSurface + Metal を使用し、Windows は共有 D3D11 テクスチャを使用し、OpenHarmony は外部テクスチャを使用し、Linux は RGBA リードバックを使用します。他のプラットフォームは ErikaVideoView にフォールバックします。macOS / Windows / OpenHarmony / Linux で Opacity、クリッピング、変換、カラーフィルターなどの Flutter 合成効果が必要な場合に使用します。
ErikaVideoView統合されたクロスプラットフォーム ビュー: macOS/iOS PlatformView、Windows ネイティブ ウィンドウ、Android TextureView/SurfaceView、OpenHarmony 外部テクスチャ、Linux RGBA テクスチャ。ユニバーサル再生の入り口。 Flutter トリミングとカラー フィルターが必要な場合は、Texture が推奨されます。 Windows Texture は SDR を出力します。

基本的な使用例

import 'package:flutter/material.dart';
import 'package:erika_flutter/erika_flutter.dart';

class VideoScreen extends StatefulWidget {
  const VideoScreen({super.key});

  @override
  State<VideoScreen> createState() => _VideoScreenState();
}

class _VideoScreenState extends State<VideoScreen> {
  final _player = ErikaPlayer();

  @override
  void initState() {
    super.initState();
    _initPlayer();
  }

  Future<void> _initPlayer() async {
    /* 1. 同步打开媒体（解析轨道与时长，状态置为 Ready） */
    await _player.open(
      'https://example.com/movie.mp4',
      httpHeaders: {'User-Agent': 'FlutterApp/1.0'},
    );
    /* 2. 启动异步解码与播放 */
    await _player.play();
  }

  @override
  void dispose() {
    _player.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: AspectRatio(
          aspectRatio: 16 / 9,
          child: ErikaVideoView(player: _player),
        ),
      ),
    );
  }
}

透明ビデオとブレンディングモード透明アニメーション#

player によってリクエストされた透明なビデオ:ErikaVideoAlphaMode.packedAlphaRight 左右のパーティションを必要とするエンコードされたマテリアル - 左半分はカラー、右半分はグレースケール alpha マスクです。 GPU レンダリング シェーダー (Metal / wgpu / D3D11) は、エンコードされた幅の半分でレンダリングされたビデオを使用して、プリマルチプライされた alpha フレームを再構築します。このモードを要求していない player は引き続き画面を不透明として解釈し、既存のコンテンツは影響を受けません。ブレンディングと不透明度はビデオ widget に入力されます。

透明なビデオの例

final player = ErikaPlayer(
  videoAlphaMode: ErikaVideoAlphaMode.packedAlphaRight,
);

ErikaTextureVideoView(
  player: player,
  blendMode: BlendMode.overlay,
  opacity: 0.8,
)
プラットフォームとパスblendModeopacity
macOS · ErikaTextureVideoView（Flutter Texture）だけ srcOver;他の値はネイティブレイヤーに変更され、Core Animation によって混合されます。Flutter Opacity
macOS · ネイティブ層 (blendMode ≠ srcOver)サポート overlay(背景認識);他の値は無視されますネイティブ CALayer opacity
Windows · ErikaTextureVideoView（SDR）srcOver;overlay ネイティブ合成レイヤーに変更Flutter Opacity
Linux ・ Flutter テクスチャ / Wayland ネイティブ レイヤーテクスチャは Flutter コンポジットになります。ネイティブレイヤーは不透明のみです srcOverテクスチャサポート Flutter Opacity;ネイティブレイヤーの固定不透明度
Windows · ウィンドウ Overlay (DirectComposition)srcOver / overlay; 他の値を指定するとプラグイン エラーがスローされます。IDCompositionEffectGroup opacity
Android / iOS / OpenHarmony作成パラメータを受け入れますが、消費しませんFlutter側によるTextureパス上のアプリケーション

Windows 透明/overlay ウィンドウ Overlay ビデオは、独立した不透明なポップアップ ウィンドウを使用しなくなりましたが、事前に乗算された alpha DirectComposition swap chain を Flutter HWND にバインドして直接合成され、基になる Flutter またはゲーム画面は表示されたままになります。 HDR ソースは、liberika 内の tone map から SDR 合成空間になります。不透明なビデオは引き続き元の HWND パスを使用します。

イベントリスニングイベント購入確認#

プレーヤーのイベント ストリームを聞く

_player.events.listen((event) {
  switch (event.kind) {
    case ErikaEventKind.stateChanged:
      debugPrint('播放状态: ${event.state}');
    case ErikaEventKind.durationChanged:
      debugPrint('总时长: ${event.duration}');
    case ErikaEventKind.positionChanged:
      debugPrint('当前进度: ${event.position}');
    case ErikaEventKind.bufferingChanged:
      debugPrint('缓冲状态: ${event.buffering}');
    case ErikaEventKind.error:
      debugPrint('播放错误: ${event.error ?? event.message}');
    default:
      break;
  }
});

HTTP キャッシュ#

httpReadAheadBytes 前方に読み取るバイト数を決定します。デフォルトは 2 MiB です。httpBackBufferBytes 保持する再生データの量を決定します。デフォルトは 16 MiB です。両方を省略するか、0 を渡してデフォルト値を使用します。先読みのデフォルト値は次のように指定することもできます。 ERIKA_HTTP_READAHEAD_BYTES 設定。

巻き戻しキャッシュ内の後方 seek は、ダウンロードされたデータを直接再利用できます。高ビットレートのビデオには、より大きな予算が必要です。80 Mbit/s のビデオを約 10 秒保持するには、約 100 MB が必要になります。キャッシュはバイト数によって制限されており、固定の再生秒数を表しません。

Dart

await player.open(
  'https://example.com/video.mp4',
  httpReadAheadBytes: 8 * 1024 * 1024,
  httpBackBufferBytes: 128 * 1024 * 1024,
);
await player.play();

GIFをエクスポート#

ErikaPlayer.exportGif() 別のヘッドレス パイプラインを使用し、ビデオ ビューを必要とせず、現在の再生には影響しません。クリップの開始時間と終了時間、フレーム レート、出力サイズを渡します。

Dart

final result = await ErikaPlayer.exportGif(
  ErikaGifExportOptions(
    inputUri: '/path/input.mp4',
    outputPath: '/path/output.gif',
    start: const Duration(seconds: 5),
    end: const Duration(seconds: 10),
    framesPerSecond: 10,
    outputWidth: 640,
    outputHeight: 360,
    quality: ErikaGifExportQuality.high,
  ),
);
