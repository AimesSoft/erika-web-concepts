Swift access

Swift & Apple Platforms

liberika-swift Is the official SwiftPM library for the Apple platform (macOS 11+, iOS 13+, tvOS 13+). SDK provides ErikaPlayerView and for AppKit / UIKit ErikaVideoView, automatically hosts Metal layer binding and display frame clock scheduling.

  • module import Erika
  • support macOS 11+ / iOS 13+ / tvOS 13+
  • Ground floor VideoToolbox · Metal · CoreAudio

View and thread life cycleビューConnection#

Two core lifecycle principles for using the liberika player:

  • Forcibly hold the player: ErikaPlayerView with ErikaVideoView Yes ErikaPlayer adopt weak Weak reference. Host's ObservableObject、@Observable ViewModel or ViewController must be held with a strong reference ErikaPlayer Example.
  • The main thread runs: ErikaPlayer is marked as @MainActor, all playback control and status queries are executed in the main thread, and the underlying C kernel handle is automatically guaranteed to be called serialized by SDK.

SwiftUI access example

import SwiftUI
import Erika

@MainActor
final class VideoPlayerModel: ObservableObject {
    let player: ErikaPlayer

    init() {
        /* 可通过 ErikaPlayer.Configuration 设定输出模式、EDR headroom 与超分 */
        do {
            self.player = try ErikaPlayer(configuration: .init(outputMode: .automatic))
        } catch {
            fatalError("无法创建播放器: \(error)")
        }
    }

    func startPlayback() {
        do {
            /* 支持 URL 或本地路径，可传入自定义 HTTP 请求头 */
            try player.open(
                "https://example.com/stream.m3u8",
                httpHeaders: ["User-Agent": "MyApp/1.0"]
            )
            try player.play()
        } catch {
            print("播放失败: \(error)")
        }
    }

    func pausePlayback() {
        try? player.pause()
    }
}

struct VideoScreen: View {
    @StateObject private var model = VideoPlayerModel()

    var body: some View {
        ErikaPlayerView(player: model.player)
            .aspectRatio(16 / 9, contentMode: .fit)
            .onAppear {
                model.startPlayback()
            }
            .onDisappear {
                model.pausePlayback()
            }
    }
}

Pause when the page is temporarily left; called when the player is finally no longer in use close(). To play again after closing, you need to create a new player.

In the UIKit / AppKit project, you can directly use ErikaVideoView：

event pollingイベント processing#

Pass pollEvent() Consume the events currently accumulated by the player:

Event polling example

func drainEvents() {
    while let event = try? player.pollEvent() {
        switch event.kind {
        case .stateChanged:
            print("播放状态更新: \(event.state)") /* .idle / .opening / .ready / .playing 等 */
        case .durationChanged:
            let seconds = Double(event.durationMicros) / 1_000_000.0
            print("总时长: \(seconds) 秒")
        case .positionChanged:
            let seconds = Double(event.positionMicros) / 1_000_000.0
            print("当前进度: \(seconds) 秒")
        case .bufferingChanged:
            print("缓冲状态: \(event.buffering)")
        case .error:
            print("播放器错误: \(event.error ?? event.message ?? \"\")")
        default:
            break
        }
    }
}

HTTP cache#

httpReadAheadBytes Determines the number of bytes to read forward, the default is 2 MiB;httpBackBufferBytes Determine how much played data to keep, the default is 16 MiB. Omit both or pass 0 to use the default value. The readahead default value can also be given by ERIKA_HTTP_READAHEAD_BYTES set up.

The fallback seek in the rollback cache can directly reuse the downloaded data. High bitrate videos require a larger budget: a video of 80 Mbit/s would require about 100 MB to retain for about 10 seconds. The cache is limited by bytes and does not represent a fixed number of playback seconds.

Swift

try player.open(
    "https://example.com/video.mp4",
    httpReadAheadBytes: 8 * 1024 * 1024,
    httpBackBufferBytes: 128 * 1024 * 1024
)
