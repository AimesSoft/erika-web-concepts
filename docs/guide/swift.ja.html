Swift & Apple Platforms

liberika-swift Apple プラットフォーム (macOS 11+、iOS 13+、tvOS 13+) 用の公式 SwiftPM ライブラリです。 SDK が提供する ErikaPlayerView および AppKit / UIKit 用 ErikaVideoView、Metal レイヤー バインディングと表示フレーム クロック スケジューリングを自動的にホストします。

  • モジュール import Erika
  • サポート macOS 11+ / iOS 13+ / tvOS 13+
  • 1階 VideoToolbox · Metal · CoreAudio

ビューとスレッドのライフサイクル接続の表示#

liberika プレーヤーを使用するための 2 つの主要なライフサイクル原則:

  • プレーヤーを強制的に保持します。 ErikaPlayerView と ErikaVideoView はい ErikaPlayer 採用する weak 弱い参照。ホストの ObservableObject、@Observable ViewModel または ViewController は強参照で保持する必要があります ErikaPlayer 例。
  • メインスレッドは次のように実行されます。 ErikaPlayer としてマークされています @MainActor、すべての再生制御とステータス クエリはメイン スレッドで実行され、基になる C カーネル ハンドルは、SDK によってシリアル化されて呼び出されることが自動的に保証されます。

SwiftUI アクセス例

import SwiftUI
import Erika

@MainActor
final class VideoPlayerModel: ObservableObject {
    let player: ErikaPlayer

    init() {
        /* 可通过 ErikaPlayer.Configuration 设定输出模式、EDR headroom 与超分 */
        do {
            self.player = try ErikaPlayer(configuration: .init(outputMode: .automatic))
        } catch {
            fatalError("无法创建播放器: \(error)")
        }
    }

    func startPlayback() {
        do {
            /* 支持 URL 或本地路径，可传入自定义 HTTP 请求头 */
            try player.open(
                "https://example.com/stream.m3u8",
                httpHeaders: ["User-Agent": "MyApp/1.0"]
            )
            try player.play()
        } catch {
            print("播放失败: \(error)")
        }
    }

    func pausePlayback() {
        try? player.pause()
    }
}

struct VideoScreen: View {
    @StateObject private var model = VideoPlayerModel()

    var body: some View {
        ErikaPlayerView(player: model.player)
            .aspectRatio(16 / 9, contentMode: .fit)
            .onAppear {
                model.startPlayback()
            }
            .onDisappear {
                model.pausePlayback()
            }
    }
}

ページを一時的に離れる場合は一時停止します。プレーヤーが最終的に使用されなくなったときに呼び出されます close()。終了後に再度プレイするには、新しいプレーヤーを作成する必要があります。

イベントポーリングイベント処理#

パス pollEvent() プレーヤーによって現在蓄積されているイベントを消費します。

イベントポーリングの例

func drainEvents() {
    while let event = try? player.pollEvent() {
        switch event.kind {
        case .stateChanged:
            print("播放状态更新: \(event.state)") /* .idle / .opening / .ready / .playing 等 */
        case .durationChanged:
            let seconds = Double(event.durationMicros) / 1_000_000.0
            print("总时长: \(seconds) 秒")
        case .positionChanged:
            let seconds = Double(event.positionMicros) / 1_000_000.0
            print("当前进度: \(seconds) 秒")
        case .bufferingChanged:
            print("缓冲状态: \(event.buffering)")
        case .error:
            print("播放器错误: \(event.error ?? event.message ?? \"\")")
        default:
            break
        }
    }
}

HTTP キャッシュ#

httpReadAheadBytes 前方に読み取るバイト数を決定します。デフォルトは 2 MiB です。httpBackBufferBytes 保持する再生データの量を決定します。デフォルトは 16 MiB です。両方を省略するか、0 を渡してデフォルト値を使用します。先読みのデフォルト値は次のように指定することもできます。 ERIKA_HTTP_READAHEAD_BYTES 設定。

ロールバック キャッシュ内のフォールバック seek は、ダウンロードされたデータを直接再利用できます。高ビットレートのビデオには、より大きな予算が必要です。80 Mbit/s のビデオを約 10 秒保持するには、約 100 MB が必要になります。キャッシュはバイト数によって制限されており、固定の再生秒数を表しません。

Swift

try player.open(
    "https://example.com/video.mp4",
    httpReadAheadBytes: 8 * 1024 * 1024,
    httpBackBufferBytes: 128 * 1024 * 1024
)
