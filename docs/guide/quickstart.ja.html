クイックスタート

Quickstart

liberika は、複数のテクノロジー スタックへのアクセス方法を提供します: Flutter プラグイン erika_flutter、SwiftPMパッケージ liberika-swift、OpenHarmony ArkTS ネイティブ パッケージ erika、Rust ネイティブ crate 標準 C ABI 動的/静的ライブラリ、および独立した Web / WASM ブラウザー バックエンド。

  • プリコンパイル済み 6つの主要なプラットフォーム
  • ソースコード Rust 1.92+
  • ネイティブの依存関係 静的カプセル化

プリコンパイルされたバイナリ製品プリビルト#

GitHub Releases（github.com/AimesSoft/liberika/releases) は、すべての主要なプラットフォーム向けに自己完結型のプリコンパイル済みアーカイブを提供します。

製品アーカイブコンテンツが含まれていますサポートアーキテクチャ

SwiftPM と OHPM パッケージにはそれぞれの公開済みバージョンを使ってください。コア Release の Swift XCFramework は 0.3.1 ランタイムです。

Flutter アクセスFlutter#

pubspec.yaml

dependencies:
  erika_flutter: ^0.3.1

lib/main.dart

final player = ErikaPlayer();
await player.open('/path/to/video.mp4');
await player.play();

このプラグインは、macOS / iOS / tvOS / Windows / Android / OpenHarmony をカバーし、実験的な Linux サポートを追加します。使い方は同梱されています Flutter 埋め込みガイド、Linux の依存関係とコンパイル手順は、 Linux アクセス。

Swift / Apple ネイティブ アクセスSwift#

SwiftPM 依存関係を Xcode プロジェクトに追加 https://github.com/AimesSoft/liberika-swift、Metal レンダリングとシステム ハードウェアデコードを通じてすぐに始められます。

Swiftの例

import Erika

let player = try ErikaPlayer()
try player.open("https://example.com/video.mp4")
try player.play()

ネイティブビュー ErikaPlayerView ライフサイクルの詳細を確認する Swift 導入ガイド。

OpenHarmony / ArkTSOpenHarmony#

OHPM を介してネイティブ ArkTS パッケージをインストールし、 XComponent サーフェス駆動の再生:

shell

ohpm install erika

ArkTS ページのライフサイクルとフレーム スケジュールの詳細については、を参照してください。 OpenHarmony 導入ガイド。

Rust アクセスRust#

Cargo.toml

[dependencies]
erika = { git = "https://github.com/AimesSoft/liberika", tag = "v0.3.1" }

src/main.rs

use erika::{Player, PlayerConfig, MediaRequest};

let player = Player::new(PlayerConfig::default());
player.open(MediaRequest::new("/path/to/video.mp4"))?;
player.play()?;

完全な API とチャンネル購読については、次を参照してください。 Rust埋め込み。

C / C++ ABI アクセスC ABI#

パス erika.h プリコンパイルあり liberika_capi アクセスします。カーネル管理のレンダリングとオーディオを使用することをお勧めします。 ErikaPresenterHandle：

main.c

#include "erika.h"

ErikaPresenterHandle *p = erika_presenter_create();
erika_presenter_attach_metal_layer(p, (uint64_t)layer, w, h, scale);
erika_presenter_open(p, "https://example.com/video.mp4");
erika_presenter_play(p);

/* 在显示时钟回调中每帧驱动 */
ErikaPresenterStats stats;
erika_presenter_render_tick(p, host_time, &stats);

完全仕様かつヘッドレス ErikaHandle 比較のために参照してください C ABI 埋め込み。

Web / WASM#

ダウンロード liberika-web-0.3.1.zip、完全な解凍後、HTTPS または localhost を通じてデモ ページにアクセスします。 JavaScriptを使用する Player.create({ canvas }) ローカルの MKV、ASS フォント、弾幕、マルチトラック、チャプター、スクリーンショットにアクセスし、サポートします。対応コーデックはブラウザーの WebCodecs 実装によって決まり、現在の出力は SDR です。詳細については参照してください Web / WASM ガイド。
