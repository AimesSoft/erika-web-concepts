公的合意共通の規制#

  • 戻り値。 ステータスを返す関数は ErikaStatus を使います。ErikaStatus_Ok（0）は成功、ErikaStatus_NoEvent（5）はイベントキューが空であることを示し、その他はエラーです。ポインタ、数値、void を返す関数はヘッダーの規約を確認してください。
  • エラーメッセージ。 一部の失敗はスレッドローカルのエラーを設定しますが、すべての失敗で保証されず、空または以前のメッセージの場合があります。失敗したスレッドで次の呼び出しの前に erika_last_error_message() で取得し、非 NULL の戻り値を erika_string_free() で解放してください。 例えば、erika_add_external_subtitle の out_track_id が NULL の場合は NullPointer を直接返し、スロットは更新されません。
  • 所有権。 liberika が返す char* ヒープ メモリは呼び出し元が所有します。独立した文字列の使用 erika_string_free(); 構造 (例: ErikaTrackInfo) 内部に含まれる文字列は一致するものを使用します erika_track_info_free()。
  • パラメータの借用。 const char* パラメーターは関数呼び出し中にのみ借用され、NUL で終わる UTF-8 文字列である必要があります。
  • カウント配列。 リストクエリの用途 (buf, capacity, &len) モード:len 書き込み中は常にストリーム内の実際の合計金額を返します。 buf 最大数 capacity。横断するときは、次のようにする必要があります。 min(len, capacity) 国境を越えたアクセスを避けるための境界として。
  • スレッドセーフ。 単一の handle には内部的に同期ロックが含まれておらず、複数のスレッドで同じハンドルのメソッドを同時に呼び出すことは禁止されています。

Presenter エンドツーエンドの例Presenterの流れ#

ネイティブアプリで使用する ErikaPresenterHandle ドライバーの完全な再生リンク:

C / C++ ネイティブ再生アクセス

#include <stdio.h>
#include <stdint.h>
#include "erika.h"

/* 辅助函数：读取并打印线程局部错误信息 */
static void print_last_error(const char *action, ErikaStatus status) {
    char *msg = erika_last_error_message();
    fprintf(stderr, "[liberika Error] %s failed (status=%d): %s\n",
            action, status, msg ? msg : "unknown");
    if (msg) {
        erika_string_free(msg);
    }
}

void play_video(void *metal_layer, int pixel_w, int pixel_h, double scale) {
    /* 1. 创建 Presenter 句柄 */
    ErikaPresenterHandle *p = erika_presenter_create();
    if (!p) {
        fprintf(stderr, "创建 liberika Presenter 失败\n");
        return;
    }

    /* 2. 绑定原生渲染表面 (以 Apple CAMetalLayer 为例) */
    ErikaStatus st = erika_presenter_attach_metal_layer(
        p, (uint64_t)(uintptr_t)metal_layer, pixel_w, pixel_h, scale);
    if (st != ErikaStatus_Ok) {
        print_last_error("attach_metal_layer", st);
        erika_presenter_destroy(p);
        return;
    }

    /* 3. 同步打开媒体（完成流探测与轨道解析，进入 Ready 状态） */
    st = erika_presenter_open(p, "https://example.com/video.mp4");
    if (st != ErikaStatus_Ok) {
        print_last_error("open", st);
        erika_presenter_detach_surface(p);
        erika_presenter_destroy(p);
        return;
    }

    /* 4. 启动异步解码与播放呈现 */
    st = erika_presenter_play(p);
    if (st != ErikaStatus_Ok) {
        print_last_error("play", st);
    }

    /* 5. 显示时钟驱动回调 (通常由 CADisplayLink / CVDisplayLink 驱动) */
    double host_time_seconds = 1000.0;
    ErikaPresenterStats stats;
    erika_presenter_render_tick(p, host_time_seconds, &stats);

    /* 6. 消费事件 (ErikaEvent 是平铺结构) */
    ErikaEvent ev;
    while (erika_presenter_poll_event(p, &ev) == ErikaStatus_Ok) {
        if (ev.kind == ErikaEventKind_StateChanged) {
            printf("状态迁移: %d\n", ev.state);
        } else if (ev.kind == ErikaEventKind_DurationChanged) {
            printf("媒体总时长: %lld us\n", (long long)ev.duration_micros);
        } else if (ev.kind == ErikaEventKind_PositionChanged) {
            printf("当前进度: %llu us\n", (unsigned long long)ev.position_micros);
        } else if (ev.kind == ErikaEventKind_Error) {
            print_last_error("event_error", ev.status);
        }
    }

    /* 7. 安全退出：先分离渲染表面，再销毁句柄 */
    erika_presenter_detach_surface(p);
    erika_presenter_destroy(p);
}

メディア トラックを安全にクエリする土六情報の取得#

オーディオおよび字幕のトラック リストをクエリするときは、セーフ配列境界チェックを使用します。

トラック情報のクエリとリリース

ErikaTrackInfo tracks[16];
uintptr_t total_count = 0;

/* 最多填充 16 条，total_count 接收流中的实际总轨道数 */
ErikaStatus st = erika_presenter_tracks(p, tracks, 16, &total_count);
if (st == ErikaStatus_Ok) {
    uintptr_t available = total_count < 16 ? total_count : 16;
    for (uintptr_t i = 0; i < available; i++) {
        printf("轨道 #%lld: %s (语言: %s)\n",
               (long long)tracks[i].id,
               tracks[i].title ? tracks[i].title : "无标题",
               tracks[i].language ? tracks[i].language : "未知");

        /* 释放结构体内部的堆字符串 */
        erika_track_info_free(&tracks[i]);
    }
}

Handleモード（ヘッドレスコントロール）概要#

ステート マシンとメディア制御のみが必要で、画面とオーディオを駆動するために liberika を必要としない軽量のシナリオを使用できます。 ErikaHandle：

ErikaHandle制御例

ErikaHandle *h = erika_create();

ErikaStatus st = erika_open(h, "https://example.com/video.mp4");
if (st == ErikaStatus_Ok) {
    erika_play(h);

    ErikaEvent ev;
    while (erika_poll_event(h, &ev) == ErikaStatus_Ok) {
        /* 处理就绪与播放事件 */
    }
}

erika_destroy(h);

HTTP キャッシュ#

http_read_ahead_bytes 前方に読み取るバイト数を決定します。デフォルトは 2 MiB です。http_back_buffer_bytes 保持する再生データの量を決定します。デフォルトは 16 MiB です。両方を省略するか、0 を渡してデフォルト値を使用します。先読みのデフォルト値は次のように指定することもできます。 ERIKA_HTTP_READAHEAD_BYTES 設定。

ロールバック キャッシュ内のフォールバック seek は、ダウンロードされたデータを直接再利用できます。高ビットレートのビデオには、より大きな予算が必要です。80 Mbit/s のビデオを約 10 秒保持するには、約 100 MB が必要になります。キャッシュはバイト数によって制限されており、固定の再生秒数を表しません。

C

ErikaOpenOptions options = {0};
options.http_read_ahead_bytes = 8 * 1024 * 1024;
options.http_back_buffer_bytes = 128 * 1024 * 1024;
ErikaStatus status = erika_presenter_open_with_options(
    player, "https://example.com/video.mp4", &options);

ヘッダー ファイルはカーネルと同じリリース バージョンを使用します。 0.1.8以降 ErikaPresenterConfig 含まれています video_alpha_mode;0.2.1/ ErikaOpenOptions 元の予約された場所を使用してフォールバック キャッシュ フィールドを提供し、残りのフィールドを提供します reserved フィールドはゼロに設定されます。
