Swift 接入

Swift & Apple Platforms

ErikaSwift 是面向 Apple 平台（macOS、iOS、tvOS）的原生 Swift 接入库。内核经由 VideoToolbox 硬解、Metal 渲染与 CoreAudio / AudioQueue 输出，宿主通过 SwiftPM 引入，以清晰的生命周期驱动视频画面与事件。

  • 包 ErikaSwift 0.1.7
  • 支持 macOS 11+ / iOS 13+ / tvOS 13+
  • 渲染 Metal (CAMetalLayer)

安装与引入インストール#

在 Xcode 项目中通过 Swift Package Manager 添加依赖：

Xcode Package URL

https://github.com/AimesSoft/ErikaSwift

或在 Package.swift 中声明：

Package.swift

dependencies: [
    .package(url: "https://github.com/AimesSoft/ErikaSwift", from: "0.1.7")
]

SwiftPM 会自动下载包含了 macOS universal、iOS 设备/模拟器、tvOS 设备/模拟器预编译二进制的 CErika.xcframework。原生依赖已包含在内，无需单独配置 FFmpeg 或 libass。

线程契约与对象持有スレッドとライフタイム#

在 Apple 平台接入 Erika 时，请务必注意两个关键设计契约：

  • 强持有播放器。 视图组件（如 ErikaVideoView）对 ErikaPlayer 采用 weak 弱引用设计，避免循环引用。宿主的 ViewModel 或 ViewController 必须以强引用持久持有 ErikaPlayer 实例，否则播放器会在进入页面后立即被释放。
  • 线程串行化。 底层 C 内核句柄没有内部同步锁，不可多线程并发调用。高层 ErikaPlayer 标记为 @MainActor，保证所有 UI 操作与生命周期调用在主线程串行执行。若自定义封装 C ABI，必须在调用点加锁或绑定固定执行线程。

画面承载与 Metal 图层サーフェス描画#

Erika 在 Apple 平台上以 CAMetalLayer 作为原生输出表面。视图层需要把 CAMetalLayer 的指针与物理像素尺寸告知内核：

SwiftUI 视图包装 (VideoSurfaceView.swift)

import SwiftUI
import QuartzCore
import ErikaSwift

#if os(macOS)
public struct VideoSurfaceView: NSViewRepresentable {
    public let player: ErikaPlayer

    public init(player: ErikaPlayer) {
        self.player = player
    }

    public func makeNSView(context: Context) -> ErikaMetalView {
        ErikaMetalView(player: player)
    }

    public func updateNSView(_ view: ErikaMetalView, context: Context) {
        view.syncSurface()
    }
}
#else
public struct VideoSurfaceView: UIViewRepresentable {
    public let player: ErikaPlayer

    public init(player: ErikaPlayer) {
        self.player = player
    }

    public func makeUIView(context: Context) -> ErikaMetalView {
        ErikaMetalView(player: player)
    }

    public func updateUIView(_ view: ErikaMetalView, context: Context) {
        view.syncSurface()
    }
}
#endif

原生视图的尺寸同步与图层附加：

AppKit / UIKit 图层宿主视图

#if os(macOS)
final class ErikaMetalView: NSView {
    private let player: ErikaPlayer
    private var attached = false

    init(player: ErikaPlayer) {
        self.player = player
        super.init(frame: .zero)
        wantsLayer = true
    }

    required init?(coder: NSCoder) { fatalError() }

    override func makeBackingLayer() -> CALayer {
        let layer = CAMetalLayer()
        layer.isOpaque = true
        layer.backgroundColor = NSColor.black.cgColor /* 垫黑防白闪 */
        return layer
    }

    override func layout() {
        super.layout()
        syncSurface()
    }

    func syncSurface() {
        guard let metalLayer = layer as? CAMetalLayer, let win = window else { return }
        let scale = win.backingScaleFactor
        let pixelWidth = Int((bounds.width * scale).rounded())
        let pixelHeight = Int((bounds.height * scale).rounded())
        guard pixelWidth > 0, pixelHeight > 0 else { return }

        if attached {
            player.resizeSurface(width: pixelWidth, height: pixelHeight, scale: scale)
        } else {
            player.attachMetalLayer(metalLayer, width: pixelWidth, height: pixelHeight, scale: scale)
            attached = true
        }
    }

    func teardown() {
        guard attached else { return }
        attached = false
        player.detachSurface()
    }
}
#endif

播放与生命周期再生制御#

open() 方法会同步解封装并探测媒体（获取流信息、视频尺寸与轨道列表），将播放器置入 Ready 状态后返回；随后的解码与渲染在调用 play() 后由内核后台工作线程异步驱动。

播放控制示例

import ErikaSwift

@MainActor
final class PlayerViewModel: ObservableObject {
    let player = ErikaPlayer()

    func loadVideo(url: String) {
        do {
            /* 支持 HTTP Headers 注入与本地路径 */
            try player.open(url, headers: ["User-Agent": "MyApp/1.0"])
            try player.play()
        } catch {
            print("打开媒体失败: \(error)")
        }
    }

    func seek(seconds: Double) {
        let micros = UInt64(seconds * 1_000_000)
        try? player.seek(positionMicros: micros)
    }

    func setSpeed(_ speed: Double) {
        try? player.setPlaybackRate(speed)
    }

    func setVolume(_ volume: Double) {
        try? player.setVolume(volume)
    }

    /* 页面退出时务必按顺序停止与解绑 */
    func teardown() {
        try? player.pause()
        try? player.close()
        player.detachSurface()
    }
}

事件消费イベント処理#

内核通过非阻塞事件队列发布播放状态、时长变化、缓冲指示、轨道变动与错误信息。在显示帧时钟（DisplayLink）或定时器中轮询 pollEvent()：

事件消费循环

func pollEvents() {
    while let event = player.pollEvent() {
        switch event {
        case .stateChanged(let state):
            /* state: .opening / .ready / .playing / .paused / .stopped / .ended / .error */
            self.playbackState = state
        case .durationChanged(let micros):
            self.duration = Double(micros) / 1_000_000.0
        case .positionChanged(let micros):
            self.currentPosition = Double(micros) / 1_000_000.0
        case .bufferingChanged(let isBuffering):
            self.isBuffering = isBuffering
        case .tracksChanged(let tracks):
            self.availableTracks = tracks
        case .error(let message):
            self.lastErrorMessage = message
        default:
            break
        }
    }
}

销毁与释放顺序破棄順序#

为避免 Metal 渲染管道与窗口层销毁时的竞争崩溃，页面退出时请遵循如下销毁顺序：

  1. 停止帧调度： 停止 CVDisplayLink 或 CADisplayLink。
  2. 分离渲染表面： 调用 player.detachSurface()，让内核释放绑定的 CAMetalLayer 与 drawable 资源。
  3. 关闭与释放： 调用 player.close()，随后释放 ErikaPlayer 引用。
