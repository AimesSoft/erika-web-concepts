Swift 接入

Swift & Apple Platforms

ErikaSwift 是面向 Apple 平台（macOS 11+、iOS 13+、tvOS 13+）的官方 SwiftPM 库。SDK 提供了针对 SwiftUI 的 ErikaPlayerView 与针对 AppKit / UIKit 的 ErikaVideoView，自动托管 Metal 图层绑定与显示帧时钟调度。

  • 模块 import Erika
  • 支持 macOS 11+ / iOS 13+ / tvOS 13+
  • 底层 VideoToolbox · Metal · CoreAudio

安装与引入インストール#

在 Xcode 项目中添加 Package 依赖：

Xcode Package URL

https://github.com/AimesSoft/ErikaSwift

或在 Package.swift 的 dependencies 中加入：

Package.swift

dependencies: [
    .package(url: "https://github.com/AimesSoft/ErikaSwift", from: "0.1.7")
]

在代码中导入模块：

Swift

import Erika

SwiftPM 会自动拉取 erika-swift-core-0.1.7.xcframework.zip 预编译核心二进制（覆盖 macOS universal、iOS 设备/模拟器、tvOS 设备/模拟器），无需手动配置 C/C++ 原生依赖。

视图与线程生命周期ビュー連携#

使用 Erika 播放器的两个核心生命周期原则：

  • 强持有播放器： ErikaPlayerView 与 ErikaVideoView 对 ErikaPlayer 采用 weak 弱引用。宿主的 ObservableObject、@Observable ViewModel 或 ViewController 必须以强引用持有 ErikaPlayer 实例。
  • 主线程运行： ErikaPlayer 被标记为 @MainActor，所有播放控制与状态查询均在主线程执行，底层 C 内核句柄由 SDK 自动保证调用串行化。

SwiftUI 接入示例

import SwiftUI
import Erika

@MainActor
final class VideoPlayerModel: ObservableObject {
    let player: ErikaPlayer

    init() {
        /* 可通过 ErikaPlayer.Configuration 设定输出模式、EDR headroom 与超分 */
        do {
            self.player = try ErikaPlayer(configuration: .init(outputMode: .automatic))
        } catch {
            fatalError("无法创建播放器: \(error)")
        }
    }

    func startPlayback() {
        do {
            /* 支持 URL 或本地路径，可传入自定义 HTTP 请求头 */
            try player.open(
                "https://example.com/stream.m3u8",
                httpHeaders: ["User-Agent": "MyApp/1.0"]
            )
            try player.play()
        } catch {
            print("播放失败: \(error)")
        }
    }

    func teardown() {
        try? player.close()
    }
}

struct VideoScreen: View {
    @StateObject private var model = VideoPlayerModel()

    var body: some View {
        ErikaPlayerView(player: model.player)
            .aspectRatio(16 / 9, contentMode: .fit)
            .onAppear {
                model.startPlayback()
            }
            .onDisappear {
                model.teardown()
            }
    }
}

在 UIKit / AppKit 项目中，可直接使用 ErikaVideoView：

UIKit / AppKit 接入

let videoView = ErikaVideoView()
videoView.player = model.player
videoView.onError = { error in
    print("图层渲染错误: \(error)")
}
view.addSubview(videoView)

播放控制 API再生制御#

ErikaPlayer 提供类型安全的原生方法：

方法签名说明
openopen(_ source: String/URL, httpHeaders: [String: String])同步完成媒体探测与轨道解析，将状态置为 ready。
playplay()启动后台硬件解码与音频/视频渲染呈现。
pause / stoppause() / stop()暂停或停止播放。
seekseek(to seconds: TimeInterval)跳转到指定时间（秒）。
setPlaybackRatesetPlaybackRate(_ rate: Double)设置倍速（如 1.25）。
setVolumesetVolume(_ volume: Double)设置音量（0.0 ~ 1.0）。
closeclose()停止后台线程并关闭播放会话。

事件轮询イベント処理#

通过 pollEvent() 消费播放器当前堆积的事件：

事件轮询示例

func drainEvents() {
    while let event = try? player.pollEvent() {
        switch event.kind {
        case .stateChanged:
            print("播放状态更新: \(event.state)") /* .idle / .opening / .ready / .playing 等 */
        case .durationChanged:
            let seconds = Double(event.durationMicros) / 1_000_000.0
            print("总时长: \(seconds) 秒")
        case .positionChanged:
            let seconds = Double(event.positionMicros) / 1_000_000.0
            print("当前进度: \(seconds) 秒")
        case .bufferingChanged:
            print("缓冲状态: \(event.buffering)")
        case .error:
            print("播放器错误: \(event.error ?? event.message ?? \"\")")
        default:
            break
        }
    }
}

轨道、字幕、弹幕与超分高度な機能#

功能类别Swift API说明
轨道管理tracks() / selectAudioTrack(id:) / selectSubtitleTrack(id:)查询轨道列表（[ErikaTrack]）并按 ID 选择音轨与字幕轨（传 nil 禁用）。
外挂字幕addExternalSubtitle(_ uri:) / removeSubtitleTrack(id:) / setSubtitleScale(_ scale:)加载外部 SRT/ASS 字幕文件并调节字号缩放。
弹幕系统loadDanmaku(from:) / loadDanmaku(json:) / addDanmakuTrack(from:name:offset:) / danmakuTracks() / clearDanmaku()加载 Bilibili XML 或 JSON 格式弹幕，支持多轨叠加与时间线偏移。JSON 契约见规范说明。
神经网络超分setUpscaler(_ upscaler:)在 Apple Silicon 上启用 ArtCNN 动漫 2× 超分（.artCNNC4F16 / .artCNNC4F16DS）。
视频截图captureFrame(width:height:)从当前渲染管线抓取指定尺寸的原始 RGBA 帧像素数据（ErikaFrame）。
性能诊断presenterStats() / outputStatus() / resourceStatus()实时查询解码渲染 FPS、丢帧数、Metal 显存占用与 EDR headroom 状态。
