public agreementcommon regulations#

  • Return values. Status-returning functions use ErikaStatus: ErikaStatus_Ok (0) indicates success and ErikaStatus_NoEvent (5) indicates an empty event queue; other statuses indicate errors. Check the header for pointer, value, and void return conventions.
  • Error messages. Some failures set a thread-local error, but not all do; the slot may be empty or retain an earlier message. On the same thread, before another call, read any available message using erika_last_error_message() and free a non-null result using erika_string_free(). For example, erika_add_external_subtitle returns NullPointer directly when out_track_id is NULL, without updating the slot.
  • Ownership. Returned by liberika char* Heap memory is owned by the caller. Independent string usage erika_string_free();Structure (such as ErikaTrackInfo) The string contained inside uses the matching erika_track_info_free()。
  • Parameter borrowing. const char* Parameters are only borrowed during function calls and must be UTF-8 strings ending with NUL.
  • Count array. List query uses (buf, capacity, &len) Mode:len Always returns the actual total amount in the stream, while writing buf The maximum number of capacity. When traversing, it should be min(len, capacity) as a boundary to avoid cross-border access.
  • Thread safe. A single handle does not contain a synchronization lock internally, and it is prohibited to call methods of the same handle concurrently in multiple threads.

Presenter end-to-end examplePresenter の流れ#

Use in native apps ErikaPresenterHandle Driver full playback link:

C / C++ native playback access

#include <stdio.h>
#include <stdint.h>
#include "erika.h"

/* 辅助函数：读取并打印线程局部错误信息 */
static void print_last_error(const char *action, ErikaStatus status) {
    char *msg = erika_last_error_message();
    fprintf(stderr, "[liberika Error] %s failed (status=%d): %s
",
            action, status, msg ? msg : "unknown");
    if (msg) {
        erika_string_free(msg);
    }
}

void play_video(void *metal_layer, int pixel_w, int pixel_h, double scale) {
    /* 1. 创建 Presenter 句柄 */
    ErikaPresenterHandle *p = erika_presenter_create();
    if (!p) {
        fprintf(stderr, "创建 liberika Presenter 失败
");
        return;
    }

    /* 2. 绑定原生渲染表面 (以 Apple CAMetalLayer 为例) */
    ErikaStatus st = erika_presenter_attach_metal_layer(
        p, (uint64_t)(uintptr_t)metal_layer, pixel_w, pixel_h, scale);
    if (st != ErikaStatus_Ok) {
        print_last_error("attach_metal_layer", st);
        erika_presenter_destroy(p);
        return;
    }

    /* 3. 同步打开媒体（完成流探测与轨道解析，进入 Ready 状态） */
    st = erika_presenter_open(p, "https://example.com/video.mp4");
    if (st != ErikaStatus_Ok) {
        print_last_error("open", st);
        erika_presenter_detach_surface(p);
        erika_presenter_destroy(p);
        return;
    }

    /* 4. 启动异步解码与播放呈现 */
    st = erika_presenter_play(p);
    if (st != ErikaStatus_Ok) {
        print_last_error("play", st);
    }

    /* 5. 显示时钟驱动回调 (通常由 CADisplayLink / CVDisplayLink 驱动) */
    double host_time_seconds = 1000.0;
    ErikaPresenterStats stats;
    erika_presenter_render_tick(p, host_time_seconds, &stats);

    /* 6. 消费事件 (ErikaEvent 是平铺结构) */
    ErikaEvent ev;
    while (erika_presenter_poll_event(p, &ev) == ErikaStatus_Ok) {
        if (ev.kind == ErikaEventKind_StateChanged) {
            printf("状态迁移: %d
", ev.state);
        } else if (ev.kind == ErikaEventKind_DurationChanged) {
            printf("媒体总时长: %lld us
", (long long)ev.duration_micros);
        } else if (ev.kind == ErikaEventKind_PositionChanged) {
            printf("当前进度: %llu us
", (unsigned long long)ev.position_micros);
        } else if (ev.kind == ErikaEventKind_Error) {
            print_last_error("event_error", ev.status);
        }
    }

    /* 7. 安全退出：先分离渲染表面，再销毁句柄 */
    erika_presenter_detach_surface(p);
    erika_presenter_destroy(p);
}

Safely query media tracksAcquisition of Toroku information#

When querying audio and subtitle track lists, use safe array bounds checking:

Query and release track information

ErikaTrackInfo tracks[16];
uintptr_t total_count = 0;

/* 最多填充 16 条，total_count 接收流中的实际总轨道数 */
ErikaStatus st = erika_presenter_tracks(p, tracks, 16, &total_count);
if (st == ErikaStatus_Ok) {
    uintptr_t available = total_count < 16 ? total_count : 16;
    for (uintptr_t i = 0; i < available; i++) {
        printf("轨道 #%lld: %s (语言: %s)\n",
               (long long)tracks[i].id,
               tracks[i].title ? tracks[i].title : "无标题",
               tracks[i].language ? tracks[i].language : "未知");

        /* 释放结构体内部的堆字符串 */
        erika_track_info_free(&tracks[i]);
    }
}

Handle mode (headless control)Handle Summary#

Lightweight scenarios that only require state machine and media control, and do not need liberika to drive the screen and audio, can be used ErikaHandle：

ErikaHandle control example

ErikaHandle *h = erika_create();

ErikaStatus st = erika_open(h, "https://example.com/video.mp4");
if (st == ErikaStatus_Ok) {
    erika_play(h);

    ErikaEvent ev;
    while (erika_poll_event(h, &ev) == ErikaStatus_Ok) {
        /* 处理就绪与播放事件 */
    }
}

erika_destroy(h);

HTTP cache#

http_read_ahead_bytes Determines the number of bytes to read forward, the default is 2 MiB;http_back_buffer_bytes Determine how much played data to keep, the default is 16 MiB. Omit both or pass 0 to use the default value. The readahead default value can also be given by ERIKA_HTTP_READAHEAD_BYTES set up.

The fallback seek in the rollback cache can directly reuse the downloaded data. High bitrate videos require a larger budget: a video of 80 Mbit/s would require about 100 MB to retain for about 10 seconds. The cache is limited by bytes and does not represent a fixed number of playback seconds.

C

ErikaOpenOptions options = {0};
options.http_read_ahead_bytes = 8 * 1024 * 1024;
options.http_back_buffer_bytes = 128 * 1024 * 1024;
ErikaStatus status = erika_presenter_open_with_options(
    player, "https://example.com/video.mp4", &options);

The header files use the same release version as the kernel. Starting from 0.1.8 ErikaPresenterConfig contains video_alpha_mode;0.2.1 of ErikaOpenOptions Use the original reserved location to provide fallback cache fields, and the rest reserved The field is set to zero.
