Web / WASM 接入

Browser Playback

把原始 MKV 交给浏览器，保留 ASS 特效、字体附件和弹幕。liberika 0.3.1 用 FFmpeg WASM 解封装、WebCodecs 解码、libass 绘制字幕，再以 WebGL2 合成到宿主的一块 Canvas。

  • 版本 0.3.1
  • 分发 GitHub Release ZIP
  • 环境 HTTPS / localhost
  • 输出 SDR

下载与试播#

下载 liberika-web-0.3.1.zip，按同一 Release 的 SHA256SUMS 校验，完整解压后通过 HTTPS 或本机 HTTP 服务访问 index.html。演示页可选择本地视频、字幕和弹幕，无需媒体服务器。

在解压后的目录运行

python3 -m http.server 18765 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:18765

包内包含 JavaScript、两个 WASM、Worker、许可证、构建清单和演示页。运行时尚未发布到 npm。部署时保留完整目录及相对路径，正确提供 JavaScript 模块和 application/wasm MIME；无需 SharedArrayBuffer 或跨源隔离。

最小接入#

把运行时资源放入网站的 liberika/ 目录。示例让用户选择本地 File，浏览器在 Worker 内分块读取；也可向 open 传入 Blob 或允许跨域的媒体 URL。

HTML + JavaScript module

<input id="media" type="file">
<button id="play" disabled>播放</button>
<canvas id="video" style="width:100%;height:60vh"></canvas>
<pre id="status"></pre>
<script type="module">
import { Player } from './liberika/index.js';
const media = document.querySelector('#media');
const play = document.querySelector('#play');
const status = document.querySelector('#status');
const showError = error => { status.textContent = error.message; };
const player = await Player.create({ canvas: document.querySelector('#video') });
player.addEventListener('error', event => showError(event.detail));
media.onchange = async () => {
  const file = media.files[0];
  if (!file) return;
  media.disabled = true;
  play.disabled = true;
  try {
    const info = await player.open(file);
    status.textContent = `${file.name}：${info.duration.toFixed(1)} 秒`;
    play.disabled = false;
  } catch (error) {
    showError(error);
  } finally {
    media.disabled = false;
  }
};
play.onclick = () => player.play().catch(showError);
// 应用卸载时：await player.destroy();
</script>

从用户点击中调用 play()，满足浏览器音频策略。应用卸载时执行 await player.destroy()。Canvas 只能转交一次；销毁后重建播放器需新 Canvas，布局切换时应保留原实例。

如果 Canvas 或播放器要延迟创建，可在页面初始化时创建 AudioSession，随后传给 Player.create({ canvas, audioSession })，确保第一次真实用户输入能够准备音频。

字幕、弹幕与播放控制#

MKV 内嵌 ASS/SSA 和字体附件自动交给 libass；弹幕复用原生 Rust DFM 引擎。字幕与弹幕共享 Web Audio 播放时钟，并在同一个 Canvas 合成。

打开媒体后调用

await player.addSubtitle(await subtitleFile.text()); // ASS / SSA / SRT / WebVTT
await player.addDanmaku(await danmakuFile.text());   // Bilibili XML / Dandanplay JSON
await player.configureDanmaku({ opacity: 0.8, fontSize: 30, delay: 0 });
await player.configureSubtitles({ scale: 1 });

字幕与弹幕双倍采样默认开启，不改变显示大小或视频分辨率。分别传入 { supersampling: false } 可关闭；省略字段保留当前值。

操作API 与行为
播放 / 跳转play()、pause()、seek(seconds)；跳转保留暂停或播放状态。
音量 / 倍速setVolume(0…1)、setRate(0.25…4)；当前倍速会改变音调。
轨道info.tracks、selectAudio(id)、selectSubtitle(id)；null 关闭对应轨。
章节info.chapters 的 start / end 以秒计，end 可为 null；调用 seek(chapter.start) 定位。
截图capture(width?) 返回含视频、字幕和弹幕的 PNG Blob。
关闭 / 释放close() 清空当前媒体后可重新 open；destroy() 释放 Worker、解码器、帧、GPU 和音频资源。

完整类型见 index.d.ts。loaded、stats、timeupdate、error、log 是 CustomEvent，数据在 detail 中；play / pause / ended 是普通 Event。

浏览器与媒体源要求#

  • 同时需要 WebCodecs 视频/音频解码、OffscreenCanvas、WebGL2 和 Web Audio。打开时查询编码配置、profile 和尺寸；编码支持取决于浏览器，WASM 不包含音视频软解或服务端转码回退。
  • 默认请求 prefer-hardware，再尝试 no-preference；open(source, { hardwareDecode: false }) 请求 prefer-software。偏好字段不能证明实际用了硬解。
  • 远程大文件通过有界 HTTP Range 缓存读取；超过 8 MiB 需要服务器正确返回 206 和已知总长度，跨域时通过 Access-Control-Expose-Headers 暴露 Content-Range。
  • 容器包括 MP4/MOV、MKV/WebM、MPEG-TS、AVI、FLV 和 Ogg。音视频编码是否能播，以当前浏览器的 WebCodecs 查询结果为准。
  • 当前输出为 SDR，暂不包含桌面 HDR/EDR/Dolby Vision、ArtCNN、DRM、未知长度直播、位图字幕和内嵌非 ASS 字幕转换。SRT/VTT 作为纯文本转换，不保留复杂 VTT 排版。
  • 内嵌 ASS 跳转预读前 5 秒并保留已见事件；首次跳到更早开始的长事件可能暂时缺失。完整外挂 ASS 脚本没有此限制。

源码验证记录覆盖 Chrome 与 Safari 的指定版本和素材；Firefox 尚未验证。详细构建与测试步骤见源码 Web 指南。

从源码构建#

使用 Emscripten 4.0.23、wasm-bindgen-cli 0.2.126，以及 Rust、Python 3、Node、CMake、Meson、Ninja、make 和 pkg-config。固定工具版本及初始化步骤见上方源码指南。

shell

cargo run -p xtask -- web build
python3 scripts/serve_web.py
# 已构建原生 C 依赖时可追加 --skip-native

完整可部署目录为 target/web，中间文件为 target/web-build。服务端宜把运行时放进版本目录，避免新旧 JS/WASM 混用。
