C ABI Embedding

C / C++ / 原生宿主经 erika.h 接入。接口提供两个入口族：标准应用接入使用由内核托管渲染与音频的 ErikaPresenterHandle；无头控制与轻量宿主可使用 ErikaHandle。

入口选择入口の選択#

ErikaPresenterHandle（推荐）ErikaHandle
架构模型推模型（Push）。内核托管硬解、音频输出、渲染管线、字幕与弹幕。无头控制模型。提供状态机、传输控制与事件接收器。
宿主职责提供原生表面（CAMetalLayer / HWND / wgpu），并在显示时钟驱动 render_tick。调用播放控制并轮询事件；无内置渲染与音频设备输出。
适用场景GUI 原生播放器、游戏引擎嵌入、桌面/移动应用。无头播放器、后端服务控制或基础事件桥接。
平台支持macOS / iOS / tvOS / Windows / Android / OpenHarmony。全部平台。

注：当前 C ABI 未导出裸像素帧拉取接口。如果需要在宿主原生窗口上显示视频画面，请使用 ErikaPresenterHandle。

公共约定共通規約#

  • 返回值。 每个可能失败的调用返回 ErikaStatus。ErikaStatus_Ok（0）表示成功；ErikaStatus_NoEvent（5）表示事件队列暂空。非零且非 5 的状态码均表示错误。
  • 错误消息。 发生错误时，内核会将详细的可读错误信息保存在线程局部变量中。必须在调用失败的同一线程中立即调用 erika_last_error_message() 读取，并使用 erika_string_free() 释放返回的指针。
  • 所有权。 Erika 返回的 char* 堆内存归调用方所有。独立字符串使用 erika_string_free()；结构体（如 ErikaTrackInfo）内部包含的字符串使用配套的 erika_track_info_free()。
  • 参数借用。 const char* 参数仅在函数调用期间被借用，必须是以 NUL 结尾的 UTF-8 字符串。
  • 计数数组。 列表查询采用 (buf, capacity, &len) 模式：len 总是返回流中的实际总数量，而写入 buf 的数量最多为 capacity。遍历时应以 min(len, capacity) 为界，避免越界访问。
  • 线程安全。 单个 handle 内部不包含同步锁，禁止在多个线程中并发调用同一句柄的方法。

Presenter 端到端示例Presenter の流れ#

在原生应用中使用 ErikaPresenterHandle 驱动完整播放链路：

C / C++ 原生播放接入

#include <stdio.h>
#include <stdint.h>
#include "erika.h"

/* 辅助函数：安全检查并打印错误 */
static void check_status(ErikaStatus status, const char *action) {
    if (status != ErikaStatus_Ok && status != ErikaStatus_NoEvent) {
        char *msg = erika_last_error_message();
        fprintf(stderr, "[Erika Error] %s failed (%d): %s\n", action, status, msg ? msg : "unknown");
        if (msg) erika_string_free(msg);
    }
}

void play_video(void *metal_layer, int pixel_w, int pixel_h, double scale) {
    /* 1. 创建 Presenter 句柄 */
    ErikaPresenterHandle *p = erika_presenter_create();
    if (!p) {
        fprintf(stderr, "创建 Erika Presenter 失败\n");
        return;
    }

    /* 2. 绑定原生渲染表面 (以 Apple CAMetalLayer 为例) */
    ErikaStatus st = erika_presenter_attach_metal_layer(
        p, (uint64_t)(uintptr_t)metal_layer, pixel_w, pixel_h, scale);
    check_status(st, "attach_metal_layer");

    /* 3. 同步打开媒体并就绪 */
    st = erika_presenter_open(p, "https://example.com/video.mp4");
    check_status(st, "open");

    /* 4. 启动异步解码与播放 */
    st = erika_presenter_play(p);
    check_status(st, "play");

    /* 5. 显示时钟回调循环 (通常由 CADisplayLink 或 CVDisplayLink 驱动) */
    double host_time_seconds = 1000.0; /* 宿主显示时钟时间戳 */
    ErikaPresenterStats stats;
    erika_presenter_render_tick(p, host_time_seconds, &stats);

    /* 6. 消费事件 */
    ErikaEvent ev;
    while (erika_presenter_poll_event(p, &ev) == ErikaStatus_Ok) {
        if (ev.kind == ErikaEventKind_StateChanged) {
            printf("状态迁移: %d\n", ev.data.state_changed.state);
        } else if (ev.kind == ErikaEventKind_DurationChanged) {
            printf("媒体时长: %llu us\n", (unsigned long long)ev.data.duration_changed.duration_micros);
        }
    }

    /* 7. 安全退出与资源释放：先 detach 表面，再 destroy 句柄 */
    erika_presenter_detach_surface(p);
    erika_presenter_destroy(p);
}

安全查询媒体轨道トラック情報取得#

查询音频与字幕轨道列表时，请使用安全的数组边界检查：

查询并释放轨道信息

ErikaTrackInfo tracks[16];
uintptr_t total_count = 0;

/* 最多填充 16 条，total_count 接收流中的实际总轨道数 */
ErikaStatus st = erika_presenter_tracks(p, tracks, 16, &total_count);
if (st == ErikaStatus_Ok) {
    uintptr_t available = total_count < 16 ? total_count : 16;
    for (uintptr_t i = 0; i < available; i++) {
        printf("轨道 #%lld: %s (语言: %s)\n",
               (long long)tracks[i].id,
               tracks[i].title ? tracks[i].title : "无标题",
               tracks[i].language ? tracks[i].language : "未知");

        /* 释放结构体内部的堆字符串 */
        erika_track_info_free(&tracks[i]);
    }
}

Handle 模式 (无头控制)Handle 概要#

仅需状态机与媒体控制、无需由 Erika 驱动上屏与音频的轻量级场景，可使用 ErikaHandle：

ErikaHandle 控制示例

ErikaHandle *h = erika_create();

ErikaStatus st = erika_open(h, "https://example.com/video.mp4");
if (st == ErikaStatus_Ok) {
    erika_play(h);

    ErikaEvent ev;
    while (erika_poll_event(h, &ev) == ErikaStatus_Ok) {
        /* 处理就绪与播放事件 */
    }
}

erika_destroy(h);
