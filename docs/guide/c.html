C ABI Embedding

C / C++ / Swift / Dart FFI 宿主经 erika.h 接入。接口提供两个相互独立的入口族，按渲染所有权二选一。全部导出以头文件为准，本文给出选型依据与端到端流程。

  • 头文件 crates/erika_capi/include/erika.h
  • 导出 91 个函数
  • 入口 2 族

入口选择入口の選択#

ErikaHandleErikaPresenterHandle
模型pull。宿主渲染，拉取状态。push。内核托管解码、时序、音频与渲染。
宿主职责渲染循环、帧数据消费。提供表面，每帧调用 render_tick。
适用宿主已有渲染管线，或需要原始帧数据。宿主只提供表面，其余交给内核。
编译范围所有目标。macOS / iOS / Windows / Android / OpenHarmony；其他目标 create 返回 NULL。

两者共享事件、状态与轨道 API。选择入口后不要混用两族的函数。

公共约定共通規約#

  • 返回值。 每个可能失败的调用返回 ErikaStatus。Ok（0）与 NoEvent（5）是仅有的非错误结果。panic 被捕获并映射为 ErikaStatus_Panic。
  • 错误消息。 非 Ok/NoEvent 结果的人读消息存放在线程局部槽位。在同一线程经 erika_last_error_message() 读取，用 erika_string_free() 释放。
  • 所有权。 Erika 返回的 char* 归调用方所有。独立字符串用 erika_string_free()；ErikaTrackInfo / ErikaDanmakuTrackInfo 内的字符串用配套的 *_info_free()。
  • 参数借用。 const char* 参数仅调用期间借用，必须是以 NUL 结尾的 UTF-8。
  • 计数数组。 列表查询使用 (buf, capacity, &len) 惯用法：len 置为总数，最多写入 capacity 条；capacity 为 0 且 buf 为 NULL 时只查询数量。
  • 像素单位。 attach 与 resize 的宽高是物理像素。scale 是 UI（弹幕等）使用的逻辑内容 / DPI 比例，不缩放表面范围。
  • 线程。 一个 handle 不提供内部同步，不得从多个线程并发调用。

Presenter 端到端Presenter の流れ#

macOS / iOS（Metal 表面）

#include "erika.h"

/* 1. 创建。config 可指定输出模式、EDR headroom 与超分模式 */
ErikaPresenterHandle *p = erika_presenter_create();
if (!p) { /* 读 erika_last_error_message() */ }

/* 2. 附着表面。CAMetalLayer* 转为 uint64_t */
erika_presenter_attach_metal_layer(p, (uint64_t)layer, w, h, scale);

/* 3. 打开与播放。open 是异步的，状态经 poll_event 到达 */
erika_presenter_open(p, "/path/to/video.mp4");
erika_presenter_play(p);

/* 4. 显示循环：每个显示帧调用一次 */
for (;;) {
  ErikaPresenterStats stats;
  erika_presenter_render_tick(p, host_time, &stats);

  ErikaEvent ev;
  while (erika_presenter_poll_event(p, &ev) != ErikaStatus_NoEvent) {
    /* 处理 StateChanged / DurationChanged / Error 等 */
  }
}

/* 5. 清理 */
erika_presenter_destroy(p);

要点：

  • render_tick 的第一个参数是宿主显示时钟的时间（秒），内核用它做 vsync 量化调度。传入与表面刷新同步的时间。
  • 表面尺寸或 scale 变化时调用 resize_surface，不要重建 presenter。
  • out_stats 可为 NULL，不需要统计时省略。
  • Windows 用 attach_windows_hwnd（hwnd + hinstance），Android / HarmonyOS 用 attach_wgpu_surface 系列。渲染后端由 presenter 配置决定，与附着调用无关。

Handle 模式Handle の流れ#

宿主自行渲染时，ErikaHandle 提供播放控制与状态查询，不含渲染循环：

pull 模型

ErikaHandle *h = erika_create();

erika_open(h, "https://example.com/video.mp4");

/* 事件轮询 */
ErikaEvent ev;
while (erika_poll_event(h, &ev) != ErikaStatus_NoEvent) {
  /* 等 DurationChanged 后读取轨道等 */
}

ErikaTrackInfo tracks[16];
uintptr_t count = 0;
erika_tracks(h, tracks, 16, &count);
for (uintptr_t i = 0; i < count; i++) {
  /* 读取 tracks[i]，完成后释放 */
  erika_track_info_free(&tracks[i]);
}

帧数据的获取与渲染循环由宿主实现。Rust 侧的等价物见Rust 嵌入。

Swift 与 Dart FFISwift / Dart#

Swift 与 Dart 宿主经 FFI 声明导入同一组函数。注意两点：

  • 错误消息的线程局部槽位按线程隔离。异步回调用宿主侧线程时，要在同一线程内读取 last_error_message，或把返回值复制出来。
  • 结构体（ErikaPresenterStats 等）按值传入传出。跨语言时结构体布局必须与 erika.h 一致；Flutter 插件在 Swift 侧手写镜像结构体，改动 erika.h 结构体时同步更新。
