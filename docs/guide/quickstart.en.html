Quick start

Quickstart

liberika provides access methods for multiple technology stacks: Flutter plug-in erika_flutter, SwiftPM package liberika-swift, OpenHarmony ArkTS native package erika, Rust native crate standard C ABI dynamic/static library, and independent Web / WASM browser backend.

  • precompiled 6 major platforms
  • Source code Rust 1.92+
  • Native dependencies statically bundled

Flutter accessFlutter#

pubspec.yaml

dependencies:
  erika_flutter: ^0.3.0

lib/main.dart

final player = ErikaPlayer();
await player.open('/path/to/video.mp4');
await player.play();

The plug-in covers macOS / iOS / tvOS / Windows / Android / OpenHarmony, and adds experimental Linux support. How to use is included in Flutter Embedding Guide, the dependencies and compilation steps of Linux are included in Linux access。

Swift / Apple native accessSwift#

Add SwiftPM dependency to Xcode project https://github.com/AimesSoft/liberika-swift, get started quickly through Metal rendering and system hardware decoding:

Swift example

import Erika

let player = try ErikaPlayer()
try player.open("https://example.com/video.mp4")
try player.play()

native view ErikaPlayerView See details about life cycle Swift Integration guide。

OpenHarmony / ArkTSOpenHarmony#

Install the native ArkTS package through OHPM, combined with XComponent Surface driven playback:

shell

ohpm install erika

For detailed ArkTS page life cycle and frame scheduling, please refer to OpenHarmony Integration guide。

Rust accessRust#

Cargo.toml

[dependencies]
erika = { git = "https://github.com/AimesSoft/liberika", tag = "v0.3.0" }

src/main.rs

use erika::{Player, PlayerConfig, MediaRequest};

let player = Player::new(PlayerConfig::default());
player.open(MediaRequest::new("/path/to/video.mp4"))?;
player.play()?;

Complete API with channel subscription see Rust embedded。

C / C++ ABI accessC ABI#

Pass erika.h with precompilation liberika_capi access. It is recommended to use kernel-managed rendering and audio ErikaPresenterHandle：

main.c

#include "erika.h"

ErikaPresenterHandle *p = erika_presenter_create();
erika_presenter_attach_metal_layer(p, (uint64_t)layer, w, h, scale);
erika_presenter_open(p, "https://example.com/video.mp4");
erika_presenter_play(p);

/* 在显示时钟回调中每帧驱动 */
ErikaPresenterStats stats;
erika_presenter_render_tick(p, host_time, &stats);

Complete specification and headless ErikaHandle See for comparison C ABI embedded。

Web / WASM#

Download liberika-web-0.3.0.zip, access the demo page through HTTPS or localhost after complete decompression. Use JavaScript Player.create({ canvas }) Access, support local MKV, ASS fonts, danmaku, multi-track, chapters and screenshots. Codec support is determined by the browser’s WebCodecs implementation, and the current output is SDR; see for details Web / WASM Guide。
