Flutter embedded

Flutter Embedding

erika_flutter It is the official Flutter plug-in for liberika, supports macOS, iOS, tvOS, Windows, Android, OpenHarmony, and provides experimental Linux plug-in. The plug-in provides complete playback control, multi-track management, danmaku and subtitle rendering, ArtCNN upscaling, and three view components.

  • target platform 7 a
  • view component 3 money
  • Dart SDK ≥ 3.5

Dependencies and installationインストール#

pubspec.yaml

dependencies:
  erika_flutter: ^0.3.0

run flutter pub get That’s it. Apple, Windows, Android, and OpenHarmony builds automatically download matching precompiled kernels. Linux needs to build a local dynamic library and set it up first ERIKA_LIBRARY_DIR, the steps are included in Linux access. If you need to build from local source code, set environment variables ERIKA_FORCE_SOURCE_BUILD=1 and specify ERIKA_REPO_ROOT That’s it. Exception: Detected when using macOS plugin in liberika repository crates/erika_capi Source code compilation will be automatically changed (scenes in the warehouse that do not require the Rust tool chain can be set ERIKA_FORCE_PREBUILT=1 Force the use of precompiled packages).

View selectionビューの选択#

The plugin provides three rendering view components:

view componentunderlying mechanismRecommended scenarios
ErikaWindowOverlayVideoViewNative child window / native Overlay layerThe native rendering of Apple / Windows; Linux Wayland uses the native video layer, and the video area needs to remain transparent.
ErikaTextureVideoViewFlutter Texture: macOS uses IOSurface + Metal, Windows uses the shared D3D11 texture, OpenHarmony uses an external texture, Linux uses RGBA readback; other platforms fall back to ErikaVideoView.Required on macOS / Windows / OpenHarmony / Linux Opacity, cropping, transformation, color filter and other Flutter synthesis effects.
ErikaVideoViewUnified cross-platform views: macOS/iOS PlatformView, Windows native window, Android TextureView/SurfaceView, OpenHarmony external texture, Linux RGBA texture.Universal playback entrance. When Flutter cropping and color filters are required, Texture is preferred; Windows Texture outputs SDR.

Basic usage examples

import 'package:flutter/material.dart';
import 'package:erika_flutter/erika_flutter.dart';

class VideoScreen extends StatefulWidget {
  const VideoScreen({super.key});

  @override
  State<VideoScreen> createState() => _VideoScreenState();
}

class _VideoScreenState extends State<VideoScreen> {
  final _player = ErikaPlayer();

  @override
  void initState() {
    super.initState();
    _initPlayer();
  }

  Future<void> _initPlayer() async {
    /* 1. 同步打开媒体（解析轨道与时长，状态置为 Ready） */
    await _player.open(
      'https://example.com/movie.mp4',
      httpHeaders: {'User-Agent': 'FlutterApp/1.0'},
    );
    /* 2. 启动异步解码与播放 */
    await _player.play();
  }

  @override
  void dispose() {
    _player.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: AspectRatio(
          aspectRatio: 16 / 9,
          child: ErikaVideoView(player: _player),
        ),
      ),
    );
  }
}

Transparent video and blending modesTransparent animation#

Transparent video requested by player:ErikaVideoAlphaMode.packedAlphaRight Encoded material requiring left and right partitions - the left half is color, the right half is grayscale alpha mask. The GPU rendering shader (Metal / wgpu / D3D11) reconstructs a premultiplied alpha frame, with the video rendered at half the encoded width. player that has not requested this mode will still interpret the screen as opaque, and the existing content will not be affected. Blending and Opacity are input on video widget.

Transparent video example

final player = ErikaPlayer(
  videoAlphaMode: ErikaVideoAlphaMode.packedAlphaRight,
);

ErikaTextureVideoView(
  player: player,
  blendMode: BlendMode.overlay,
  opacity: 0.8,
)

event listeningイベント purchase verification#

Listen to the player event stream

_player.events.listen((event) {
  switch (event.kind) {
    case ErikaEventKind.stateChanged:
      debugPrint('播放状态: ${event.state}');
    case ErikaEventKind.durationChanged:
      debugPrint('总时长: ${event.duration}');
    case ErikaEventKind.positionChanged:
      debugPrint('当前进度: ${event.position}');
    case ErikaEventKind.bufferingChanged:
      debugPrint('缓冲状态: ${event.buffering}');
    case ErikaEventKind.error:
      debugPrint('播放错误: ${event.error ?? event.message}');
    default:
      break;
  }
});

HTTP cache#

httpReadAheadBytes Determines the number of bytes to read forward, the default is 2 MiB;httpBackBufferBytes Determine how much played data to keep, the default is 16 MiB. Omit both or pass 0 to use the default value. The readahead default value can also be given by ERIKA_HTTP_READAHEAD_BYTES set up.

A backward seek within the rewind cache can directly reuse the downloaded data. High bitrate videos require a larger budget: a video of 80 Mbit/s would require about 100 MB to retain for about 10 seconds. The cache is limited by bytes and does not represent a fixed number of playback seconds.

Dart

await player.open(
  'https://example.com/video.mp4',
  httpReadAheadBytes: 8 * 1024 * 1024,
  httpBackBufferBytes: 128 * 1024 * 1024,
);
await player.play();

Export GIF#

ErikaPlayer.exportGif() Uses a separate headless pipeline, does not require a video view, and does not affect current playback. Pass in the clip start and end time, frame rate and output size:

Dart

final result = await ErikaPlayer.exportGif(
  ErikaGifExportOptions(
    inputUri: '/path/input.mp4',
    outputPath: '/path/output.gif',
    start: const Duration(seconds: 5),
    end: const Duration(seconds: 10),
    framesPerSecond: 10,
    outputWidth: 640,
    outputHeight: 360,
    quality: ErikaGifExportQuality.high,
  ),
);
