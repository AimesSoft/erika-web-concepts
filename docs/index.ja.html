開発者向けドキュメント

Developer Documentation

liberika は、クロスプラットフォームの音声・動画アプリケーション向けの組み込み再生エンジンです。このドキュメントは、liberika をアプリに組み込むチームとエンジン開発者を対象とし、v0.3.0 を基準とします。プロジェクト名は liberika ですが、erika crate、erika_* C ABI、SDK のパッケージ名は互換性のため維持されています。

  • バージョン 0.3.0
  • C ABI エクスポート 108
  • Rust 1.92+
  • ライセンス MPL-2.0

0.3.0 アップグレードのヒント#

デフォルト動作の変更：ネイティブと Web では字幕・弾幕のスーパーサンプリングが既定で有効です。ネイティブのソフトウェア動画デコードは既定で FFmpeg のマルチスレッドを使います。ERIKA_VIDEO_DECODE_THREADS=1 を設定するとシングルスレッドに戻せます。

Web / WASM バックエンド、独立したフレーム出力、診断スナップショット、チャプター取得を追加しました。Flutter、SwiftPM、OHPM の 0.3.0 は公開済みです。変更の詳細は変更履歴をご覧ください。

導入ガイド導入手引#

liberika をアプリに組み込みます。まずクイックスタートを読み、環境と言語に合うガイドを選んでください。

01
クイックスタートQuickstart
ビルド済み成果物、Flutter、SwiftPM、OpenHarmony OHPM、Rust、C ABI、Web / WASM の導入方法の概要。
02
Flutter埋め込みFlutter Embedding
公式プラグインは 7 プラットフォームに対応し、ネイティブ動画レイヤー、Flutter テクスチャ、互換ビューを提供します。Linux はソースからビルドします。
03
Swift アクセスSwift & Apple
macOS / iOS / tvOS 向け SwiftPM パッケージ liberika-swift：CAMetalLayer の接続、イベント取得、ライフサイクル管理。
04
OpenHarmony / OHPMArkTS SDK
OpenHarmony 向け ArkTS SDK：XComponent のサーフェス接続、renderTick によるフレーム制御、ライフサイクル管理。
05
Rust埋め込みRust Embedding
erika crate の Player と PresenterRuntime を使ったメディアのオープン、イベント購読、デコード済みフレームの取得。
06
C ABI 埋め込みC ABI Embedding
erika.h を使った接続。描画と音声を管理する ErikaPresenterHandle、軽量なヘッドレス制御の ErikaHandle を説明します。
07
Linux アクセスLinux / WSLg
実験的な Linux 対応：FFmpeg 8、X11 / Wayland、PulseAudio、Flutter のソースビルド。
08
Web / WASM アクセスBrowser Playback
WebCodecs、FFmpeg WASM、libass、Rust 弾幕：ローカル MKV、字幕フォント、複数トラック、チャプター、PNG キャプチャ。
