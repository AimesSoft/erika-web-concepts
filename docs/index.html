开发者文档

Developer Documentation

Erika 是为现代跨平台音视频应用量身打造的高性能嵌入式播放内核。本文档面向在应用中接入 Erika 的工程团队，以及参与内核演进的开发者。内容以 v0.1.7 为准。

  • 版本 0.1.7
  • C ABI 导出 91
  • Rust 1.92+
  • 许可证 MPL-2.0

接入指南導入手引#

从零开始把 Erika 接入你的应用。先读快速开始，再按宿主平台与编程语言选择对应的指南。

01
快速开始Quickstart
主流接入方式概览：SwiftPM、Flutter、OpenHarmony OHPM、Rust 与 C ABI 预编译归档。
02
Swift 接入Swift & Apple
macOS / iOS / tvOS 原生 SwiftPM 包 ErikaSwift：CAMetalLayer 图层绑定、事件轮询与生命周期管理。
03
Rust 嵌入Rust Embedding
使用 erika crate 的 Player 与 PresenterRuntime：媒体打开、事件订阅与解码帧通道。
04
C ABI 嵌入C ABI Embedding
经 erika.h 接入：推荐托管渲染与音频的 ErikaPresenterHandle，以及轻量无头控制的 ErikaHandle。
05
Flutter 嵌入Flutter Embedding
官方插件覆盖 6 大平台，提供 Window Overlay 与 PlatformView 两款高性能视图。
06
OpenHarmony / OHPMArkTS SDK
OpenHarmony 原生 ArkTS SDK：XComponent 原生表面绑定、DisplayLink 帧渲染与生命周期。

内核原理核の仕組み#

从媒体解封装、硬件解码到最终上屏呈现的完整架构与核心子系统实现。

07
架构总览Architecture
crate 分层、模块划分、线程模型与流水线数据流。
08
硬件解码Decoding
VideoToolbox、D3D11VA、MediaCodec、AVCodec 硬件加速解码通路与自动回退。
09
零拷贝导入Zero-copy Import
解码后直接导入 GPU 纹理：CVPixelBuffer、DirectX 共享句柄、AHardwareBuffer、OHNativeBuffer。
10
渲染管线Render Pipeline
单次 Render Pass 完成色彩空间转换、Tone Mapping、字幕与弹幕图层高效混合。
11
高动态范围HDR / EDR
Apple EDR、HDR10 PQ、Extended-linear scRGB 输出协商与动态 Headroom 调节。
12
神经超分Neural Upscaling
ArtCNN 动漫超分算法：Metal SIMDGroup Matrix 与 wgpu Compute 硬件加速。
13
字幕与弹幕Subtitle & Danmaku
libass 矢量特效字幕渲染与自研 DFM+ 碰撞避让弹幕排版引擎。
14
时钟与调度Clock & Scheduling
高精度音频主时钟、Ring Buffer 缓冲、VSync 量化帧调度与智能丢帧控制。
