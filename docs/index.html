开发者文档

Developer Documentation

Erika 是 NipaPlay 的自研播放内核。本文档面向在应用中嵌入 Erika 的工程师，以及参与内核开发的贡献者。内容以 v0.1.6 源码为准。

  • 版本 0.1.6
  • C ABI 导出 91
  • Rust 1.92+
  • 许可证 MPL-2.0

接入指南導入手引#

从零开始把 Erika 接入你的应用。先读快速开始，再按宿主语言选择对应的嵌入指南。

01
快速开始Quickstart
四种接入方式概览：预编译产物、Rust、C ABI、Flutter。十分钟跑通第一个播放。
02
Rust 嵌入Rust Embedding
使用 erika crate 的 Player API：媒体打开、播放控制、事件订阅与帧订阅。
03
C ABI 嵌入C ABI Embedding
经 erika.h 接入：pull 模型的 ErikaHandle 与 push 模型的 ErikaPresenterHandle 二选一。
04
Flutter 嵌入Flutter Embedding
插件覆盖 macOS / iOS / tvOS / Windows / Android / HarmonyOS 六个目标，两种视图路径。

内核原理核の仕組み#

从 demux 到上屏的整条通路如何工作。先读架构总览，再按子系统深入。

05
架构总览Architecture
crate 分层、模块划分、线程模型与数据流。理解其余页面的起点。
06
硬件解码Decoding
VideoToolbox、D3D11VA、MediaCodec、AVCodec 四条硬解通路，互操作不可用时回退软解。
07
零拷贝导入Zero-copy Import
解码器输出直接成为 GPU 纹理：CVPixelBuffer、AHardwareBuffer、OHNativeBuffer 导入路径。
08
渲染管线Render Pipeline
pass 图构建规则：色彩转换、tone mapping、字幕与弹幕合成，一次 render pass 完成。
09
高动态范围HDR / EDR
Apple EDR、HDR10 PQ、extended-linear scRGB 输出协商，以及显式 SDR 回退。
10
神经超分Neural Upscaling
ArtCNN 动漫亮度 2× 超分：Metal simdgroup matrix 与 wgpu compute 两条执行路径。
11
字幕与弹幕Subtitle & Danmaku
SRT / WebVTT / ASS 经 libass 渲染；弹幕走 DFM+ 碰撞避让布局与 glyph atlas。
12
时钟与调度Clock & Scheduling
音频主时钟、ring buffer、时钟修正参数、vsync 量化帧调度与丢帧策略。
