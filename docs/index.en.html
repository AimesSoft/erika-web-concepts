Developer Documentation

liberika is a high-performance embeddable playback kernel built for modern cross-platform audio and video apps. This documentation is for engineering teams integrating liberika into their apps and for developers working on the kernel itself. It describes v0.3.0. The project is now named liberika; the erika crate, the erika_* C ABI, and SDK package names stay compatible.

  • Version 0.3.0
  • C ABI exports 108
  • Rust 1.92+
  • License MPL-2.0

0.3.0 upgrade notes#

Default behavior changes: Subtitle and danmaku supersampling is now on by default on native and Web. Native software video decoding now uses FFmpeg multithreading by default. Set ERIKA_VIDEO_DECODE_THREADS=1 to restore single-threaded decoding.

New in this release: the Web / WASM backend, standalone frame export, diagnostics snapshots, and chapter queries. Version 0.3.0 has been released for Flutter, SwiftPM, and OHPM. See the changelog for the full list of changes.
