C ABI 概要

C ABI Overview

C ABI のグローバル規則と型定義。関数リストはエントリ ファミリごとにページ分割されています。ErikaHandle(23)、ErikaPresenterHandle(72)、一般および独立した入り口 (13)。に crates/erika_capi/include/erika.h 唯一の権限として。

  • エクスポート機能 108
  • 種類 45
  • イベント 12 親切

入場と同意入場と規制#

2 つの独立したエントランス ファミリは、一度に 2 つのうちの 1 つを統合します。

  • ErikaHandle — pull モデル。ホストが描画し、状態を取得します。
  • ErikaPresenterHandle — push モデル。エンジンがデコード、タイミング、音声、描画を管理し、ホストはサーフェスを提供して render_tick を呼びます。macOS / iOS / tvOS / Windows / Android / OpenHarmony / Linux で利用でき、それ以外の対象では create が NULL を返します。

世界的な合意:

  • ステータスを返す関数は ErikaStatus を使います。Ok（0）と NoEvent（5）はエラーではありません。ポインタ、数値、または void を返す関数の失敗条件はヘッダーを確認してください。多くのステータス関数は panic を捕捉して ErikaStatus_Panic を返しますが、全入口で捕捉される保証はなく、panic-abort ビルドではプロセスが終了することがあります。
  • 一部の失敗はスレッドローカルのエラーメッセージを設定しますが、すべての失敗で保証されるわけではなく、空または以前のメッセージの場合があります。失敗したスレッドで次の呼び出しの前に erika_last_error_message() から利用可能なメッセージを取得し、非 NULL の結果を erika_string_free() で解放してください。 例えば、erika_add_external_subtitle の out_track_id が NULL の場合は NullPointer を直接返し、スロットは更新されません。
  • liberika が返す char* は呼び出し元が所有します。独立した文字列は erika_string_free() で、ErikaTrackInfo / ErikaDanmakuTrackInfo 内の文字列は対応する *_info_free() で解放します。
  • const char* パラメータは呼び出し中にのみ借用され、NUL で終わる UTF-8 である必要があります。
  • リスト クエリでは、カウントされた配列イディオムを使用します。(buf, capacity, &len)。len 合計数に設定し、最大で書き込みます capacity バー; capacity が 0 で、buf が NULL の場合、数量のみが照会されます。
  • attach と resize の幅と高さは物理ピクセルです。 scale は、地表範囲をスケーリングしない、UI (弾幕など) / DPI 比の論理内容です。
  • handle は内部同期を提供しないため、複数のスレッドから同時に呼び出すことはできません。

ErikaSubtitleStyle

字幕のフォールバック表示は、不透明な白文字（0xFFFFFFFF）と半透明の黒い縁取り（0x0000007F）が既定です。範囲外の数値はクランプし、border_style と alignment は範囲外なら既定値 1 / 2 を使います。コンテナ内 ASS トラックでは、override_mask が 0 のときフォントファミリーのフォールバックを除きこれらのフィールドは効きません。対応するビットを立てると ASS の dialogue で宣言されたスタイルを上書きします。SRT/WebVTT のプレーンテキスト字幕では、liberika が生成する ASS ヘッダーにスタイル全体を反映し、override_mask には依存しません。すべての寸法は ASS スクリプト単位で、set_subtitle_scale を掛けます。

ErikaDanmakuConfig

字幕スタイルオーバーライドマスク

http_read_ahead_bytes 前方に読み取るバイト数を決定します。デフォルトは 2 MiB です。http_back_buffer_bytes 保持する再生データの量を決定します。デフォルトは 16 MiB です。両方を省略するか、0 を渡してデフォルト値を使用します。先読みのデフォルト値は次のように指定することもできます。 ERIKA_HTTP_READAHEAD_BYTES 設定。

巻き戻しキャッシュ内の後方 seek は、ダウンロードされたデータを直接再利用できます。高ビットレートのビデオには、より大きな予算が必要です。80 Mbit/s のビデオを約 10 秒保持するには、約 100 MB が必要になります。キャッシュはバイト数によって制限されており、固定の再生秒数を表しません。
