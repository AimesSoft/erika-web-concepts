JSON bridge

JSON Bridge Reference

Three JSON variant functions with 47 named methods. For use by hosts that have used platform channels to serialize structured parameters, such as Dart FFI hosts MethodChannel one side. The method covers Presenter operation, global log and frame export, and the parameters are passed in through the JSON object; use listMethods to query the interfaces supported by the runtime.

Call the named method. The returned JSON string is owned by the caller and is erika_string_free release.

render_tick The JSON variant, returns the statistic JSON.

char *erika_presenter_poll_event_json(ErikaPresenterHandle *handle)

poll_event The JSON variant. Returns NULL when the event queue is empty.

The release rules of the returned string are consistent with C:invoke_json / render_tick_json The result of erika_string_free；poll_event_json The free NULL does not need to be released. Unknown method name returns error response.

response envelopeレスポンス#

Successful response:

{ "ok": true, "status": 0, "value": /* 方法返回值，无值时为 null */ }

Failure response:

{ "ok": false, "status": 3, "error": "human readable message" }

Check ok. The bridge may generate argument or method errors itself. For C API failures it reads the thread-local message, falling back to a status description if the slot is empty. A caught panic becomes an error response; uncaught panics or panic-abort builds may terminate the process. C API non-Ok statuses are mapped to status: 3.

event return shapeイベント#

poll_event_json The event object fields are the same as ErikaEvent One-to-one correspondence, kind is an integer (0–12, seeC ABI Overviewevent table):

{ "kind": 1, "status": 0, "state": 2, "durationMicros": 0,
  "positionMicros": 0, "buffering": false,
  "video": { "width": 0, "height": 0, "primaries": 0, "transfer": 0 },
  "tracks": { "video": 0, "audio": 0, "subtitle": 0 } }

Three kind come with extra fields:Error(9)Attachment error string;VideoDecoderChanged(11)Attachment decoder with message;AudioOutputChanged(12)Attachment audio with message. Returns NULL when the queue is empty.

Interface Discovery, Chapters and Diagnostics · 0.3.0#

listMethods Return {schema, methods}. Each item contains name, scope, summary, arguments (name / type / required), returns, blocking and writesFiles; whichever table is returned during the current run. The global method does not require handle, and the Presenter method needs to be valid handle; the table entry describes the behavior of synchronous blocking and possible file writing, and does not represent asynchronous task scheduling.

Chapter position in milliseconds, endMs can be null; passed to seek Convert startMs to microseconds. Single frame and batch export are synchronous blocking operations that can write files and must be executed in the UI working thread. Export multiplexing decoders in batches. Failure of a single frame will be recorded in the corresponding entry, and the rest will continue.

The export includes timestampMicros, source dimensions, and toneMapped; HDR maps to SDR. For detailed memory and thread rules, seeFrame export C entry. limit=0 of the log reads all reserved entries, sinceSeq uses the last nextSeq; the log ring can retain up to 2000 entries / 512 KiB.

ExampleExample#

// seek 到 30 秒
char *out = erika_presenter_invoke_json(p,
    "seek", "{ \"positionMicros\": 30000000 }");
// {"ok":true,"status":0,"value":null}
erika_string_free(out);

// 打开并附带请求头:httpHeaders 是"名称:值"对象,不是数组
out = erika_presenter_invoke_json(p, "open",
    "{ \"uri\": \"https://example.com/v.mp4\", "
    "\"httpHeaders\": { \"Referer\": \"https://example.com\" } }");
erika_string_free(out);

// 事件轮询：队列为空时返回 NULL
char *ev = erika_presenter_poll_event_json(p);
if (ev) { erika_string_free(ev); }
