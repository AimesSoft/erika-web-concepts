JSON bridge

JSON Bridge Reference

Three JSON variant functions and 47 named methods, for hosts that already serialize structured parameters over a platform channel, such as the MethodChannel side of a Dart FFI host. The methods cover Presenter operations, global logging, and frame export. Parameters are passed as a JSON object; call listMethods to query the interfaces the runtime supports.

  • Methods 47
  • Naming camelCase

Entry functions入口関数#

char *erika_presenter_invoke_json(ErikaPresenterHandle *handle, const char *method, const char *arguments_json)

Calls a named method. The returned JSON string is owned by the caller; release it with erika_string_free.

char *erika_presenter_render_tick_json(ErikaPresenterHandle *handle, double time_seconds)

JSON variant of render_tick; returns the statistics as JSON.

char *erika_presenter_poll_event_json(ErikaPresenterHandle *handle)

JSON variant of poll_event. Returns NULL when the event queue is empty.

Ownership of returned strings follows the same rules as the C API: release results from invoke_json and render_tick_json with erika_string_free; the NULL that poll_event_json returns when idle needs no release. An unknown method name returns an error response.

Response envelopeレスポンス#

Success response:

{ "ok": true, "status": 0, "value": /* method return value; null when there is none */ }

Failure response:

{ "ok": false, "status": 3, "error": "human readable message" }

Check the ok field. The bridge layer can generate argument or method errors on its own. When a C call fails, it reads the thread-local message and, if that is empty, generates a description from the status. A caught panic becomes an error response; a panic outside the catch scope, or a panic-abort build, may terminate the process. Any non-Ok status from the C layer maps to status: 3.

Event return shapeイベント#

The fields of the event object from poll_event_json correspond one-to-one to ErikaEvent. kind is an integer (0–12; see the event table in the C ABI overview):

{ "kind": 1, "status": 0, "state": 2, "durationMicros": 0,
  "positionMicros": 0, "buffering": false,
  "video": { "width": 0, "height": 0, "primaries": 0, "transfer": 0 },
  "tracks": { "video": 0, "audio": 0, "subtitle": 0 } }

Three kinds carry extra fields: Error (9) adds an error string; VideoDecoderChanged (11) adds decoder and message; AudioOutputChanged (12) adds audio and message. Returns NULL when the queue is empty.

setDanmakuConfig is read-modify-write: only the keys you pass are overwritten, and fields you omit keep their current values. Boolean keys: enabled, mergeDuplicates, allowStacking, allowScrollOverwrite, blockTop, blockBottom, blockScroll; numeric keys: fontSize, opacity, displayArea, scrollDurationSeconds, scrollSpeedFactor, trackGapRatio, outlineWidth, shadowOffsetX, shadowOffsetY, maxQuantity, maxLinesPerMode, shadowStyle. There are also two conditional keys: when customFontFamily or customFontFilePath is present, the call goes through erika_presenter_set_danmaku_font; when blockWordsJson is present, it goes through erika_presenter_set_danmaku_block_words_json.

Method discovery, chapters, and diagnostics · 0.3.0#

listMethods returns {schema, methods}. Each entry contains name, scope, summary, arguments (name / type / required), returns, blocking, and writesFiles; the table that the current runtime returns is authoritative. Global methods need no handle; Presenter methods need a valid handle. The entries describe synchronous blocking and possible file writes; they do not imply asynchronous task scheduling.

C

char *methods = erika_presenter_invoke_json(NULL, "listMethods", "{}");
// Parse, then free
erika_string_free(methods);

exportFrameuri, positionMillis; optional width, height, format (png / rgba), outputPath, overwrite, httpHeaders, httpReadAheadBytes. Returns dataBase64 when no path is specified.global
exportFramesuri, positionsMillis, outputDir; the other options are the same as for single-frame export. Returns the source size, duration, seek and decode counts, and per-frame results.global

Chapter positions are in milliseconds, and endMs can be null; to pass one to seek, convert startMs to microseconds. Single-frame and batch export are synchronous, blocking operations that may write files, so run them on a worker thread, not the UI thread. Batch export reuses the decoder; if a single frame fails, the failure is recorded on its entry and the rest continue.

Export results include timestampMicros, the source dimensions, and toneMapped; HDR is tone-mapped to SDR. For the detailed memory and threading rules, see Frame export C entry points. A log limit of 0 reads all retained entries, and sinceSeq takes the nextSeq from the previous call. The log ring keeps at most 2000 entries / 512 KiB.

Example例#

// Seek to 30 seconds
char *out = erika_presenter_invoke_json(p,
    "seek", "{ \"positionMicros\": 30000000 }");
// {"ok":true,"status":0,"value":null}
erika_string_free(out);

// Open with request headers: httpHeaders is a name-to-value object, not an array
out = erika_presenter_invoke_json(p, "open",
    "{ \"uri\": \"https://example.com/v.mp4\", "
    "\"httpHeaders\": { \"Referer\": \"https://example.com\" } }");
erika_string_free(out);

// Poll for events: returns NULL when the queue is empty
char *ev = erika_presenter_poll_event_json(p);
if (ev) { erika_string_free(ev); }
