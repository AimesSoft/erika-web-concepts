C ABI Overview

Global conventions and type definitions for the C ABI. The function lists are split by entry family: ErikaHandle (23), ErikaPresenterHandle (72), and general and standalone entry points (13). crates/erika_capi/include/erika.h is the sole authority.

  • Types 45
  • Event kinds 12

Entry points and conventions入口と規約#

There are two independent entry families. Integrate one or the other, not both:

  • ErikaHandle — pull model. The host renders and polls state.
  • ErikaPresenterHandle — push model. The engine manages decoding, timing, audio, and rendering; the host provides a surface and calls render_tick. Available on macOS / iOS / tvOS / Windows / Android / OpenHarmony / Linux; on other targets create returns NULL.

Global conventions:

  • Functions that return a status use ErikaStatus: Ok (0) and NoEvent (5) are non-error results. Other functions return pointers, values, or nothing; consult the header for their failure conventions. Many status-returning operations catch panics as ErikaStatus_Panic, but not every entry point catches panics, and panic-abort builds can terminate the process.
  • Some failures set a thread-local error message, but not every failure guarantees one; the slot may be empty or retain an earlier message. On the thread where the call failed, before making another call, read any available message with erika_last_error_message() and free a non-null result with erika_string_free(). For example, erika_add_external_subtitle returns NullPointer directly when out_track_id is NULL, without updating the slot.
  • A char* returned by liberika belongs to the caller. Free independent strings with erika_string_free(); release strings inside ErikaTrackInfo / ErikaDanmakuTrackInfo with the matching *_info_free().
  • const char* parameters are borrowed only for the duration of the call and must be NUL-terminated UTF-8.
  • List queries use the counted-array idiom (buf, capacity, &len). len is set to the total count, and at most capacity entries are written. When capacity is 0 and buf is NULL, the call only queries the count.
  • The width and height passed to attach and resize are in physical pixels. scale is the DPI ratio for logical content such as UI and danmaku; it does not scale the surface extent.
  • A handle has no internal synchronization and must not be called concurrently from multiple threads.

ErikaEventKindイベント#

The enum has 13 values: 12 event kinds and None, which represents no event.

Events are retrieved with poll_event. The queue is unbounded: a host that never polls only accumulates events and stops observing state; no events are dropped. Only one group of fields in ErikaEvent is valid, as determined by kind. ErikaSubtitleStyle

Fallback subtitle appearance defaults to opaque white text (0xFFFFFFFF) with a translucent black outline (0x0000007F). Out-of-range numeric metrics are clamped rather than rejected; an out-of-range border_style or alignment is replaced with its default (1 and 2, respectively). How the fields take effect depends on the subtitle type. On container ASS tracks, these fields have no effect when override_mask is 0, except for font-family fallback; setting a bit makes the corresponding field override the style declared by the ASS dialogue. For plain-text subtitles (SRT/WebVTT), liberika bakes the whole style into the ASS header it generates, regardless of override_mask. All dimensions are in ASS script units and are multiplied by the set_subtitle_scale factor.

When an override bit is set, dimensions stay resolution-independent: a font_size of 48 yields the same pixel size regardless of the PlayResY the script declares. Margins are the exception: on container ASS tracks they scale with the script’s PlayResY, while on plain-text subtitles they are in pixels (liberika generates that script to match the frame size). With a zero mask, all fields stay fallback-only: they have no effect on container tracks, and erika_presenter_set_subtitle_style only influences font selection.

For max_lines_per_mode, “per mode” means one limit each for scroll-left, scroll-right, top, and bottom. set_danmaku_config replaces the fields visible from C; block_words and the custom font fields are inherited from the current configuration.

Subtitle style override mask

override_mask is a bitwise OR of ERIKA_SUBTITLE_OVERRIDE_* values, which mirror libass’s ASS_OVERRIDE_BIT_* values. Setting a bit makes the corresponding fields override the style that an ASS dialogue event requests, instead of acting as a fallback; 0 keeps all fields as fallbacks. Unknown bits are discarded.

http_read_ahead_bytes sets how many bytes to read ahead (default 2 MiB). http_back_buffer_bytes sets how much already-played data to keep (default 16 MiB). Omit either one or pass 0 to use its default. You can also set the read-ahead default with ERIKA_HTTP_READAHEAD_BYTES.

A backward seek that lands inside the back buffer reuses the data already downloaded. High-bitrate video needs a larger budget: keeping about 10 seconds of an 80 Mbit/s stream takes roughly 100 MB. The cache is limited by bytes, not by a fixed number of seconds of playback.
