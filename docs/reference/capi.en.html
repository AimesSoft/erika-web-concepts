Entrance and AgreementEntrance and regulations#

Two independent entrance families, integrate one of the two at a time:

  • ErikaHandle — pull model. The host renders and polls state.
  • ErikaPresenterHandle — push model. The engine manages decoding, timing, audio, and rendering; the host provides a surface and calls render_tick. Available on macOS / iOS / tvOS / Windows / Android / OpenHarmony / Linux; on other targets create returns NULL.

Global agreement:

  • Functions that return a status use ErikaStatus: Ok (0) and NoEvent (5) are non-error results. Other functions return pointers, values, or nothing; consult the header for their failure conventions. Many status-returning operations catch panics as ErikaStatus_Panic, but not every entry point catches panics, and panic-abort builds can terminate the process.
  • Some failures set a thread-local error message, but not every failure guarantees one; the slot may be empty or retain an earlier message. On the same thread, before another call, read any available message with erika_last_error_message() and free a non-null result with erika_string_free(). For example, erika_add_external_subtitle returns NullPointer directly when out_track_id is NULL, without updating the slot.
  • A char* returned by liberika belongs to the caller. Free independent strings with erika_string_free(); release strings inside ErikaTrackInfo / ErikaDanmakuTrackInfo with the matching *_info_free().
  • const char* Parameters are only borrowed during the call and must be UTF-8 ending in NUL.
  • List queries use the counted array idiom:(buf, capacity, &len)。len Set to total number, write at most capacity Bar; when capacity is 0 and buf is NULL, only the quantity is queried.
  • The width and height of attach and resize are physical pixels. scale is the logical content of UI (danmaku, etc.) / DPI ratio, without scaling the surface range.
  • A handle provides no internal synchronization and may not be called concurrently from multiple threads.

ErikaSubtitleStyle

Subtitle fallback appearance defaults to opaque white text (0xFFFFFFFF) with a translucent black outline (0x0000007F). Out-of-range numeric metrics are clamped; out-of-range border_style and alignment use defaults 1 and 2. On container ASS tracks, these fields have no effect when override_mask is 0, except font-family fallback. Setting a bit overrides the corresponding style declared by ASS dialogue. For plain-text SRT/WebVTT, liberika bakes the entire style into its generated ASS header regardless of override_mask. All dimensions use ASS script units and are multiplied by set_subtitle_scale.

http_read_ahead_bytes Determines the number of bytes to read forward, the default is 2 MiB;http_back_buffer_bytes Determine how much played data to keep, the default is 16 MiB. Omit both or pass 0 to use the default value. The readahead default value can also be given by ERIKA_HTTP_READAHEAD_BYTES set up.

A backward seek within the rewind cache can directly reuse the downloaded data. High bitrate videos require a larger budget: a video of 80 Mbit/s would require about 100 MB to retain for about 10 seconds. The cache is limited by bytes and does not represent a fixed number of playback seconds.
