Subtitle font and stylesubtitles#

ErikaStatus erika_presenter_set_subtitle_font(ErikaPresenterHandle *handle, const char *family, const char *file_path)

Set fallback subtitle font. NULL or empty string clears the corresponding half. The container ASS script retains its own fonts unless set_subtitle_style Pass in the font name override bit.

ErikaStatus erika_presenter_register_subtitle_memory_font(ErikaPresenterHandle *handle, const uint8_t *data, uintptr_t data_len, uint64_t *out_font_id)

Register the memory font data and output the font id. The data is not written to the disk, and the renderer rebuilds the cache according to the selected generation of the font: fonts in the selected set will take effect on the activated subtitle track immediately after replacement; fonts that are only registered but not selected will not trigger renderer reconstruction. (Same-name replacements for custom font file paths are detected as mtime/size and reloaded immediately.)

Clear the memory font registry.

ErikaStatus erika_presenter_get_subtitle_memory_font_status(ErikaPresenterHandle *handle, ErikaSubtitleMemoryFontStatus *out_status)

Read registry status (number, bytes, selected font id). The result is used erika_subtitle_memory_font_status_free release.

ErikaStatus erika_presenter_get_subtitle_memory_font_info(ErikaPresenterHandle *handle, uint64_t font_id, ErikaSubtitleMemoryFontInfo *out_info)

diagnostic snapshot#

ErikaStatus erika_presenter_get_diagnostics_json(ErikaPresenterHandle *handle, char **out_json)

Read the decoder and actual hardware decoding path, rendering count and time consumption, output /HDR, audio, buffer depth and scheduling timing at once. Read count only, no decoding, rendering, or waiting for the playback thread; unknown value is null. Comply with the rule that the same handle is not called concurrently.

Return with success schema The caller has all JSON strings, using erika_string_free Released; NULL on failure. When compatible with old native libraries, they are resolved as optional symbols. If they are missing, they are considered not supported. The corresponding method of JSON bridge is getDiagnosticsSnapshot。
