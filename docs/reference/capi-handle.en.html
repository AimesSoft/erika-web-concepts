ErikaHandle Reference

All functions of the pull-model entry point: lifecycle, playback control, tracks and subtitles, state and events, surface attachment, and the general helper functions shared by both entry points. Signatures and comments in erika.h are authoritative.

Playback control再生制御#

ErikaStatus erika_open(ErikaHandle *handle, const char *uri)

Opens media. uri is a local path or an HTTP(S) URL. The call synchronously probes stream information, parses tracks, and sets the state to Ready. After it returns, call the play function to start asynchronous decoding and presentation.

ErikaStatus erika_open_with_headers(ErikaHandle *handle, const char *uri, const ErikaHttpHeader *headers, uintptr_t header_count)

Opens media with custom HTTP request headers.

ErikaStatus erika_open_with_options( ErikaHandle *handle, const char *uri, const ErikaOpenOptions *options)

Opens media with ErikaOpenOptions, which can carry HTTP request headers, the read-ahead window, and the back-buffer budget in a single call. The options are borrowed only for the duration of the call; set reserved to zero. start_position_micros is the starting time in microseconds; 0 opens at the beginning. It occupies the first former reserved slot, so zero-initialized older structs still open at the beginning.

ErikaStatus erika_play(ErikaHandle *handle)

Starts playback. play only enqueues the work; the final outcome is reported by a StateChanged or Error event.

ErikaStatus erika_pause(ErikaHandle *handle)

Pauses playback.

ErikaStatus erika_stop(ErikaHandle *handle)

Stops playback.

ErikaStatus erika_close(ErikaHandle *handle)

Closes the media and releases its resources, moving to the Closed state. Destroy the handle afterward; create a new handle for the next playback.

ErikaStatus erika_seek(ErikaHandle *handle, uint64_t position_micros)

Seeks to the given position, in microseconds.

Standalone GIF export#

ErikaStatus erika_export_gif( const ErikaGifExportOptions *options, ErikaGifExportResult *out_result)

A standalone, synchronous export entry point that needs no player or surface. Times are in milliseconds; UI hosts should run it on a worker thread. On success it fills in the dimensions, frame count, and file size.

C

ErikaGifExportOptions options = {
    .input_uri = "/path/input.mp4",
    .output_path = "/path/output.gif",
    .start_millis = 5000,
    .end_millis = 10000,
    .frames_per_second = 10,
    .output_width = 640,
    .output_height = 360,
    .quality = ErikaGifExportQuality_High,
    .loop_count = 0,
};
ErikaGifExportResult result = {0};
ErikaStatus status = erika_export_gif(&options, &result);

Standalone frame export and logging · 0.3.0#

Frame export is synchronous; UI hosts should run it on a worker thread. The input position_millis is in milliseconds; the result’s timestamp_micros and duration_micros are in microseconds. HDR (PQ / HLG / Dolby Vision) is tone-mapped along the SDR display path, and the result sets ERIKA_FRAME_EXPORT_TONE_MAPPED (1) in reserved_flags.

ErikaStatus erika_export_frame( const ErikaFrameExportOptions *options, ErikaFrameExportResult *out_result)

Standalone, synchronous export of the image at a media timestamp, returned as RGBA or PNG. It preserves the display aspect ratio, scales down to fit within the optional size limits, and never scales up. It has its own demuxer and a multithreaded software decoder, so it needs no player or surface.

void erika_frame_export_result_free(ErikaFrameExportResult *result)

Frees the data in the result and resets the result. Do not substitute erika_string_free or the host’s free.

ErikaStatus erika_frame_export_session_open( const ErikaFrameExportSessionOptions *options, ErikaFrameExportSession **out_session)

Opens a media file once for continuous frame capture and returns a session on success. Zero out reserved and reserved_flags when you initialize the structs.

ErikaStatus erika_frame_export_session_frame( ErikaFrameExportSession *session, const ErikaFrameExportRequest *request, ErikaFrameExportResult *out_result)

Exports the image at the given time from the session. For increasing requests with no intervening keyframe, it keeps decoding; otherwise it seeks again. The result is identical to a single export, and you free each one with result_free.

void erika_frame_export_session_close(ErikaFrameExportSession *session)

Closes and releases the session; accepts NULL. Calls on one session must be serialized: they must not run concurrently with close, and the session must not be used after it is closed.

ErikaStatus erika_log_read_json( uint32_t limit, int32_t min_level, uint64_t since_seq, char **out_json)

Reads the process-wide redacted log ring, which holds at most 2000 entries / 512 KiB. limit=0 reads all retained entries, min_level=-1 applies no level filter, and since_seq takes the previous nextSeq for incremental reads. Callable from any thread with no handle. Free a successful string with erika_string_free; on failure, out_json is NULL.

Standalone frame export decodes only the media image; it does not include the current Presenter’s subtitles or danmaku. Native erika_presenter_capture_frame_rgba includes video and subtitles but not danmaku, while Web capture() includes all three.
