ErikaStatus erika_open(ErikaHandle *handle, const char *uri)

Open media.uri is the local path or HTTP(S) URL. The function synchronously completes stream information detection and track analysis and sets the status to Ready. After returning, it calls the playback function to start asynchronous decoding and presentation.

ErikaStatus erika_open_with_options( ErikaHandle *handle, const char *uri, const ErikaOpenOptions *options)

Use ErikaOpenOptions When opening the media, you can pass in the HTTP request header, read-ahead window and fallback cache budget at the same time. Options are only borrowed during the call,reserved Set to zero.

ErikaStatus erika_play(ErikaHandle *handle)

Start playing. play only delivers work, the final result is StateChanged or Error The event shall prevail.

Stop playing.

ErikaStatus erika_close(ErikaHandle *handle)

Close and release the media resources and enter the Closed state. The handle is then destroyed; a new handle is created for the next playback.

Standalone GIF export#

ErikaStatus erika_export_gif( const ErikaGifExportOptions *options, ErikaGifExportResult *out_result)

Independent sync export portal, no player or surface required. The time unit is milliseconds; UI host runs on a worker thread. After success, fill in the size, frame number and file size.

C

ErikaGifExportOptions options = {
    .input_uri = "/path/input.mp4",
    .output_path = "/path/output.gif",
    .start_millis = 5000,
    .end_millis = 10000,
    .frames_per_second = 10,
    .output_width = 640,
    .output_height = 360,
    .quality = ErikaGifExportQuality_High,
    .loop_count = 0,
};
ErikaGifExportResult result = {0};
ErikaStatus status = erika_export_gif(&options, &result);

Independent frame export and log · 0.3.0#

Frame export is a synchronous operation, and the UI host should be placed on the worker thread. The input position_millis is in milliseconds; the results timestamp_micros and duration_micros are in microseconds. HDR (PQ / HLG / Dolby Vision) will display the path tone map as SDR and place in the result reserved_flags ERIKA_FRAME_EXPORT_TONE_MAPPED（1）。

ErikaStatus erika_export_frame( const ErikaFrameExportOptions *options, ErikaFrameExportResult *out_result)

Independently synchronously exports images at media time, returning RGBA or PNG; maintaining display aspect ratio, scaling within the selectable size range, and not enlarging. Features independent depackager and multi-threaded software decoder, no player or surface required.

void erika_frame_export_result_free(ErikaFrameExportResult *result)

Release data in the result and reset the result. Cannot be replaced by erika_string_free or host free.

ErikaStatus erika_frame_export_session_open( const ErikaFrameExportSessionOptions *options, ErikaFrameExportSession **out_session)

Open the media once for continuous frame capture, and return to the session if successful. Set reserved and reserved_flags to zero when initializing the structure.

ErikaStatus erika_frame_export_session_frame( ErikaFrameExportSession *session, const ErikaFrameExportRequest *request, ErikaFrameExportResult *out_result)

Export the image at the specified time from the session; continue decoding when there is an incremental request and there are no keyframes in the middle, and restart seek in other cases. The result is the same as a single export, calling result_free releases one by one.

void erika_frame_export_session_close(ErikaFrameExportSession *session)

Close and release the session, accepting NULL. Invocations of a session must be serial, cannot be concurrent with close, and cannot be continued after closing.

ErikaStatus erika_log_read_json( uint32_t limit, int32_t min_level, uint64_t since_seq, char **out_json)

Read process-level desensitized log ring: up to 2000 entries / 512 KiB. limit=0 reads all reserved entries, min_level=-1 does not limit the level, since_seq transmits the last nextSeq incremental read. Callable by any thread, no need for handle. The string is released with erika_string_free on success, and out_json is NULL on failure.

Independent frame export only decodes media images and does not include subtitles and danmaku of the current Presenter. Native erika_presenter_capture_frame_rgba Contains video and subtitles, excluding danmaku; Web capture() It includes three.
