C ABI 总览

C ABI Overview

C ABI 的全局约定与类型定义。函数清单按入口族分页：ErikaHandle（22 个）、ErikaPresenterHandle（63 个）、通用辅助函数（6 个）。以 crates/erika_capi/include/erika.h 为唯一权威。

  • 导出函数 91
  • 类型 33
  • 事件 12 种

入口与约定入口と規約#

两个独立的入口族，一次集成二选一：

  • ErikaHandle — pull 模型。宿主渲染并拉取状态。
  • ErikaPresenterHandle — push 模型。内核托管解码、时序、音频与渲染；宿主提供表面并调用 render_tick。编译于 macOS / iOS / Windows / Android / OpenHarmony；其他目标 create 返回 NULL。

全局约定：

  • 每个可能失败的调用返回 ErikaStatus。Ok（0）与 NoEvent（5）是仅有的非错误结果。panic 被捕获并映射为 ErikaStatus_Panic。
  • 非 Ok/NoEvent 结果的人读消息存放在线程局部槽位。在同一线程经 erika_last_error_message() 读取，用 erika_string_free() 释放。
  • Erika 返回的 char* 归调用方所有。独立字符串用 erika_string_free()；ErikaTrackInfo / ErikaDanmakuTrackInfo 内的字符串用配套的 *_info_free()。
  • const char* 参数仅调用期间借用，必须是 NUL 结尾的 UTF-8。
  • 列表查询使用计数数组惯用法：(buf, capacity, &len)。len 置为总数，最多写入 capacity 条；capacity 为 0 且 buf 为 NULL 时只查询数量。
  • attach 与 resize 的宽高是物理像素。scale 是 UI（弹幕等）的逻辑内容 / DPI 比例，不缩放表面范围。
  • 一个 handle 不提供内部同步，不得从多个线程并发调用。

ErikaStatusステータス#

值名称含义
0Ok成功。
1NullPointer参数为空指针。
2InvalidUtf8字符串参数不是合法 UTF-8。
3PlayerError播放器错误。
4Panic内部 panic，已捕获。
5NoEvent事件队列为空（非错误）。

ErikaState状態#

值名称含义
0Idle创建后的初始状态。
1Opening打开中。

3Playing播放中。
4Paused已暂停。
5Stopped已停止。
6Closed已关闭。
7Error错误状态。
