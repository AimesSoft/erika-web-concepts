再生コントロール回生制御#

ErikaStatus erika_open(ErikaHandle *handle, const char *uri)

メディアを開きます。uri ローカル パスまたは HTTP(S) URL です。この関数はストリーム情報の検出とトラック分析を同期して完了し、ステータスを Ready に設定します。戻った後、再生関数を呼び出して、非同期デコードとプレゼンテーションを開始します。

ErikaStatus erika_open_with_headers(ErikaHandle *handle, const char *uri, const ErikaHttpHeader *headers, uintptr_t header_count)

カスタム HTTP リクエスト ヘッダーを持つメディアを開きます。

ErikaStatus erika_open_with_options( ErikaHandle *handle, const char *uri, const ErikaOpenOptions *options)

使用する ErikaOpenOptions メディアを開くときに、HTTP リクエスト ヘッダー、先読みウィンドウ、およびフォールバック キャッシュ バジェットを同時に渡すことができます。オプションは通話中にのみ借りられますが、reserved ゼロに設定します。 start_position_micros は開始位置（マイクロ秒）で、0 は先頭から開きます。従来の最初の reserved 枠を使うため、ゼロ初期化した旧構造体は先頭から開きます。

ErikaStatus erika_play(ErikaHandle *handle)

プレイを開始します。 play は作業のみを提供します。最終結果は次のとおりです。 StateChanged または Error イベントが優先されます。

ErikaStatus erika_pause(ErikaHandle *handle)

再生を一時停止します。

ErikaStatus erika_stop(ErikaHandle *handle)

遊ぶのをやめてください。

ErikaStatus erika_close(ErikaHandle *handle)

メディア リソースを閉じて解放し、Closed 状態に入ります。その後、ハンドルは破壊されます。次の再生のために新しいハンドルが作成されます。

ErikaStatus erika_seek(ErikaHandle *handle, uint64_t position_micros)

マイクロ秒単位で指定された場所にジャンプします。

スタンドアロン GIF エクスポート#

ErikaStatus erika_export_gif( const ErikaGifExportOptions *options, ErikaGifExportResult *out_result)

独立した同期エクスポート ポータル。プレーヤーやサーフェスは必要ありません。時間の単位はミリ秒です。 UI ホストはワーカー スレッドで実行されます。成功したら、サイズ、フレーム番号、ファイル サイズを入力します。

C

ErikaGifExportOptions options = {
    .input_uri = "/path/input.mp4",
    .output_path = "/path/output.gif",
    .start_millis = 5000,
    .end_millis = 10000,
    .frames_per_second = 10,
    .output_width = 640,
    .output_height = 360,
    .quality = ErikaGifExportQuality_High,
    .loop_count = 0,
};
ErikaGifExportResult result = {0};
ErikaStatus status = erika_export_gif(&options, &result);

独立したフレームのエクスポートとログ · 0.3.0#

フレームのエクスポートは同期操作であり、UI ホストをワーカー スレッドに配置する必要があります。入力 position_millis はミリ秒単位です。結果の timestamp_micros と duration_micros の単位はマイクロ秒です。 HDR (PQ / HLG / Dolby Vision) は、パス トーン マップを SDR として表示し、結果 reserved_flags に配置します。 ERIKA_FRAME_EXPORT_TONE_MAPPED（1）。

ErikaStatus erika_export_frame( const ErikaFrameExportOptions *options, ErikaFrameExportResult *out_result)

メディア時に画像を個別に同期的にエクスポートし、RGBA または PNG を返します。表示のアスペクト比を維持し、選択可能なサイズ範囲内で拡大縮小し、拡大しません。独立したデパッケージャーとマルチスレッド ソフトウェア デコーダーを備えており、プレーヤーやサーフェスは必要ありません。

void erika_frame_export_result_free(ErikaFrameExportResult *result)

結果内の data を放し、結果をリセットします。 erika_string_free またはホスト free で置き換えることはできません。

ErikaStatus erika_frame_export_session_open( const ErikaFrameExportSessionOptions *options, ErikaFrameExportSession **out_session)

連続フレーム キャプチャのためにメディアを 1 回開き、成功した場合はセッションに戻ります。構造体を初期化するときに、reserved と reserved_flags をゼロに設定します。

ErikaStatus erika_frame_export_session_frame( ErikaFrameExportSession *session, const ErikaFrameExportRequest *request, ErikaFrameExportResult *out_result)

指定した時刻にセッションから画像をエクスポートします。インクリメンタルリクエストがあり、途中にキーフレームがない場合はデコードを続行し、それ以外の場合は seek を再起動します。結果は、result_free リリースを 1 つずつ呼び出す単一のエクスポートと同じになります。

void erika_frame_export_session_close(ErikaFrameExportSession *session)

NULL を受け入れて、セッションを閉じて解放します。セッションの呼び出しはシリアルである必要があり、close と同時に行うことはできず、終了後に続行することもできません。

ErikaStatus erika_log_read_json( uint32_t limit, int32_t min_level, uint64_t since_seq, char **out_json)

プロセスレベルの感度を下げたログリングの読み取り: 最大 2000 エントリ / 512 KiB。 limit=0 はすべての予約済みエントリを読み取り、min_level=-1 はレベルを制限せず、since_seq は最後の nextSeq 増分読み取りを送信します。どのスレッドからも呼び出すことができ、handle は必要ありません。文字列は成功すると erika_string_free で解放され、失敗すると out_json が NULL になります。

独立したフレームのエクスポートでは、メディア イメージのみがデコードされ、現在の Presenter の字幕と弾幕は含まれません。ネイティブ erika_presenter_capture_frame_rgba 弾幕を除くビデオと字幕が含まれます。 Web capture() 3つ含まれます。
