播放与运行参数再生#

ErikaStatus erika_presenter_open(ErikaPresenterHandle *handle, const char *uri)

打开媒体。uri 是本地路径或 HTTP(S) URL。函数同步完成流信息探测与轨道解析并将状态置为 Ready，返回后调用播放函数开始异步解码与呈现。

ErikaStatus erika_presenter_open_with_headers(ErikaPresenterHandle *handle, const char *uri, const ErikaHttpHeader *headers, uintptr_t header_count)

带自定义 HTTP 请求头打开媒体。

ErikaStatus erika_presenter_open_with_options( ErikaPresenterHandle *handle, const char *uri, const ErikaOpenOptions *options)

使用 ErikaOpenOptions 打开媒体，可同时传入 HTTP 请求头、预读窗口与回退缓存预算。选项只在调用期间借用，reserved 置零。 start_position_micros 为起始时间（微秒）；0 从头打开。该字段占用原首个保留位，清零的旧结构保持从头打开。

ErikaStatus erika_presenter_play(ErikaPresenterHandle *handle)

开始播放。play 只投递工作，最终结果以 StateChanged 或 Error 事件为准。

ErikaStatus erika_presenter_pause(ErikaPresenterHandle *handle)

暂停播放。

ErikaStatus erika_presenter_stop(ErikaPresenterHandle *handle)

停止播放。

ErikaStatus erika_presenter_close(ErikaPresenterHandle *handle)

关闭并释放媒体资源。

ErikaStatus erika_presenter_seek(ErikaPresenterHandle *handle, uint64_t position_micros)

跳转到指定位置，单位为微秒。

ErikaStatus erika_presenter_set_playback_rate(ErikaPresenterHandle *handle, double rate)

设置播放倍速。1.0 为正常速度，钳制到 0.25–16×。

ErikaStatus erika_presenter_set_volume(ErikaPresenterHandle *handle, double volume)

设置音量，范围为 0.0–1.0。

ErikaStatus erika_presenter_set_upscaler(ErikaPresenterHandle *handle, int32_t mode)

设置超分模式，取 ErikaLumaUpscalerMode。Metal 与具备 compute 能力的 wgpu/Vulkan 渲染器执行 ArtCNN；其他后端保留原生亮度采样并显式上报 Inactive。

ErikaStatus erika_presenter_set_subtitle_scale(ErikaPresenterHandle *handle, double scale)

设置字幕缩放比例。

字幕字体与样式字幕#

ErikaStatus erika_presenter_set_subtitle_font(ErikaPresenterHandle *handle, const char *family, const char *file_path)

设置回退字幕字体。NULL 或空串清除对应的半边。容器 ASS 脚本保留自己的字体，除非经 set_subtitle_style 传入字体名覆盖位。

ErikaStatus erika_presenter_register_subtitle_memory_font(ErikaPresenterHandle *handle, const uint8_t *data, uintptr_t data_len, uint64_t *out_font_id)

注册内存字体数据，输出字体 id。数据不写盘，渲染器按字体的选中代际重建缓存：被选中集合内的字体在替换后立即对激活的字幕轨生效；仅注册而未选中的字体不会触发渲染器重建。（自定义字体文件路径的同名替换则按 mtime/size 检测并立即重载。）

ErikaStatus erika_presenter_select_subtitle_memory_fonts(ErikaPresenterHandle *handle, const uint64_t *font_ids, uintptr_t font_count)

选择有序回退字体集合。

ErikaStatus erika_presenter_clear_subtitle_memory_fonts(ErikaPresenterHandle *handle)

清空内存字体注册表。

ErikaStatus erika_presenter_get_subtitle_memory_font_status(ErikaPresenterHandle *handle, ErikaSubtitleMemoryFontStatus *out_status)

读取注册表状态（数量、字节数、选中的字体 id）。结果用 erika_subtitle_memory_font_status_free 释放。

ErikaStatus erika_presenter_get_subtitle_memory_font_info(ErikaPresenterHandle *handle, uint64_t font_id, ErikaSubtitleMemoryFontInfo *out_info)

读取指定字体的 faces 与元数据。结果用 erika_subtitle_memory_font_info_free 释放。

ErikaStatus erika_presenter_set_subtitle_style(ErikaPresenterHandle *handle, ErikaSubtitleStyle style)

应用字幕样式覆盖。覆盖粒度由 style.override_mask 的位标志控制,各字段的取值与钳制范围见C ABI 总览的类型节。

表面与呈现サーフェス#

渲染后端（原生 Metal、原生 D3D11 或 wgpu）由 presenter 配置决定，与附着调用无关。任何 drawable 尺寸或 scale 变化都要调用 resize_surface。

ErikaStatus erika_presenter_attach_metal_layer(ErikaPresenterHandle *handle, uint64_t raw_layer, uint32_t width, uint32_t height, double scale)

附着 Metal 表面（macOS / iOS）。raw_layer 是 CAMetalLayer* 转为 uint64_t。

ErikaStatus erika_presenter_attach_wgpu_surface(ErikaPresenterHandle *handle, ErikaWgpuSurfaceKind kind, uint64_t raw_window, uint64_t raw_display, uint32_t width, uint32_t height, double scale)

附着 wgpu 表面。raw_window / raw_display 是对应 kind 的平台句柄。

ErikaStatus erika_presenter_attach_wgpu_surface_with_output_capabilities(ErikaPresenterHandle *handle, ErikaWgpuSurfaceKind kind, uint64_t raw_window, uint64_t raw_display, uint32_t width, uint32_t height, double scale, ErikaSurfaceOutputCapabilities output_capabilities)

带输出能力声明附着 wgpu 表面，用于 HDR 协商。

ErikaStatus erika_presenter_attach_windows_hwnd(ErikaPresenterHandle *handle, uint64_t hwnd, uint64_t hinstance, uint32_t width, uint32_t height, double scale)

附着 Windows 表面。封装 attach_wgpu_surface 的 WindowsHwnd 变体：hwnd 为 HWND，hinstance 为 HINSTANCE。

ErikaStatus erika_presenter_attach_flutter_texture(ErikaPresenterHandle *handle, ErikaFlutterTextureKind kind, int64_t texture_id, uint32_t width, uint32_t height, double scale)

绑定由 texture registrar 的 texture_id 标识的 Flutter 纹理表面（目前为 Apple 的 MacOsTextureRegistrar/IosTextureRegistrar）。pixel buffer 所有权始终在宿主侧。

ErikaStatus erika_presenter_set_flutter_texture_buffer(ErikaPresenterHandle *handle, uint64_t raw_texture, uint32_t width, uint32_t height)

在每次 render_tick 之前，选定下一帧要渲染的宿主 GPU 纹理。Apple 上 raw_texture 是强转为 uint64_t 的 id<MTLTexture>，必须为 BGRA8Unorm 且尺寸与声明一致。纹理只在当帧内被借用，宿主在 render_tick 返回后可复用或释放。

ErikaStatus erika_presenter_windows_composition_swapchain_iunknown(ErikaPresenterHandle *handle, void **out_swapchain)

仅限 Windows。以 direct_composition 能力附着、且以透明 alpha 模式或 overlay 混合播放时，返回 liberika 创建的预乘 alpha DirectComposition swap chain。返回的 IUnknown 已 AddRef，调用者拥有该 COM 引用并必须 Release；解码器或输出设备重建 swap chain 后需重新获取（指针未变说明没有重建）。

ErikaStatus erika_presenter_resize_surface(ErikaPresenterHandle *handle, uint32_t width, uint32_t height, double scale)

调整表面尺寸或 scale。任何 drawable 尺寸变化后调用。

ErikaStatus erika_presenter_detach_surface(ErikaPresenterHandle *handle)

分离当前表面。

截图スクリーンショット#

显示目标时间#

ErikaStatus erika_presenter_render_tick_with_timing( ErikaPresenterHandle *handle, double time_seconds, const double *presentation_delay_seconds, ErikaPresenterStats *out_stats)

presentation_delay_seconds 是从调用入口到显示目标时刻的秒数，可为负数，范围 ±0.25 秒。传 NULL 保持 render_tick 的采样行为。字幕、弹幕与视频使用同一目标时刻快照，不改变播放时钟。

诊断快照#

ErikaStatus erika_presenter_get_diagnostics_json(ErikaPresenterHandle *handle, char **out_json)

一次读取解码器及实际硬解路径、呈现计数与耗时、输出/HDR、音频、缓冲深度及调度时序。仅读计数，不解码、不渲染，也不等待播放线程；未知值为 null。遵守同一 handle 不并发调用的规则。

成功时返回带 schema 的调用方所有 JSON 字符串，用 erika_string_free 释放；失败时为 NULL。兼容旧原生库时按可选符号解析，缺失即视为不支持。JSON bridge 的对应方法为 getDiagnosticsSnapshot。

播放与原生纹理接口#

ErikaStatus erika_presenter_set_open_start_position(ErikaPresenterHandle *handle, uint64_t position_micros)

为下一次未指定非零起始位置的 open 设置起点；单位微秒，0 清除，使用后取走。

ErikaStatus erika_presenter_set_subtitle_delay(ErikaPresenterHandle *handle, int64_t delay_micros)

正值使字幕延后、负值使其提前；内嵌和外挂字幕均适用，范围限制在 ±10 分钟，0 恢复原时间戳。

ErikaStatus erika_presenter_set_danmaku_random_colors(ErikaPresenterHandle *handle, bool enabled)

设置弹幕随机颜色是否启用。

ErikaStatus erika_presenter_capture_frame_rgba_with_danmaku(ErikaPresenterHandle *handle, uint32_t width, uint32_t height, uint8_t *out_rgba, uintptr_t out_capacity)

输出 SDR RGBA8，包含视频、字幕和已启用的弹幕，不含 debug HUD；不需要 surface 或预先 render tick，缓冲至少 width × height × 4 字节。

ErikaPresenterHandle *erika_presenter_create_for_texture_export(ErikaPresenterConfig config)

选择 WgpuFallback 用于原生纹理导出；失败时返回 NULL 并设置 last_error。

ErikaStatus erika_presenter_export_frame_texture(ErikaPresenterHandle *handle, uint32_t width, uint32_t height, double content_scale, ErikaTextureFrame **out_frame)

从 WgpuFallback 导出不可变 SDR 原生纹理，包含视频、字幕与已启用弹幕，不含 HUD。支持 Linux Vulkan OPAQUE_FD 和 Apple Metal；无需 surface、Flutter 注册器、CPU 读回或 GPU 纹理复制。返回前等待生产端 GPU 完成，并驱动音频；NoEvent 表示尚无视频，非 Ok 时 out_frame 为 NULL。

ErikaStatus erika_texture_frame_get_info(const ErikaTextureFrame *frame, ErikaExternalTextureInfo *out_info)

纹理帧可比 presenter 活得更久；消费者 GPU 工作及导入别名结束后再 release。get_info 的句柄为借用：Metal 可独立 retain 并覆盖消费期间；Vulkan OPAQUE_FD（0 也有效）导入前须 dup，匹配设备和驱动 UUID，并按相同属性导入专用分配；读取前从 EXTERNAL 获取队列所有权，旧布局 GENERAL。纹理只读、UNORM 存储中的像素为 sRGB 编码 RGBA。

void erika_texture_frame_release(ErikaTextureFrame *frame)

消费者 GPU 工作和导入别名结束后释放。
