JSON bridge

JSON Bridge Reference

47 の名前付きメソッドを持つ 3 つの JSON バリアント関数。 Dart FFI ホストなど、構造化パラメーターをシリアル化するためにプラットフォーム チャネルを使用したホストで使用します。 MethodChannel 片側。このメソッドは、Presenter 操作、グローバル ログ、フレーム エクスポートをカバーしており、パラメータは JSON オブジェクトを通じて渡されます。 listMethods を使用して、ランタイムでサポートされているインターフェイスをクエリします。

  • 方法 47 ある
  • 名前 camelCase

エントリー機能入口レベルの数#

char *erika_presenter_invoke_json(ErikaPresenterHandle *handle, const char *method, const char *arguments_json)

指定されたメソッドを呼び出します。返された JSON 文字列は呼び出し元が所有しており、 erika_string_free リリース。

char *erika_presenter_render_tick_json(ErikaPresenterHandle *handle, double time_seconds)

render_tick JSON バリアントは、統計 JSON を返します。

char *erika_presenter_poll_event_json(ErikaPresenterHandle *handle)

poll_event JSON のバリアント。イベントキューが空の場合は、NULLを返します。

返される文字列のリリース ルールは、C と一致します。invoke_json / render_tick_json の結果 erika_string_free；poll_event_json 無料の NULL をリリースする必要はありません。不明なメソッド名がエラー応答を返します。

応答エンベロープレスポンス#

成功した応答:

{ "ok": true, "status": 0, "value": /* 方法返回值，无值时为 null */ }

失敗時の応答:

{ "ok": false, "status": 3, "error": "human readable message" }

ok を確認してください。ブリッジ自身が引数やメソッドのエラーを生成する場合があります。C API の失敗時はスレッドローカルのメッセージを読み、空ならステータスの説明を生成します。捕捉された panic はエラー応答になりますが、捕捉範囲外や panic-abort ビルドではプロセスが終了することがあります。C API の非 Ok ステータスは status: 3 に変換されます。

イベントの戻り形状イベント#

poll_event_json イベント オブジェクトのフィールドは次と同じです。 ErikaEvent 1 対 1 の対応。kind は整数 (0 ～ 12、参照)C ABI 概要イベントテーブル):

{ "kind": 1, "status": 0, "state": 2, "durationMicros": 0,
  "positionMicros": 0, "buffering": false,
  "video": { "width": 0, "height": 0, "primaries": 0, "transfer": 0 },
  "tracks": { "video": 0, "audio": 0, "subtitle": 0 } }

3 つの kind には追加フィールドが付属しています。Error(9)添付書類 error 文字列;VideoDecoderChanged(11)添付書類 decoder と message;AudioOutputChanged(12)添付書類 audio と message。キューが空の場合は、NULL を返します。

メソッドリストメソッド#

パラメータ名は常に camelCase です。オプションのパラメータは角かっこで囲まれています。省略した場合は、C関数のデフォルト値が使用されます。パラメータと戻り値のみがリストされており、セマンティクスは同じ名前のものと同じです。 C関数一貫した。

インターフェイスの検出、章、診断 · 0.3.0#

listMethods 戻る {schema, methods}。各アイテムには、name、scope、summary、arguments (name / type / required)、returns、blocking、writesFiles が含まれます。現在の実行中に返されるテーブル。グローバル メソッドには handle は必要ありません。また、Presenter メソッドは有効な handle である必要があります。表のエントリは、同期ブロッキングの動作と可能なファイル書き込みを説明するものであり、非同期タスクのスケジューリングを表すものではありません。

C

char *methods = erika_presenter_invoke_json(NULL, "listMethods", "{}");
// 解析后释放
erika_string_free(methods);

exportFramesuri、positionsMillis、outputDir;他のオプションは単一フレームのエクスポートと同じです。ソース サイズ、期間、seek/ デコード数、およびフレームごとの結果を返します。global

ミリ秒単位の章の位置。endMs は null にすることができます。に渡されました seek startMs をマイクロ秒に変換します。単一フレームおよびバッチ エクスポートは、ファイルを書き込むことができる同期ブロッキング操作であり、UI 作業スレッドで実行する必要があります。多重化デコーダをバッチでエクスポートします。単一フレームの失敗は対応するエントリに記録され、残りは継続されます。

エクスポートには、timestampMicros、ソース ディメンション、および toneMapped が含まれます。 HDR は SDR にマップされます。メモリとスレッドのルールの詳細については、次を参照してください。フレームエクスポート C エントリ。ログの limit=0 はすべての予約済みエントリを読み取り、sinceSeq は最後の nextSeq を使用します。ログ リングは最大 2000 エントリ / 512 KiB を保持できます。

例例#

// seek 到 30 秒
char *out = erika_presenter_invoke_json(p,
    "seek", "{ \"positionMicros\": 30000000 }");
// {"ok":true,"status":0,"value":null}
erika_string_free(out);

// 打开并附带请求头:httpHeaders 是"名称:值"对象,不是数组
out = erika_presenter_invoke_json(p, "open",
    "{ \"uri\": \"https://example.com/v.mp4\", "
    "\"httpHeaders\": { \"Referer\": \"https://example.com\" } }");
erika_string_free(out);

// 事件轮询：队列为空时返回 NULL
char *ev = erika_presenter_poll_event_json(p);
if (ev) { erika_string_free(ev); }
