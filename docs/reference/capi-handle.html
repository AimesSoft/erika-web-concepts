ErikaHandle Reference

生命周期与错误ライフサイクル#

ErikaHandle *erika_create(void)

创建播放器句柄。不会失败。

void erika_destroy(ErikaHandle *handle)

销毁句柄并释放全部内部资源。

char *erika_last_error_message(void)

读取本线程最近一次错误的人读消息。返回的字符串归调用方所有，用 erika_string_free 释放。必须在发生错误的同一线程读取。

void erika_string_free(char *value)

释放由 Erika 返回的独立字符串。

void erika_subtitle_memory_font_status_free(ErikaSubtitleMemoryFontStatus *status)

释放 ErikaSubtitleMemoryFontStatus 内的数组与字符串字段。

void erika_subtitle_memory_font_info_free(ErikaSubtitleMemoryFontInfo *info)

释放 ErikaSubtitleMemoryFontInfo 内的数组与字符串字段。

播放控制再生制御#

ErikaStatus erika_open(ErikaHandle *handle, const char *uri)

打开媒体。uri 是本地路径或 HTTP(S) URL。open 是异步的，就绪状态经 StateChanged / DurationChanged 事件到达。

ErikaStatus erika_open_with_headers(ErikaHandle *handle, const char *uri, const ErikaHttpHeader *headers, uintptr_t header_count)

带自定义 HTTP 请求头打开媒体。

ErikaStatus erika_play(ErikaHandle *handle)

开始播放。play 只投递工作，最终结果以 StateChanged 或 Error 事件为准。

ErikaStatus erika_pause(ErikaHandle *handle)

暂停播放。

ErikaStatus erika_stop(ErikaHandle *handle)

停止播放。

ErikaStatus erika_close(ErikaHandle *handle)

关闭并释放媒体资源。句柄随后仍可复用或销毁。

ErikaStatus erika_seek(ErikaHandle *handle, uint64_t position_micros)

跳转到指定位置，单位为微秒。

轨道与字幕トラック#

ErikaStatus erika_add_external_subtitle(ErikaHandle *handle, const char *uri, int64_t *out_track_id)

添加外挂字幕轨，输出轨道 id。

ErikaStatus erika_remove_subtitle_track(ErikaHandle *handle, int64_t track_id)

移除字幕轨。

ErikaStatus erika_select_audio_track(ErikaHandle *handle, int64_t track_id)

选择音频轨。

ErikaStatus erika_select_subtitle_track(ErikaHandle *handle, int64_t track_id)

选择字幕轨。id 为 -1 禁用字幕。

ErikaStatus erika_track_selection(ErikaHandle *handle, ErikaTrackSelection *out_selection)

读取当前选中的视频、音频与字幕轨。

ErikaStatus erika_tracks(ErikaHandle *handle, ErikaTrackInfo *out_tracks, uintptr_t capacity, uintptr_t *out_len)

按计数数组惯用法读取轨道列表。每条填充的记录用 erika_track_info_free 释放。

void erika_track_info_free(ErikaTrackInfo *track)

释放 ErikaTrackInfo 内的字符串字段。

void erika_danmaku_track_info_free(ErikaDanmakuTrackInfo *track)

释放 ErikaDanmakuTrackInfo 内的字符串字段。

状态与事件状態とイベント#

ErikaStatus erika_state(ErikaHandle *handle, ErikaState *out_state)

读取当前播放状态。

ErikaStatus erika_poll_event(ErikaHandle *handle, ErikaEvent *out_event)

非阻塞轮询事件队列。队列为空时返回 NoEvent。事件种类、ErikaEvent 各事件的载荷字段见C ABI 总览的事件表。按 Error 事件后,可从 erika_last_error_message 取详情。
