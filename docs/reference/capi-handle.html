播放控制再生制御#

ErikaStatus erika_open(ErikaHandle *handle, const char *uri)

打开媒体。uri 是本地路径或 HTTP(S) URL。函数同步完成流信息探测与轨道解析并将状态置为 Ready，返回后调用播放函数开始异步解码与呈现。

ErikaStatus erika_open_with_headers(ErikaHandle *handle, const char *uri, const ErikaHttpHeader *headers, uintptr_t header_count)

带自定义 HTTP 请求头打开媒体。

ErikaStatus erika_open_with_options( ErikaHandle *handle, const char *uri, const ErikaOpenOptions *options)

使用 ErikaOpenOptions 打开媒体，可同时传入 HTTP 请求头、预读窗口与回退缓存预算。选项只在调用期间借用，reserved 置零。

ErikaStatus erika_play(ErikaHandle *handle)

开始播放。play 只投递工作，最终结果以 StateChanged 或 Error 事件为准。

ErikaStatus erika_pause(ErikaHandle *handle)

暂停播放。

ErikaStatus erika_stop(ErikaHandle *handle)

停止播放。

ErikaStatus erika_close(ErikaHandle *handle)

关闭并释放媒体资源，进入 Closed 状态。随后销毁句柄；下一次播放创建新句柄。

ErikaStatus erika_seek(ErikaHandle *handle, uint64_t position_micros)

跳转到指定位置，单位为微秒。

独立 GIF 导出#

ErikaStatus erika_export_gif( const ErikaGifExportOptions *options, ErikaGifExportResult *out_result)

独立的同步导出入口，不需要播放器或表面。时间单位为毫秒；UI 宿主在工作线程运行。成功后填写尺寸、帧数与文件大小。

C

ErikaGifExportOptions options = {
    .input_uri = "/path/input.mp4",
    .output_path = "/path/output.gif",
    .start_millis = 5000,
    .end_millis = 10000,
    .frames_per_second = 10,
    .output_width = 640,
    .output_height = 360,
    .quality = ErikaGifExportQuality_High,
    .loop_count = 0,
};
ErikaGifExportResult result = {0};
ErikaStatus status = erika_export_gif(&options, &result);

独立帧导出与日志 · 0.3.0#

帧导出是同步操作，UI 宿主应放在工作线程。输入 position_millis 的单位为毫秒；结果 timestamp_micros 与 duration_micros 的单位为微秒。HDR（PQ / HLG / Dolby Vision）会按 SDR 显示路径色调映射，并在结果 reserved_flags 中置 ERIKA_FRAME_EXPORT_TONE_MAPPED（1）。

ErikaStatus erika_export_frame( const ErikaFrameExportOptions *options, ErikaFrameExportResult *out_result)

独立同步导出媒体时间处的图像，返回 RGBA 或 PNG；保持显示宽高比、在可选尺寸范围内缩放且不放大。拥有独立解封装器和多线程软件解码器，无需播放器或表面。

void erika_frame_export_result_free(ErikaFrameExportResult *result)

释放结果中的 data 并重置结果。不可用 erika_string_free 或宿主 free 代替。

ErikaStatus erika_frame_export_session_open( const ErikaFrameExportSessionOptions *options, ErikaFrameExportSession **out_session)

打开一次媒体供连续截帧，成功时返回会话。初始化结构体时将 reserved 与 reserved_flags 置零。

ErikaStatus erika_frame_export_session_frame( ErikaFrameExportSession *session, const ErikaFrameExportRequest *request, ErikaFrameExportResult *out_result)

从会话中导出指定时间的图像；递增请求且中间无关键帧时继续解码，其他情况重新 seek。结果与单次导出相同，逐个调用 result_free 释放。

void erika_frame_export_session_close(ErikaFrameExportSession *session)

关闭并释放会话，接受 NULL。一个会话的调用必须串行，不能与 close 并发，也不能在关闭后继续使用。

ErikaStatus erika_log_read_json( uint32_t limit, int32_t min_level, uint64_t since_seq, char **out_json)

读取进程级脱敏日志环：最多 2000 条 / 512 KiB。limit=0 读取全部保留条目，min_level=-1 不限级别，since_seq 传上次 nextSeq 增量读取。任意线程可调用，无需 handle。成功字符串用 erika_string_free 释放，失败时 out_json 为 NULL。

独立帧导出只解码媒体图像，不包含当前 Presenter 的字幕和弹幕。原生 erika_presenter_capture_frame_rgba 包含视频和字幕，不含弹幕；Web capture() 则包含三者。
