Build and dependencies

Building and Dependencies

The Rust code of liberika is built directly with cargo; native dependencies such as FFmpeg, dav1d, libass, HarfBuzz are obtained in source code and third_party/ Built within, by xtask deps management. The build script ensures that CI is consistent with the local output.

  • Rust 1.92+
  • edition 2024
  • Native dependencies 7 a

xtask depsdependency management#

Complete build process

cargo run -p xtask -- deps plan                 # 打印依赖计划
cargo run -p xtask -- deps fetch                # 下载并解压源码
cargo run -p xtask -- deps build                # 构建 host 目标
OptionsvalueDefault
--profilelgpl / gpl-fulllgpl
--targetSee table target belowhost
--forceForce rebuild native dependenciesClose; reuse completed products by default
--allAdditional construction of subtitle stack: libass + FreeType + HarfBuzz + FriBidi (fetch captures the source code of these four at the same time)Build only the video stack
--jobsParallelismautomatic

The difference between the two profile is in the configure flag of FFmpeg. lgpl disables the GPL component, disables network, and only enables the demuxer / parser / decoder required by the playback core; gpl-full enables the GPL part on this basis. The default lgpl meets publishing needs.

The build result saves the build tag by target with profile; FFmpeg and dav1d will check the version, patch and build options. changed xtask/src/main.rs or third_party/patches/ Needed later deps build --force Trigger a rebuild.

Workspace buildワークスペース#

cargo build --workspace
cargo test --workspace

The workspace contains three crate:erika(kernel),erika_capi（C ABI）、erika_ffmpeg_sys(FFmpeg binding), and xtask with over 20 examples. Example is a minimal program that verifies a specific path:

macOS desktop smoke test

cargo run -p macos_native_demo -- --smoke-seconds 3 /path/to/video.mp4

macos_native_demo is a complete end-to-end demonstration of presenter: opening, playback, Metal rendering and system media control. Other examples of division of labor by name,capi_smoke Cover the main calling path of C ABI,playback_tick / player_tick Covering the scheduling cycle of two entries play / pull.

Linux system library construction#

Linux uses systems FFmpeg 8 and PulseAudio, and separately builds the liberika patch version libass. The entrance is different from the release target of xtask:

shell

bash scripts/build_linux_libass.sh
cargo build --locked --release -p erika_capi -p linux_native_demo

Release dependencies, Flutter dynamic library paths and X11 / Wayland examples are included in Linux access. The codecs and licenses for system FFmpeg depend on the distribution build; setting lgpl profile does not change the system libraries.
