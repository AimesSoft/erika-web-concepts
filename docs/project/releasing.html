bundle 结构構成#

所有 bundle 由 packaging/bundle.sh 生成，结构一致：

<bundle-name>/
  lib/                    # 库文件或 xcframework
  include/erika.h         # C ABI 头文件
  LICENSE                 # MPL-2.0
  THIRD_PARTY_NOTICES.md  # 依赖许可证声明与 LGPL relink 说明
  licenses/               # 各依赖的许可证原文
  MANIFEST.txt            # ref / commit / profile / 构建时间

MANIFEST.txt 记录构建出处：bundle 名、git ref、commit、profile 与 UTC 时间。排查产物来源时先读它。

THIRD_PARTY_NOTICES.md 说明 LGPL 组件的 relink 义务：库以静态链接分发，改动态链接的宿主需要能替换这些组件。

预编译消费プレビルト利用#

Flutter 插件以 ERIKA_PREBUILT=1 切换到预编译运行时，跳过源码构建：

flutter build macos --dart-define=... # 或构建前导出：
export ERIKA_PREBUILT=1                # 启用预编译下载
export ERIKA_PREBUILT_TAG=v0.1.5       # 版本标签，默认当前版本

构建脚本按平台从 github.com/AimesSoft/Erika/releases/download/<tag>/ 下载对应 bundle 并解包。下载失败自动回退源码构建，回退与失败都会输出明确日志。

native 宿主的消费方式：把 bundle 解包，include/erika.h 作为唯一头文件，lib/ 内的库链接进宿主，见C ABI 嵌入。
