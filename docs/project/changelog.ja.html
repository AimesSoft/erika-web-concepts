0.3.0 · 2026-10-25#

デフォルトの動作の変更:ネイティブと Web の字幕と弾幕スーパーサンプリングはデフォルトで有効になっており、それぞれオフにすることができます。ソフトウェア ビデオ デコードでは、デフォルトでフレーム/スライスのマルチスレッドが有効になり、スレッドの数は FFmpeg によって選択されます。設定 ERIKA_VIDEO_DECODE_THREADS=1 シングルスレッドを復元します。

Web、エクスポートと診断

  • 独立したものを追加 Web / WASM バックエンド: FFmpeg カプセル化解除、WebCodecs デコード、libass ASS/SSA 字幕とフォント添付ファイル、Rust 弾幕、Web Audio クロック、WebGL2 合成。ローカル ファイル、HTTP Range、マルチトラック、チャプター、PNG スクリーンショットをサポートし、エンコード機能はブラウザーに依存します。
  • Release新規 liberika-web-0.3.0.zip、完全なランタイム、ライセンス、デモ ページが一緒に配布され、要約も含まれています。 SHA256SUMS。
  • 独立した RGBA / PNG フレーム エクスポートと連続フレーム キャプチャ セッションを追加しました。デコードステータスを再利用し、HDR を SDR にマッピングします。
  • 感度を下げたログ ループ、デコードおよびハードウェア フォールバック診断、オーディオ/プレゼンテーション タイミング スナップショットを追加しました。listMethods JSON インターフェイスを見つけることができます。 blocking / writesFiles 財産。
  • Presenter JSON 新しい chapters 既存の C 構造を拡張せずにクエリを実行します。

修理と互換性

  • 一時停止ジャンプ、seek にわたる長い字幕、および一時停止トラックのカット後の字幕更新を修正しました (#171)。
  • iOS / tvOS 古いランタイムとの互換性を確保し、静的リンクによる新しいシンボルの喪失を避けるために、シンボルの可用性ごとにオプションのインターフェイスを保存します (#170)。
  • 通常の HTTP 末尾読み取り失敗は EOF として処理され、Range チェックサム リソース変更エラーは保持されます (#169)。
  • Danmaku システム フォント フォールバックは、ゼロ コピー カバレッジ チェックと制限付き LRU を使用し、メモリ スパイクを修正し、表示可能な文字を保持します (#173)。
  • erika_play trace は起動失敗の理由を記録します。 Windows、Android、Hongmeng へのアクセスが向上します。
  • プロジェクトの名前が liberika に変更されました。 Rust crate erika、C ABI erika_*、Flutter/OHPM パッケージ名は引き続き互換性があります。

GitHub Release、Flutter 0.3.0、Swift SDK 0.3.0 そして OHPM erika 0.3.0 全て公開されております。完全な記録については、を参照してください。ソースコード CHANGELOG。

0.1.8 · 2026-09-07バージョン#

HTTP 開始オプションと先読みウィンドウ構成、統一された SDK パブリッシング入口、および Windows Flutter SDR テクスチャを追加しました。 Presenter 構成ではビデオ alpha モードが追加され、ネイティブ ホストはそれに応じてヘッダー ファイルとランタイムを更新する必要があります。

クロスプラットフォームネイティブ GPU 合成による透明なビデオ (#124)

  • packed-alpha ビデオ プレゼンテーションを追加しました (ErikaVideoAlphaMode.packedAlphaRight): 左半分のカラーと右半分の alpha を持つマテリアルは、alpha で事前乗算された GPU で再構築され、エンコード幅の半分でレンダリングされます。このモードを要求しないプレイヤーは変更されずに動作します。
  • macOS は、IOSurface + Metal の Flutter Texture パスを追加します (ErikaTextureVideoView)、Flutter 不透明度、トリミング、変換、およびカラー フィルターを取得するためのフレームごとの CPU リードバックはありません。バックグラウンドを意識したミキシングが必要な場合はネイティブに切り替える CAMetalLayer(サポート overlayBlendMode レイヤーの不透明度を使用)。
  • Windows 透明ビデオは DirectComposition 合成に変更されます。 Composition Swap alpha で事前乗算された Chain は、Flutter HWND に直接バインドされ、元の独立した不透明ポップアップ ウィンドウを置き換えます。サポートされている srcOver / overlay ブレンディングと不透明度を備えた overlay は、同じ HWND 内で実際のゲームの背景をサンプリングできます。不透明なビデオは、元の HWND 再生パスを維持します。
  • ネイティブ再生速度制限が 4 倍速から 16 倍速に向上し、ショート アニメーションや特殊効果素材の高速再生がサポートされます。
  • C ABI 新しい erika_presenter_create_with_output_mode_and_alpha、erika_presenter_attach_flutter_texture / erika_presenter_set_flutter_texture_buffer と erika_presenter_windows_composition_swapchain_iunknown(AddRef/Release 独自仕様)。

弾幕の継続性とJSON契約(#121)

  • 放棄された弾幕が途中で再出現したり、目に見える弾幕が強制的に軌道を変更したりすることを防ぐために、連続する計画スライディング ウィンドウ間の軌道の割り当てと許可の決定を安定した状態に保ちます。
  • ホストによって渡された弾幕サービス ID をカーネルの内部レイアウト ID から分離し、オプションの JSON ID を正確に解析することをサポートします。 u64 または 10 進数の文字列を使用して、浮動小数点の倍精度丸めによって発生する ID の切り捨てを回避します。
  • インライン弾幕 JSON 契約を正式に標準化して文書化し、標準配列と comments / danmaku / items ルートオブジェクト。

字幕メモリーフォント

  • メモリ サブタイトル フォント レジストリは、Rust、C、API、Dart を各ネイティブ Flutter 埋め込みに接続します。ホストは、ディスクに書き込むことなく、フォント faces を確認し、順序付けられたフォールバック セットを選択し、フォント データを置き換え、レジストリをクリアできます。
  • libass は順序付けられたロールバックを保持します。 TTC / OTC データは face 全体で共有されます。同じパス内のフォントが置き換えられると、レンダラー キャッシュが無効になり、アクティブな字幕トラックは新しいデータをすぐに使用します。

プレイ再開

  • オーディオおよびビデオ入力が不足している場合は、明示的なバッファ変換を開始します。再生クロックは、stall 中にフリーズし、データが復元された後にメディア時間に再固定され、クロックのオーバーランや長期的なフレーム ドロップや黒い画面の発生を回避します。

0.1.4バージョン#

互換性に関するヒント

  • 弾幕 outline_width マルチプライヤーの代わりにギアに変更します。0 オフ、1 細かい、2 ノーマル、3 粗い、3 を超えると粗いクランプになります。通常および粗いスケールは、1.0 および 2.0 の古い連続乗算器の幅を正確に再現するため、以前に送信されました。 outline_width: 1.0 ホストは今度は送信する必要があります 2.0 同じストロークを保つために。移行されていないストロークは細くなります。デフォルトのフォント サイズでは、ラスタライズ半径が 2 px から 1 px に半分になります。
  • 弾幕のフォントサイズはemごとのピクセル数で説明されています。ab_glyph の PxScale ascenderからdescenderまでの高さです。古いコードは em サイズを直接渡しており、レンダリングはリクエストよりも小さくなります。テキストはリクエストと一致するようになり、アップグレード後は弾幕が大きくなりました。 PingFang SC の比率は 1.4 で、同じ構成では 40% 大きくなります。古い外観を希望するホストは、フォント サイズを小さくする必要があります。
  • 弾幕のスクロール期間は、ビューポートの論理幅に応じて変化します (640 pt では ×0.9、1920 pt 以上では ×1.3)。同じ設定でも、大きなウィンドウではスクロールが遅くなります。
  • 弾幕のスクリーンショットには弾幕が含まれなくなりました。capture_* ビデオと字幕のみが合成され、debug HUD はスクリーンショットには含まれません。

再生、レンダリング、ウィンドウの統合

  • 共有再生クロックは直接公開され、フレーム スナップショットのアトミック サンプリング時間、状態、世代が含まれます。弾幕、字幕、レンダリングは同じタイムベースを共有します。
  • 一時停止された seek はプレビュー フレームをデコードしてレンダリングしますが、メディア クロックはフリーズしたままになります。 seek preroll、EOF、および seek の一時停止と再開の起動競合状態によって、クロック ロールバック、worker のアイドリング、または長い黒いフレームが生成されなくなりました。
  • オーディオとビデオの demux 要件が分離され、オーディオ バックプレッシャーによってビデオ パケットのスキャンがブロックされなくなりました。字幕を切り替えたり追加しても、オーディオとビデオの demux の選択はリセットされません。
  • macOS は次のように再構築されてレンダリングされます。 CVDisplayLink、フレームの結合が遅い、画面変更後に display link をリセットします。重複する overlay アタッチメントと GPU リソースのウィンドウ移行時の作業が削減されます。
  • デスクトップ overlay API は複数をサポートします FlutterView そして二次ウィンドウ。プレーヤーは、ホスト ウィンドウ間を移行するときに、サーフェス、可視性、世代、および aspect-fit 状態を維持します。
  • Windows D3D11 overlay ライフサイクル、ノンブロッキング レンダリングおよびリカバリ seek 処理の改善。字幕はビデオ ビューポート内で合成され、弾幕はフル ウィンドウ ビューポートを維持します。

弾幕と字幕

  • 弾幕の衝突境界をラスター化されたストロークに合わせ、シャドウ/ストローク/テキストの順序を修正し、トラックの設定を安定させ、オーバーフロートラックへの高密度のオーバーラップを制限します。
  • 非同期リフロー中、古い弾幕 plan は動き続けます。純粋な描画設定ではレイアウトが再利用され、表示設定はすぐに有効になります。
  • 増分 glyph atlas がアップロードされ、再利用可能 Metal instance buffer となり、フレームごとの DFM 割り当てと候補走査オーバーヘッドが削減されます。
  • プラグイン テキスト字幕の文字セット検出とトランスコーディング。GBK、Big5、Shift_JIS、UTF-16、UTF-8 パススルー、低信頼性、またはバイナリ入力フォールバック保護をカバーします。
  • libass はすべてのプラットフォームに登録されています。 liberikaを内蔵しています。 Droid Sans Fallback;非システム フォント プロバイダーのターゲットはデフォルトでこのファミリーになり、解析不可能なカテゴリには分類されなくなりました。 Arial。
  • 字幕のフォールバックと選択的なスタイルのオーバーライド: カスタム フォント ファミリとファイル、RGBA カラー、メトリクス、テキスト プロパティ、境界線、配置、マージン、ぼかし。入り口は、 erika_presenter_set_subtitle_font、erika_presenter_set_subtitle_style と ErikaPlayer.setSubtitleStyle。

ネットワークとメディアの診断

  • erika_open_with_headers と erika_presenter_open_with_headers。リクエスト ヘッダーは、probe、range の読み取り、リトライ、プリフェッチに適用されますが、字幕と弾幕 sidecar には渡されません。
  • ホストの受信 liberika 管理トランスポート ヘッダーと不正な HTTP フィールドを拒否します。 HTTP range 入力強化: 無視 Range、エラー オフセット、一時的な障害、部分応答、偽 EOF による繰り返しプリフェッチ、再試行制限。
  • bitrate を追跡し、合理的なフレーム レート メタデータは Rust、C、Dart を通過します。オプションのネイティブ debug HUD は、デコーダー、レンダラー、GPU、オーディオ、出力、および HDR、弾幕診断をカバーします。

オーディオ、カラー、コーデック

  • クリッピングを防ぐために、サラウンドからステレオのダウンミックス マトリックス正規化を行います。
  • すべてのオーディオ バックエンドにコールバック ボリューム ランピングを追加しました。 WASAPI 監視可能な回復ステータスと制限付きバックオフによるデバイス損失回復。
  • Metal、WGPU、D3D11 は BT.2100 HLG デコードをサポートします。 D3D11 overlay は、HDR10 出力で PQ を正しくエンコードします。
  • FFmpeg は 8.1.2 にアップグレードされます。 Darwin AV1 ハードウェアデコードのインポートが改善されました。 seek は読み込み中に最後のフレームを保持し、黒く点滅しなくなりました。
