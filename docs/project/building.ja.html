ビルドと依存関係

Building and Dependencies

liberika の Rust コードは、cargo を使用して直接構築されます。 FFmpeg、dav1d、libass、HarfBuzz などのネイティブ依存関係はソース コードで取得され、 third_party/ 内部に構築され、 xtask deps 管理。ビルド スクリプトは、CI がローカル出力と一致していることを保証します。

  • Rust 1.92+
  • edition 2024
  • ネイティブの依存関係 7 ある

ネイティブの依存関係ネイティブ依存#

リリース対象の依存関係を修正版の上流ソースコードから取得し、スクリプトアプリケーションを構築します。 third_party/patches/ パッチ内で。

fetch および build の結果は作業領域にあります。 third_party/、システム ディレクトリにはインストールしないでください。

third_party/src       # 解压后的源码树

third_party/dist      # 按 target / profile 分隔的产物前缀

xtask deps依存関係の管理#

ビルドプロセスを完了する

cargo run -p xtask -- deps plan                 # 打印依赖计划
cargo run -p xtask -- deps fetch                # 下载并解压源码
cargo run -p xtask -- deps build                # 构建 host 目标
オプション値デフォルト
--profilelgpl / gpl-fulllgpl
--target以下の表 target を参照してください。host
--forceネイティブ依存関係を強制的に再構築する近い;デフォルトで完成品を再利用する
--all字幕スタックの追加構成: libass + FreeType + HarfBuzz + FriBidi (fetch はこれら 4 つのソース コードを同時にキャプチャします)ビデオスタックのみを構築する
--jobs平行度自動

2 つの profile の違いは、FFmpeg の configure フラグにあります。 lgpl は、GPL コンポーネントを無効にし、network を無効にし、再生コアに必要な demuxer / parser / decoder のみを有効にします。 gpl-full は、これに基づいて GPL 部分を有効にします。デフォルトの lgpl は公開のニーズを満たします。

ビルド結果は、profile を使用してターゲットごとにビルド タグを保存します。 FFmpeg と dav1d は、バージョン、パッチ、ビルド オプションをチェックします。変わった xtask/src/main.rs または third_party/patches/ 後で必要になる deps build --force 再構築をトリガーします。

ワークスペースの構築ワークスペース#

cargo build --workspace
cargo test --workspace

ワークスペースには 3 つの crate が含まれています。erika(カーネル)、erika_capi（C ABI）、erika_ffmpeg_sys(FFmpeg バインディング)、および xtask 20以上の例があります。例は、特定のパスを検証する最小限のプログラムです。

macOS デスクトップのスモークテスト

cargo run -p macos_native_demo -- --smoke-seconds 3 /path/to/video.mp4

macos_native_demo これは、presenter の完全なエンドツーエンドのデモです: オープニング、再生、Metal レンダリング、システム メディア コントロール。名前による分業の他の例、capi_smoke C ABI のメイン呼び出しパスをカバーし、playback_tick / player_tick 2 つのエントリ play / pull のスケジューリング サイクルをカバーします。

Linux システムライブラリ構築#

Linux は、システム FFmpeg 8 および PulseAudio を使用し、liberika パッチ バージョン libass を個別にビルドします。入り口はxtaskのリリースターゲットとは異なります:

shell

bash scripts/build_linux_libass.sh
cargo build --locked --release -p erika_capi -p linux_native_demo

リリースの依存関係、Flutter ダイナミック ライブラリ パス、および X11 / Wayland の例が含まれています。 Linux アクセス。システム FFmpeg のコーデックとライセンスは、ディストリビューションのビルドによって異なります。 lgpl profile を設定しても、システム ライブラリは変更されません。
