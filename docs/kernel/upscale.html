神经超分

Neural Upscaling

ArtCNN 是一个面向动漫内容的亮度 2× 神经超分模型。它只处理亮度通道，输出以 NeuralUpscale pass 接入渲染管线。后端不可用时保留原生亮度采样，并显式上报 Inactive 状态。

  • 模型 ArtCNN C4
  • 倍数 亮度 ×2
  • 执行 Metal / wgpu

模型与模式モデル#

模型权重随 crate 内嵌（crates/erika/assets/artcnn），编译期打包，运行时不访问文件系统。权重按 F16 与 F32 两种精度提供，对应两种请求模式：

模式值说明
Off0关闭超分，原生亮度采样。
ArtCnnC4F161半精度权重，面向 Metal simdgroup matrix 路径。
ArtCnnC4F322单精度权重，面向 wgpu compute 路径。

执行路径実行経路#

两种 compute 实现共享同一份模型描述，权重格式对应请求模式：

  • Metal（macOS / iOS / tvOS）— simdgroup matrix 卷积。权重在 erika-upscaler-build 线程后台构建，构建完成后以 SimdgroupMatrix 状态接入管线。
  • wgpu compute（Android / HarmonyOS）— 分块 compute 算子，F32 路径。

其余渲染后端（D3D11）没有 ArtCNN 执行器，请求启用时保留原生亮度采样，active_backend 报告 Inactive，宿主可以看到该平台不支持超分。

后端状态含义
Off未请求。
Inactive已请求但后端不可用，保留原生采样。
Building权重构建中，尚未接入管线。
Scalar标量执行路径。
SimdgroupMatrixsimdgroup matrix 执行路径。

接入方式パイプライン#

超分作为 NeuralUpscale pass 插入 pass 图，位于导入与采样之间：亮度通道经模型放大 2×，色度通道按常规缩放。后续的 tone mapping、合成与输出变换保持不变。

每帧的编码与 GPU 耗时记录在 last_encode_micros 与 last_gpu_micros。执行失败会累计 fallback_count 并临时回退原生采样，下一帧重试。
