神经超分

Neural Upscaling

liberika 0.3.4 提供神经网络、空间滤波与平台视频超分。可选择内置模式或由宿主加载自定义模型；不满足条件时保留原生采样并报告原因。

  • Version 0.3.4
  • Networks 2× luma
  • Backends Metal / D3D11 / wgpu

模型与模式#

模式值按系列分组；网络模式将亮度放大 2 倍，色度仍由常规缩放器处理。

值系列说明
0Off关闭超分
1–7ArtCNNC4F16 / C4F32、DS/DN 变体及 R8F64；R8F64 仅桌面打包
16–25Anime4KCNN x2 S/M/L/VL/UL，及对应 Upscale+Denoise
32Fsr1AMD FSR 1.0 EASU + RCAS，将亮度缩放到呈现尺寸
48PlatformVideo平台视频超分，缩放整个帧
49MetalFxSpatialApple MetalFX Spatial
64Custom宿主加载的自定义网络

平台执行路径#

  • Windows D3D11：神经网络、FSR1 和 NVIDIA RTX Video Super Resolution / Intel VSR；平台视频超分需要兼容 GPU、驱动设置、SDR 和 D3D11VA NV12/P010 帧。
  • Apple Metal：神经网络、FSR1、MetalFX 和 VideoToolbox 低延迟超分。VideoToolbox 要求 macOS/iOS/tvOS 26+、8 位 4:2:0、96×96 到 960×960 输入，仅 2 倍。
  • wgpu（Linux、Android、OpenHarmony、Windows wgpu 回退）：支持网络模式与 FSR1；平台视频超分和 MetalFX 不可用。Web 暂无超分。

自定义模型与状态#

使用 C erika_presenter_load_upscaler_model 或 Flutter ErikaPlayer.loadUpscalerModel 加载 Erika .esr、FSRCNNX / Anime4K CNN mpv hook 文件，再选择 custom；clearUpscalerModel 卸载。只解析权重，不执行 shader 代码；FSRCNNX 权重不随库分发。

后台编译期间报告 Building，不满足条件报告 Inactive；两者都暂用原生采样。诊断 upscaler 对象提供 engine、reason 与 lastGpuMs。

详细限制、示例和设备测试条件见源码接入指南。
