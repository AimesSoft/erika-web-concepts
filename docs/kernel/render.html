渲染管线

Render Pipeline

视频、字幕与弹幕在同一张 pass 图里完成采样、色彩转换、tone mapping、缩放与合成，一次 render pass 上屏。pass 图由 pipeline::build_graph 按源与目标的色彩状态条件化构建。

  • pass 类型 11 种
  • 后端 Metal / D3D11 / wgpu
  • 几何 aspect_fit 居中

pass 图パスグラフ#

RenderPassKind 定义了全部 11 种 pass。渲染一帧时，build_graph 从导入帧到输出变换按序组合，条件不满足的 pass 被跳过：

pass职责
ImportFrame解码帧导入为 GPU 纹理（零拷贝或 CPU upload）。
NeuralUpscaleArtCNN 亮度 2× 超分，仅在启用且后端支持时插入。
PlaneSamplingYCbCr 平面采样，uv 上采样与色度重建。
ChromaReconstruction色度平面重建。
TransferDecode传输函数解码，从编码格式还原线性光。
GamutMap色域映射，源与目标原色不同时插入。
ToneMaptone mapping，源为 HDR 且峰值超过目标约 1.05 倍时插入。
Scale缩放至输出尺寸。
OverlayComposite字幕、弹幕与宿主 overlay 的合成。
Dither输出位深降低时的抖动。
OutputTransform编码到输出格式（SDR / EDR / HDR10 PQ / scRGB）。

两个条件插入的规则来自 SourceColorState 与 TargetColorState 的比较：tone map 仅当源是 HDR 且峰值超过目标约 5% 时插入，色域映射仅当源与目标原色不同时插入。SDR 内容在 SDR 目标上直接走采样与输出变换。

后端实现バックエンド#

后端平台说明
MetalmacOS / iOS / tvOS原生实现。YCbCr 采样、色彩转换、tone mapping、overlay 合成。ArtCNN 走 simdgroup matrix。
Direct3D 11Windows原生实现。D3D11VA 纹理互操作、HDR10 输出、overlay 合成。
wgpuAndroid / HarmonyOSVulkan 后端，GLES 与恢复路径可用。HarmonyOS 经 OHNativeWindow 呈现。

渲染后端由 presenter 配置决定，与表面附着方式无关。色彩决策统一走 pipeline 模块，三个后端共享同一套 pass 图描述。

合成与几何合成#

字幕与弹幕在 OverlayComposite pass 中合成。合成发生在视频视口内：弹幕与字幕相对视频内容定位，跟随视频的 aspect-fit 几何。

视频内容以 aspect_fit 居中放置在输出表面内，letterbox 区域保持透明或填充，取决于表面配置。合成顺序为视频、字幕、弹幕、宿主 overlay。

HDR 内容的渲染链与截图链共用同一张 pass 图。截图的颜色空间与表面一致，合成内容包含视频、字幕与弹幕。
