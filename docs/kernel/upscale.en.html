Neural upscaling

Neural Upscaling

liberika 0.3.4 provides neural, spatial and platform video upscalers. Select a bundled mode or load a custom model; unsupported conditions retain native sampling and report a reason.

  • Version 0.3.4
  • Networks 2× luma
  • Backends Metal / D3D11 / wgpu

Models and modes#

Modes are grouped by family. Network modes upscale luma 2×; chroma uses the regular scaler.

ValueFamilyDescription
0OffDisable upscaling
1–7ArtCNNC4F16 / C4F32, DS/DN variants and R8F64; R8F64 is bundled only on desktop
16–25Anime4KCNN x2 S/M/L/VL/UL and corresponding Upscale+Denoise modes
32Fsr1AMD FSR 1.0 EASU + RCAS scales luma to presentation size
48PlatformVideoPlatform video super resolution scales the whole frame
49MetalFxSpatialApple MetalFX Spatial
64CustomA network supplied by the host

Execution paths#

  • Windows D3D11: networks, FSR1 and NVIDIA RTX Video Super Resolution / Intel VSR. Platform video upscaling requires a supported GPU and driver configuration, SDR and D3D11VA-decoded NV12/P010 frames.
  • Apple Metal: networks, FSR1, MetalFX and VideoToolbox low-latency super resolution. VideoToolbox requires macOS/iOS/tvOS 26+, 8-bit 4:2:0 sources between 96×96 and 960×960; it scales 2× only.
  • wgpu (Linux, Android, OpenHarmony and Windows wgpu fallback): network modes and FSR1; platform video and MetalFX are unavailable. Web has no upscaler.

Custom models and status#

Load an Erika .esr network or an FSRCNNX / Anime4K CNN mpv hook with C erika_presenter_load_upscaler_model or Flutter ErikaPlayer.loadUpscalerModel, then select custom; use clearUpscalerModel to unload. Only weights are parsed, not shader code; FSRCNNX weights are not bundled.

Building indicates background compilation; Inactive indicates that requirements are unmet. Both retain native sampling. The diagnostic upscaler object exposes engine, reason and lastGpuMs.

See the source integration guide for constraints, examples and device measurement conditions.
