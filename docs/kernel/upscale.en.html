Neural upscaling

Neural Upscaling

ArtCNN is a brightness 2× neural super-resolution model for anime content. It only handles the luminance channel and outputs it in NeuralUpscale pass is connected to the rendering pipeline. When the backend is unavailable, the native brightness samples are retained and reported explicitly. Inactive status.

  • model ArtCNN C4
  • multiple Brightness ×2
  • execute Metal / wgpu

Models and Patternsモデル#

Model weights are embedded with crate (crates/erika/assets/artcnn), packaged during compilation, and do not access the file system during runtime. The weight is provided in two precisions: F16 and F32, corresponding to two request modes:

modevalueDescription
Off0Turn off super resolution and use native brightness sampling.
ArtCnnC4F161Half-precision weights for Metal simdgroup matrix paths.
ArtCnnC4F322Single precision weights for wgpu compute paths.

Execution path実行経路#

The two compute implementations share the same model description, and the weight format corresponds to the request mode:

  • Metal(macOS / iOS / tvOS) — simdgroup matrix convolution. The weight is in erika-upscaler-build Thread background construction, after the construction is completed, use SimdgroupMatrix State access pipeline.
  • wgpu compute(Android / HarmonyOS) — Blocked compute operator, F32 path.

The remaining rendering backend (D3D11) does not have the ArtCNN executor, and requests to preserve native luminance samples when enabled,active_backend report Inactive, the host can see that the platform does not support upscaling.

backend statusmeaning
OffNot requested.
InactiveRequested but backend unavailable, native sampling retained.
BuildingThe weight is being constructed and has not yet been connected to the pipeline.
ScalarScalar execution path.
SimdgroupMatrixsimdgroup matrix execution path.

Access methodパイプライン#

overachievement NeuralUpscale pass inserts the pass image, between import and sampling: the luma channel is amplified by the model by 2×, and the chroma channel is scaled normally. Subsequent tone mapping, synthesis and output transformations remain unchanged.

The encoding and GPU time consumption of each frame are recorded in last_encode_micros with last_gpu_micros. Execution failures will accumulate fallback_count And temporarily roll back to native sampling and try again in the next frame.
