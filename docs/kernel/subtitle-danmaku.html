字幕与弹幕

Subtitle & Danmaku

字幕轨支持 SRT / WebVTT / ASS，由 libass 渲染；弹幕支持 Bilibili XML 与 JSON 两种输入，走 DFM+ 碰撞避让布局，经 glyph atlas 在 GPU 上绘制。两者都在渲染管线的合成 pass 中与视频合屏。

  • 字幕渲染 libass
  • 弹幕布局 DFM+
  • 绘制 glyph atlas

字幕字幕#

字幕轨分嵌入与外挂两种来源（ErikaTrackSource）。外挂字幕经 add_external_subtitle 添加，返回轨道 id；字幕轨 id 为 -1 表示禁用字幕。外部文本字幕自带字符集检测与转码，覆盖 GBK、Big5、Shift_JIS、UTF-16，UTF-8 直通，低置信度或二进制输入走保守回退。

渲染统一由 libass 完成，内嵌的 Droid Sans Fallback 在所有平台上注册为内存字体，无系统字体提供者的目标平台默认使用该家族。

样式覆盖

宿主可以整体覆盖字幕样式。覆盖粒度按位控制，ErikaSubtitleStyle.override_mask 的位标志：

标志位覆盖项
ERIKA_SUBTITLE_OVERRIDE_FONT_SIZE_FIELDS2字号
ERIKA_SUBTITLE_OVERRIDE_FONT_NAME3字体族与字体文件
ERIKA_SUBTITLE_OVERRIDE_COLORS4主色与描边色
ERIKA_SUBTITLE_OVERRIDE_ATTRIBUTES5粗体、斜体、下划线、删除线
ERIKA_SUBTITLE_OVERRIDE_BORDER6边框样式与宽度
ERIKA_SUBTITLE_OVERRIDE_ALIGNMENT7对齐
ERIKA_SUBTITLE_OVERRIDE_MARGINS8边距
ERIKA_SUBTITLE_OVERRIDE_BLUR11模糊

ERIKA_SUBTITLE_OVERRIDE_ALL 是以上各位的组合。容器 ASS 脚本保留自己的字体，除非宿主通过字体名覆盖位强制替换。

内存字体

0.1.5 引入内存字体注册表。宿主可以注册字体数据（不写盘）、查询字体的 faces、选择有序回退集合、替换字体数据并清空注册表。已激活字幕轨在字体替换后立即使用新数据，渲染器缓存自动失效。

弹幕弾幕#

弹幕输入为 Bilibili XML（文件或 URL）与 JSON（内联字符串）。两条加载路径：

  • load_danmaku_file / load_danmaku_json — 替换全部弹幕为一条匿名轨。
  • add_danmaku_track_file / add_danmaku_track_json — 建立命名多轨列表，每轨可单独启停与偏移。

轨级 offset_micros 偏移单条轨的时间线，全局偏移作用于所有轨。布局在 erika-danmaku 线程中生成，plan 以 generation 与 media time 门控，与视频保持同步。

DFM+ 布局

弹幕布局由 DFM+ 碰撞避让引擎完成：滚动、顶部与底部三种模式各自的轨道分配、密度限制与覆盖策略。绘制走 glyph atlas，字形一次性栅格化进 atlas，之后逐帧以实例化顶点绘制。

布局参数经 ErikaDanmakuConfig 控制：

字段含义
font_size弹幕逻辑字号，与 NipaPlay 默认弹幕字体一致，按表面 scale 换算为 glyph 像素。
opacity / outline_width / shadow_*透明度、描边宽度、阴影偏移与样式。
display_area弹幕可占的显示区域比例。
scroll_duration_seconds / scroll_speed_factor滚动时长与速度系数。
merge_duplicates重复弹幕合并。
allow_stacking / allow_scroll_overwrite同轨堆叠与滚动覆盖策略。
max_quantity / max_lines_per_mode弹幕总量与单模式最大行数。
block_top / block_bottom / block_scroll按模式屏蔽弹幕。

屏蔽词经 set_danmaku_block_words_json 提供，JSON 数组格式，逐条匹配弹幕文本。
