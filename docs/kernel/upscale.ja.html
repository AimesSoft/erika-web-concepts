ニューラル超解像

Neural Upscaling

liberika 0.3.4 はニューラル、空間フィルター、プラットフォーム動画超解像を提供します。内蔵モードまたはカスタムモデルを選べます。条件を満たさない場合は元のサンプリングを維持し、理由を報告します。

  • Version 0.3.4
  • Networks 2× luma
  • Backends Metal / D3D11 / wgpu

モデルとモード#

モード値は種類ごとに分かれます。ネットワークは輝度を 2 倍にし、色差は通常のスケーラーで処理します。

値種類説明
0Off超解像を無効化
1–7ArtCNNC4F16 / C4F32、DS/DN と R8F64。R8F64 はデスクトップのみ同梱
16–25Anime4KCNN x2 S/M/L/VL/UL と対応する Upscale+Denoise
32Fsr1AMD FSR 1.0 EASU + RCAS で輝度を表示サイズに拡大
48PlatformVideoプラットフォーム動画超解像でフレーム全体を拡大
49MetalFxSpatialApple MetalFX Spatial
64Customホストが読み込むネットワーク

実行経路#

  • Windows D3D11：ネットワーク、FSR1、NVIDIA RTX Video Super Resolution / Intel VSR。プラットフォーム超解像には対応 GPU、ドライバー設定、SDR、D3D11VA デコードの NV12/P010 が必要です。
  • Apple Metal：ネットワーク、FSR1、MetalFX と VideoToolbox 低遅延超解像。VideoToolbox は macOS/iOS/tvOS 26 以降、8 ビット 4:2:0、96×96〜960×960 の入力が必要で、倍率は 2 倍です。
  • wgpu（Linux、Android、OpenHarmony、Windows wgpu フォールバック）：ネットワークと FSR1 に対応し、プラットフォーム動画超解像と MetalFX は使えません。Web に超解像はありません。

カスタムモデルと状態#

C erika_presenter_load_upscaler_model または Flutter ErikaPlayer.loadUpscalerModel で Erika .esr、FSRCNNX / Anime4K CNN mpv hook を読み込み、custom を選択します。clearUpscalerModel で解除します。重みのみを解析し、shader コードは実行しません。FSRCNNX の重みは同梱されません。

バックグラウンドコンパイル中は Building、条件を満たさない場合は Inactive となり、元のサンプリングを維持します。診断の upscaler オブジェクトには engine、reason、lastGpuMs があります。

制限、例、デバイス測定条件の詳細はソースの導入ガイドを参照してください。
