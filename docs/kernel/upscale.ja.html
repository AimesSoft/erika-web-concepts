ニューラル超解像

Neural Upscaling

ArtCNNは、アニメコンテンツ向けの輝度2倍ニューラル超解像モデルです。輝度チャンネルのみを処理し、それを出力します。 NeuralUpscale pass はレンダリング パイプラインに接続されています。バックエンドが利用できない場合、ネイティブの輝度サンプルが保持され、明示的にレポートされます。 Inactive ステータス。

  • モデル ArtCNN C4
  • 複数の 明るさ×2
  • 実行する Metal / wgpu

モデルとパターンモデル#

モデルの重みは crate で埋め込まれます (crates/erika/assets/artcnn)、コンパイル中にパッケージ化され、実行時にはファイル システムにアクセスしません。重みは 2 つの精度 (F16 および F32) で提供され、2 つの要求モードに対応します。

モード値説明
Off0超解像度をオフにして、ネイティブの輝度サンプリングを使用します。
ArtCnnC4F161Metal simdgroup matrix パスの半精度重み。
ArtCnnC4F322wgpu compute パスの単精度重み。

実行パス実行経路#

2 つの compute 実装は同じモデル記述を共有し、重み形式はリクエスト モードに対応します。

  • Metal(macOS / iOS / tvOS) — simdgroup matrix 畳み込み。体重は入っています erika-upscaler-build スレッドの背景構築、構築完了後に使用します SimdgroupMatrix 状態アクセス パイプライン。
  • wgpu compute(Android / HarmonyOS) — ブロックされた compute オペレーター、F32 パス。

残りのレンダリング バックエンド (D3D11) には ArtCNN エグゼキュータがなく、有効になっている場合はネイティブ輝度サンプルを保持するよう要求します。active_backend 報告書 Inactive、ホストは、プラットフォームがスーパー スコアをサポートしていないことを確認できます。

バックエンドのステータス意味
Off要求されていません。
Inactiveリクエストされましたが、バックエンドは利用できません。ネイティブ サンプリングは保持されます。
Buildingウェイトは構築中であり、まだパイプラインに接続されていません。
Scalarスカラー実行パス。
SimdgroupMatrixsimdgroup matrix 実行パス。

アクセス方法パイプライン#

やり過ぎ NeuralUpscale pass は、インポートとサンプリングの間に pass イメージを挿入します。ルマ チャネルはモデルによって 2 倍に増幅され、クロマ チャネルは通常どおりスケーリングされます。後続の tone mapping、合成および出力変換は変更されません。

各フレームのエンコードと GPU 時間の消費は、 last_encode_micros と last_gpu_micros。実行失敗が蓄積される fallback_count そして、一時的にネイティブ サンプリングにロールバックし、次のフレームで再試行します。
